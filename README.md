# 용사, 또 너야? (Again, Hero?)

> **용사는 성장하고, 마왕은 학습한다.**

뱀서라이크의 역할을 뒤집은 모바일 로그라이트 전략 게임입니다.

플레이어는 마왕이 되어 몬스터 군단을 배치하고, 몬스터를 처치하며 스스로 빌드를 선택하는 **AI 용사**를 관찰합니다.  
반복되는 실패에서 전투 데이터를 얻고 몬스터와 연구를 해금하여, 용사의 빌드를 **유도하고 카운터해 최종적으로 쓰러뜨리는 것**이 목표입니다.

## 핵심 플레이

- 몬스터를 소환하고 진형/타이밍을 설계한다.
- AI 용사는 전투 상황을 보고 무기와 패시브를 선택하며 성장한다.
- 플레이어는 약한 공세를 미끼로 사용해 AI의 빌드를 특정 방향으로 유도할 수 있다.
- 실패 후 연구와 정보가 누적되어 다음 도전의 전략이 확장된다.
- 단순 스탯 싸움보다 **관찰 → 유도 → 카운터 → 학습**을 핵심 재미로 삼는다.

## 개발 방향

- Engine: **Godot 4.x**
- Target: **Mobile (Android 우선)**
- Orientation: **Portrait (1080×1920, 세로 전용)**
- Genre: Reverse Survivors-like / Roguelite / Strategy
- Prototype target: 용사 1명 + 몬스터 3종 + 자동 전투 + 레벨업 + AI 빌드 선택
