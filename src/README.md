# src/

게임 런타임 코드는 이 폴더 아래에서 관리한다.

예정 책임 분리:

- `main/` — 앱 진입점, 상위 화면 흐름
- `battle/` — 한 Run의 전투 흐름과 종료 조건
- `hero/` — AI 용사의 이동/공격/성장 상태
- `monsters/` — 몬스터 공통 로직과 개별 행동
- `ai/` — Utility AI 및 빌드 선택
- `systems/` — 지휘력, 경험치, 저장 등 공용 시스템
- `ui/` — HUD, 소환 카드, 결과 화면
- `data/` — 몬스터/스킬/밸런스 데이터 정의

## 초기 아키텍처 원칙

프로토타입 단계에서는 구조를 미리 과도하게 만들지 않는다.
Milestone에 필요한 파일만 추가하고, 실제 중복/복잡도가 생길 때 공통화를 진행한다.

첫 구현 순서는 `docs/ROADMAP.md`를 따른다.
