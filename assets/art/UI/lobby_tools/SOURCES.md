# Lobby tool icons

Generated with the built-in image_gen tool, transparent backgrounds. Original generated PNGs preserved in docs/resources/lobby_tools_sources.zip; runtime PNGs are cropped to alpha bounds, fitted into 112×112 with nearest-neighbor and centered on transparent 128×128. View uses TEXTURE_FILTER_NEAREST. No runtime resizing or image duplication.
