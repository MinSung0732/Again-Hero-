# 프로필 화면 에셋

- `banner_male.png`: 사용자가 2026-10-06 첨부한 두 번째 이미지(`codex-clipboard-d263b2ef-1db7-449b-bd79-8b8f1650305b.png`). 사용자 확인에 따른 남성 마왕 기본 배너 원본. 복사만 수행, 픽셀/색/캐릭터 수정 없음.
- `banner_female.png`: 같은 날 첨부한 첫 번째 이미지(`codex-clipboard-e31ae3e3-9c22-4eb1-bfb4-043d74ac12ab.png`). 사용자 확인에 따른 여성 마왕 기본 배너 원본. 복사만 수행, 픽셀/색/캐릭터 수정 없음.
- `icon_*.svg`: 이 작업에서 직접 제작한 투명 픽셀풍 UI 아이콘(초상화 액자, 깃발, 대표 마왕 상징, 왕관, 연필). 기존 금색/보라색 UI 색상 사용. 새 캐릭터 그림이 아닌 기능 표시용 UI 심볼이며 글자·수치는 포함하지 않음.
- 프레임은 기존 commerce_v2 `shop_featured_frame` / `shop_button_frame`을 재사용. 초상화는 기존 demonking PNG 재사용.
- 일러스트 감상 배너는 현재 선택한 기본 배너 텍스처를 재사용. 하단 후속 기능 자리는 에셋/문구/버튼 없는 빈 공간.
