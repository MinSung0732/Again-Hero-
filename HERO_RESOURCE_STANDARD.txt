용사 리소스 규격
Again-Hero- 프로젝트 공통 기준

1. 목적
이 문서는 모든 스테이지 용사의 인게임 도트와 로비 초상화가
서로 다른 원본 해상도/캔버스 크기를 사용하더라도
화면에서 일관된 체급과 점유율로 보이도록 하기 위한 프로젝트 공통 규격이다.

2. 인게임 용사 도트 기준
- 모든 용사의 화면상 크기 기준은 Stage 1 견습 마도사다.
- 기준 리소스:
  res://assets/art/heroes/stage1_mage/stage1_mage_spritesheet.png
- 기준은 첫 idle 프레임에서 투명 여백을 제외한 실제 도트 높이다.
- Stage 1 기존 렌더 스케일 3.0을 곱한 화면상 높이를 프로젝트 기준값으로 사용한다.
- 신규 용사는 원본 PNG 캔버스 크기와 상관없이 실제 사용 영역 높이를 측정해 자동 정규화한다.
- 예: 64x64 / 229x229 / 512x512 원본이어도 인게임 체급은 Stage 1 기준으로 맞춘다.
- 캐릭터별 임의 scale 하드코딩보다 자동 정규화 함수를 우선 사용한다.
- 현재 공통 함수:
  _apply_normalized_hero_visual_scale()
- 기준 용사와 체급 차이가 필요한 경우에도 먼저 기준 크기를 맞춘 뒤,
  의도된 체급 차이는 별도 데이터값으로 명시적으로 추가한다.

3. 인게임 도트 애니메이션 규격
- 같은 캐릭터의 모든 애니메이션 프레임은 동일 셀 크기를 사용한다.
- 발바닥 Y 기준점과 몸통 중심 X 기준점을 유지한다.
- idle / move / attack / hit / death 간 실제 캐릭터 체급이 크게 변하지 않아야 한다.
- 리사이즈는 nearest-neighbor를 사용한다.
- 블러, 안티앨리어싱, 반투명 외곽 보간은 사용하지 않는다.
- PNG 원본을 직접 사용하며 Base64 리소스는 사용하지 않는다.

4. 로비 용사 초상화 기준
- 모든 용사 초상화의 화면상 점유율 기준은 Stage 1 견습 마도사 초상화다.
- 기준 리소스:
  res://assets/art/heroes/stage1_mage/stage1_hero_portrait.png
- 단순히 TextureRect 프레임 크기만 동일하게 두는 것으로 끝내지 않는다.
- 각 초상화의 투명 여백을 제외한 실제 사용 영역을 측정한다.
- 신규 초상화의 실제 캐릭터 높이를 Stage 1 초상화의 실제 사용 영역 높이에 맞춘다.
- 가로세로 비율은 유지한다.
- Stage 1 초상화의 사용 영역 중심을 기준으로 중앙 배치한다.
- 최종 출력 캔버스는 Stage 1 초상화 캔버스 크기를 기준으로 맞춘다.
- 현재 로비 공통 함수:
  _normalize_hero_portrait_texture()
- 신규 스테이지 초상화는 portrait_path만 지정하면 동일 규격으로 정규화되도록 유지한다.

5. 스테이지 이름 / 용사 이름 구분
- 스테이지 카드의 큰 제목은 침입 순서를 표시한다.
  예:
  Stage 1 -> 첫 번째 침입자
  Stage 2 -> 두 번째 침입자
- 용사 직업/개체 이름은 별도 HeroName 영역에 표시한다.
  예:
  견습 마도사
  그림자 도적
- Stage display_name과 Hero profile display_name을 같은 용도로 사용하지 않는다.

6. Stage 2 현재 적용값
- Stage title:
  두 번째 침입자
- Hero display name:
  그림자 도적
- 로비 초상화:
  res://assets/art/heroes/stage2_rogue/stage2_hero_portrait2.png
- 인게임 본체:
  res://assets/art/heroes/stage2_rogue/frames/
- 인게임 도트 크기는 Stage 1 기준 자동 정규화
- 로비 초상화 크기도 Stage 1 기준 자동 정규화

7. 신규 용사 추가 체크리스트
[ ] Hero profile 작성
[ ] Stage portrait_path 지정
[ ] 첫 idle 프레임 존재
[ ] 투명 배경 PNG 사용
[ ] 모든 애니메이션 동일 셀 크기
[ ] 발바닥 Y / 몸통 중심 X 기준 유지
[ ] 인게임 도트 자동 정규화 확인
[ ] 로비 초상화 자동 정규화 확인
[ ] Stage title과 Hero display name 분리 확인
[ ] 픽셀 리소스 필터링/리사이즈 nearest 확인
[ ] 실제 모바일/PC 디버그 화면에서 체감 크기 최종 확인

8. 금지사항
- 캐릭터마다 눈대중으로 scale 값을 따로 맞추는 방식
- 초상화마다 TextureRect 크기를 별도로 수정하는 방식
- 원본 투명 여백 차이를 그대로 둔 채 같은 크기라고 판단하는 방식
- 픽셀 도트에 bilinear filtering / blur / antialiasing 적용
- 용사별 UI 체급 규칙을 별도 코드에 중복 하드코딩

9. 기준 변경 원칙
Stage 1 견습 마도사의 화면상 크기가 프로젝트 기준이다.
향후 전체 UI 스케일을 변경하더라도 개별 용사끼리의 상대 크기는
이 기준을 통해 동일하게 유지한다.
