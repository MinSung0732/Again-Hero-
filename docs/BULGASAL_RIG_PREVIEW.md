# 불가살 실제 파츠 리깅 미리보기 (2026-10-08)

## 상태와 실행

시각 검토용 개발 장면. 실제 뽑기·보상·골드·전투 코드에 등록하지 않았다.
`src/dev/bulgasal/cutscene_preview.tscn`을 Godot 4.5.1에서 열고 F6 실행.
Space: 일시정지, R: 처음부터. 5.8초마다 반복하며 공개 영상은 첫 5초이다.
이것은 Godot Skeleton2D/Polygon2D 기반 파츠 리깅이며 Cubism Live2D 모델이 아니다.

## 실제 적용 방식

- 업로드된 `bulgasal_parts_v1.zip`의 PNG 16개를 각각 사용. 원본 PNG를 수정하지 않았으며 시트를 애니메이션 프레임으로 재생하지 않는다.
- ZIP은 384×512 개별 생성 파츠 초안이며 재조립 좌표·관절 좌표가 없었다. `rig_v1/layout.json`에 공통 0.92 배율, 위치, 각도, 겹침 순서를 수동으로 기록했다. 투명 가장자리의 region만 지정하며 파츠별 자동 맞춤을 하지 않는다.
- 발·다리와 각 파츠의 보정 위치·배율은 재생 중 고정. 상체 부모에 최대1.8px 이동/0.1도 회전으로 호흡. 팔의 큰 회전과 전신 늘이기는 사용하지 않는다.
- 갈기·허리 천·꼬리만 각각 13×19 격자와 3개 뼈로 움직인다. 뿌리 고정, 중간/끝 지연. 각도는 갈기1.8도·천1.2도·꼬리0.45도; 끝은1.7배. 관절 구멍이 생기는 큰 동작은 피한다.
- 텍스처·노드는 준비 시1회 생성/캐시, 프레임마다 시간과 기존 노드 속성만 갱신. 런타임 import 리소스 사용, nearest, mipmap 없음.
- 배경·금빛 화염·불씨/쇳조각·캐릭터·이름은 별도 레이어. 0.75~1.95초 공개, 1.75~3.6초 금빛 화염, 2.3초 쇳조각 방출, 3.95~4.45초 하단 이름.
- 540×960 디자인 캔버스를 contain 방식으로 배치. 다른 비율에서는 여백을 두고 전신·이름 공간을 보존한다.

## 외형 차이와 부족한 리소스

이번 조립은 원본 일러스트와 픽셀 단위로 일치하지 않는다. 원본이 아닌 개별 생성 파츠 초안을 조립했기 때문에 팔/다리 자세와 연결부 외형이 다르다. `approved_fullbody.png`는 비교 기준일 뿐 애니메이션 본체로 사용하지 않는다.
평평하게 잘린 팔꿈치·무릎 단면은 새 금색/검정 갑주 덮개로 보완했다. 이 덮개 역시 새 디자인의 임시 보완 에셋이며 최종 승인된 원화가 아니다.
완성 모델에는 원본과 같은 좌표의 공통768×1280 파츠, 몸통 뒤 어깨/팔꿈치/무릎 피부와 갑주 연결면의 충분한 겹침, 갈기 뒤 목·어깨 복원, 허리천 뒤 골반/허벅지 복원, 눈/눈꺼풀/입 별도 파츠, 표정 기준점이 필요하다. 원본과 같은 자세·외형 보장이 필요하면 이 공통 좌표 파츠로 교체해야 한다.
현재 눈 깜빡임·입 동작·얼굴 회전·큰 팔 스킬 동작은 구현하지 않았다. 영상은 무음이며 연출과 배경은 검토용이다.

## 생성 에셋 기록

`forge_background.png`: 인물 없는 검은 암석/철제 기둥의 한국 판타지 대장간, 먼 용광로와 둥근 소환 단상, 세로 구도.
`forge_vfx_atlas.png`: 투명 2×2 시트, 금빛 화염/쇳조각/불씨 연무/작은 불씨. 각 칸은 독립 이펙트이고 동작 프레임이 아니다.
`joint_patch_atlas.png`: 투명 2×2 검정 철/금색 갑주 덮개, 팔꿈치/손목/무릎/발목. 불가살 원본을 참조해 생성. 현 조립의 단면을 덮는 보완본.
생성 이미지의 실제 크기는 각각 그대로 보존하고 atlas의 정확한 절반을 region으로 사용한다. 원본 ZIP/원본 일러스트는 덮어쓰지 않았다.

## 검증

- Godot4.5.1 Linux OpenGL(Mesa llvmpipe) 격리 프로젝트에서 실제 장면 실행, 첫5초150프레임 캡처. MP4는 이 엔진 캡처를30fps로 인코딩했다.
- 동일한 실제 스크립트/장면/텍스처를 격리 프로젝트에 복사해 실행. 전체 게임 실행/Android 실기기/APK export 검증은 하지 않았다.
- `verify_rig.gd`: 실제16개 파츠·3개 유연 리그, 300회 시간 갱신 중 보정 좌표/크기 유지와 뿌리 고정, 노드 수 유지, 이름 타이밍, 540×960·360×800·768×1024·960×540 캔버스 내부 배치 검사.
- 실행: `godot --headless --path <project> --script res://src/dev/bulgasal/verify_rig.gd`.
- 캡처: `godot --path <project> res://src/dev/bulgasal/cutscene_preview.tscn -- --capture=<absolute-directory>` (그래픽 렌더러 필요).
- 기존 뽑기 확률/픽업/골드/보상/복수 당첨 흐름은 변경하지 않았다. 최종 시각 승인 후 기존 Catalog에 별도 등록하는 단계가 남아 있다.
