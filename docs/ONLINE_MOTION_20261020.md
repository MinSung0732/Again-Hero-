# 온라인 용사·몬스터 표시 이동 — 2026-10-20

## 동작과 범위

기존 정기 상태는 10Hz다. 클라이언트가 상태 좌표에 즉시 붙이던 용사·몬스터 PNG/대체 몸체/체력바를 현재 표시점에서 새 목표까지 한 상태 주기(0.1초)에 걸쳐 선형 이동시킨다. 수신 중 새 목표가 오면 그때의 표시점에서 다시 시작한다. 입력 예측·속도 추정·외삽·추가 전송은 없다. 서버가 준 state/visual 명령은 수정하지 않는다. HP·피해·충돌·AI·소환/지휘력/인구·승패·보상은 기존 서버 경로다.

꾸준한 이동에는 약 한 상태 주기의 표시 지연이 추가될 수 있다. 이는 RTT/입력 처리 확인을 줄이는 변경이 아니다. 프레임/방향/공격 자세는 최신 PNG를 그대로 쓰며 위치만 보간한다. 식별자가 없는 투사체·도형 VFX·피격 숫자는 기존 서버 좌표 표시를 유지한다.

처음 보는 wire ID, 0.3초 이상 상태 공백, 표시점에서 256월드 단위 초과 떨어진 목표는 즉시 맞춘다. 값은 `online_presentation_catalog.gd`의 표현 정책에 모으고, 주기는 `match_rules.gd`를 공유한다. 개체 ID별 분기나 몬스터 속도 복사본은 없다. 소켓/상대 연결 끊김·종료는 표시 이동을 멈추고, 재매칭/복귀는 첫 상태부터 새 기준을 잡는다. 사라진 ID는 즉시 반납해 죽은 개체를 이전 위치에 남기지 않는다.

기둥·왕좌는 기존 정적 명령을 재사용한다. 표시 중인 개체의 접지점 Y로 인덱스 순서를 갱신하므로 이동 중 기둥을 지날 때도 앞뒤 순서를 맞춘다. 원본 명령의 z/접지점/변환은 보존한다.

## 비용

기존 수신 허용 상한 216개체+용사 1개를 고정 Packed 배열로 보관한다. ID→슬롯 사전, 고정 반납/활성 슬롯 버퍼를 재사용한다. 새 상태에서만 수신 개체 검증·슬롯 회수·표현 인덱스를 준비한다. 매 프레임에는 활성 슬롯 위치와 기존 명령의 깊이 키만 갱신하며, Y가 바뀔 때 기존 인덱스 배열을 O(n log n) 정렬한다. 매 프레임 배열/Dictionary 생성·그룹/트리 검색·전투 노드 생성/파괴·이중 개체 탐색은 추가하지 않았다. 이동과 텍스처 로딩이 끝나면 view의 `_process`를 끈다. 상태 공백은 이때도 단조 수신 시계로 판단한다.

프로토콜은6 유지. 통신 형식/전송 주기/서버 처리량은 변경하지 않았다. 새 클라이언트 빌드를 양쪽에 적용하면 된다. 서버에 이번 클라이언트 변경만을 위한 추가 설정은 없다.

## 검사와 재현

`tests/online_motion_smoke.gd`는 시간 중간점/재목표/외삽 금지/공백·순간이동, 최대 로스터 전체 교체와 ID 회수, PNG/체력바 공용 위치·기둥 깊이 교차, 원본 상태 불변·중복 ID 거부, 이동 후 idle 중지·소켓/상대 끊김·복귀·종료를 확인한다.

`tests/online_motion_benchmark.gd`는 실제 Battle/5종 로스터의 0·24·48개체를 짧게 준비한 뒤 일시정지한다. 지휘력/비용을 우회한 테스트 직접 생성이며 소환 가능 조합의 증거는 아니다. 실제 PNG 명령/성 장식을 사용하는 snapshot 생성·JSON 인코딩·view 설치와 합성 수직 이동의 CPU 비용을 따로 측정한다. 워밍업8회 후96회, 이동 비용은 마지막96개 프레임의 mean/P95다. 지속 전투/오디오/JSON decode/소켓/WSS/GPU 비용은 제외한다. 전후 최적화율·실기 FPS/수용 인원 측정이 아니다.

```sh
python tools/build_online_fixture.py /tmp/again-online-metrics
# 원본 역할 로딩/마왕성/5종 PNG·공격 효과·기존 SFX overlay 유지.
godot --headless --editor --import --path /tmp/again-online-metrics --quit
godot --headless --path /tmp/again-online-metrics --script res://tests/online_motion_smoke.gd
godot --headless --path /tmp/again-online-metrics --script res://tests/online_motion_benchmark.gd
python tools/run_online_process_smoke.py /absolute/path/to/godot /tmp/again-online-metrics --metrics
```

실제 Windows4.7.2↔Android/WSS/GPU는 미검증. 두 기기에서 전투 시작 후 측정 초기화→직선/방향 전환→다수 소환→기둥 교차→양쪽 끊김/복귀를 확인하고 각각 측정값을 복사한다. 위치 보간에 따른 조작감과 피격/VFX 시점도 확인한다. 이후 트래픽/서버 부하 조정은 실제 기기 수치를 기준으로 한다. 정식 매칭의 해금/MMR/결과 저장/중복 보상은 별도 후속이다.
