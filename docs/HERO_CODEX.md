# 용사도감

기타 → 용사도감. 왼쪽 세로 목록의 도트·이름을 눌러 선택하고 오른쪽 기본정보/기술·특성/증강/대응전략/리소스 탭으로 분석한다. 스테이지 번호는 표시하지 않는다. 왼쪽 목록과 오른쪽 설명은 독립적으로 스크롤되며 좁은 폭에서는 탭이 여러 줄로 배치된다. 기타의 기존 공통 뒤로가기 버튼을 사용한다. 모든 현재 스테이지의 용사를 볼 수 있으며 도감 조회는 해금, 저장, 전투 상태를 변경하지 않는다.

## 정보 기준

- StageCatalog의 순서·초상화·설명과 HeroProfiles의 현재 전투 데이터를 연결한다. 능력치 5항목은 입장 시 스테이지 보정과 반올림/최소값을 반영한 시작 수치이며 현재 진행 중인 전투 수치가 아니다. 성장·전투 제한시간·지도 크기도 표시한다.
- 이름이 있는 기술/소환체는 프로필의 중첩 Dictionary에서 찾는다. 자원, 재사용 대기시간, 첫 사용 대기시간, 피해, 범위, 지속시간, 발동/해금 조건을 한국어 수치 설명으로 표시한다. 반경·지름, 비율·배율을 구분하며 연출 크기/FPS/오브젝트 풀 수량 등 구현 값은 제외한다. 탄창/광기/부활/원소/소환 슬롯 등 이름 없는 자동 시스템은 별도 제목으로 표시한다.
- 기존 Hero의 기술 툴팁 문장을 HeroSkillDescriptions로 이동해 공유한다. 명시적인 프로필 description을 우선하고 부족한 기술의 설명만 보완한다. 전투 기술 판정/수치는 변경하지 않는다.
- 증강은 각 용사의 실제 augment_pool_ids와 HeroAugmentCatalog를 사용한다. 설명, 분류, 실제 최대 중첩(화학 용사 pursuit 예외 포함)을 표시한다. 현재 중첩·상호 배제·후보 조건 때문에 목록이 곧 확정 선택을 의미하지 않는다.
- AI 성향 이름/관측 간격/양수 선호 증강은 HeroAIProfiles에서 가져온다. 관찰·유도·카운터 팁은 해당 전투 방식에 대한 제안이며 확정 약점이나 확정 선택으로 표현하지 않는다.

## 구조·확장

HeroCodexCatalog는 읽기 전용 표시 데이터를 생성한다. LobbyHeroCodexView는 선택한 용사의 텍스트/초상화와 두 가지 스타일을 캐시하며, 4개 텍스트 컨트롤과 리소스 그리드 1개를 재사용한다. 목록은 원본 대기 도트, 리소스는 원본 초상화/초상화 축소 아이콘/대기·이동 첫 프레임을 사용한다. 실제 별도 아이콘을 새로 만들었다고 표현하지 않는다. 프레임별 조회나 전투 개체 생성이 없다. 신규 용사는 StageCatalog/HeroProfiles 등록 시 목록·능력치·이름 있는 기술·증강이 자동 연결된다. 신규 전투 방식의 팁과 새 수치 이름은 GUIDES/SYSTEM_TITLES/FIELDS에 추가한다. 알려지지 않은 정보는 준비 중으로 처리한다.

기존 기타 배경/제목 프레임과 원본 용사 초상화를 사용한다. 재첨부된 「용사 도감_ 검과 방패의 영웅.png」는 정상 확인했고, 왼쪽 목록/오른쪽 상세/리소스 미리보기 구조를 반영했다. 새 아트 파일은 생성하지 않았다.

## 검증

```sh
python tests/run_hero_codex_smoke.py --godot /path/to/godot
```

실제 production 데이터/뷰/터치 버튼을 최소 프로젝트에 복사해 검사한다. 로그인/클라우드/전투/사용자 저장 autoload를 실행하지 않는다. 10명과 4개 구역, 모든 이름 있는 기술의 구체적인 설명, 실제 증강 목록, 원본 데이터 불변, 스테이지 보정, 배율 표시, 미등록 ID, 재진입 캐시, 540/740/900 폭의 최소 가로 크기, 터치 완료/드래그 취소를 검사한다. 원본 Galmuri11 폰트가 있으면 사용한다.

Godot 4.5.1 격리 headless 검사와 gdtoolkit 파싱/git diff --check 통과. 전체 로비 통합, 스크롤 관성, 실제 Android 터치/화면 렌더는 미검증이다. 실제 기기에서 제목 프레임·가로 용사 목록·세로 설명 스크롤·공통 뒤로가기와 설정/프로필 재진입을 확인한다.
