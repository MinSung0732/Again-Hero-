기본 지름350(반경175) 안 살아있는 해당 아군의 현재 수를 사용합니다. 자기 자신도 이름 조건에 맞으므로 포함합니다. 사망·제거·범위 이탈 시 해당 +2 및 공속2%를 제거하며 영구 음수 중첩을 추가하지 않습니다. 다시 진입하면 다시 포함합니다.

`HP = (성장·연구·등급·증강 적용 기본 HP + 2×개체수) × (100마리 이상이면4, 그 외1)`.
`공격력 = 기존 기본 공격력 + 2×개체수`, `이동속도 = 기존 기본 이동속도 + 2×개체수`.
`공격 간격 = 기존 기본 간격 / (1 + 0.02×개체수)`.
최대HP 변경 시 체력 비율을 유지하고 기존 지원 공격 버프와 소환/대형/엘리트/마왕 성장 스냅샷을 보존합니다. 같은 수를 반복 관측해도 재곱하지 않습니다.

- 100마리 이상: 최대체력+300%, 즉4배. 99마리 이하로 내려가면 제거합니다.
