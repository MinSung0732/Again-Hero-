# 제우스 초월 소환 컷신

## 현재 구현

확정·저장된 `reveal_entries`만 소비하는 5초 표시 계층이다. 일반/픽업 모두 기존 `award_shard_batch` 성공 이후 같은 `GachaRevealOverlay.present()` 경로를 사용한다. 확률0.5%, 픽업 풀 내부 가중치3, 골드100/1000, 첫 해금/반복 조각/프로필 사용권 및 내역 저장은 변경하지 않는다. 연출 파일에는 추첨·골드·보상 쓰기 호출이 없다.

- 0–1초: 어두운 신전, 분리 소환진·푸른 전기와 작은 입자.
- 1–2초: 중앙 번개 기둥, 화면 섬광, 신전 밝기 상승.
- 2–3초: 동일 발 기준점에서 전신 실루엣 공개.
- 3–4초: 색상 공개·금빛 후광, 독립 번개.
- 4–5초: 전신 유지·전기 감소, 하단 native Label ‘제우스’만 부드럽게 등장.

배경/캐릭터/이펙트를 분리한다. 원본 idle4프레임 그대로, 고정250×210 소스 영역과 동일2.2배 확대 사용. 프레임03의 발 기준365와 다른 프레임366의 1px 차이만 위치로 보정하며 체형/스케일을 변형하지 않는다. 도트/소환진/전기/번개 모두 원본 투명 PNG, nearest 필터. FX 전용 셰이더는 원본 PNG를 수정하지 않고 푸른 전기색만 적용한다. 캐릭터와 배경에는 적용하지 않는다. 플레이어/FX/UI는 한 번 생성해 재사용하고 texture cache/고정18개 입자만 사용한다.

1280×720 가로 무대를 contain으로 맞춘다. 16:9, 넓은 가로, 4:3, 세로에서도 전체 전신·지팡이 및 하단 이름 여백을 유지한다. Android 컷신 동안 가로 방향을 요청하고 정상 종료/스킵/외부 숨김/씬 제거 때 이전 방향으로 복원한다. PC는 창을 강제 회전하지 않는다. OS가 회전을 거절하면 세로 화면 안에 가로 무대를 온전히 표시한다. Android 회전·노치/IME·실제 터치 품질은 실기기 확인 필요.

## 결과와 스킵

개별 결과를 획득 순서대로 공개하며 등록된 초월 결과 차례에만 컷신을 재생한다. 컷신 정상 종료와 자체 스킵은 그 결과의 기존 획득 카드로 연결한다. 카드 터치로 다음 획득을 진행한다. 제우스가 여러 번 나오면 각 순서에서 다시 재생한다. 기존 전체 스킵(`skip_to_results`)은 진행 중/로딩 중 컷신을 취소하고 한 번에 전체 결과 목록을 표시한다. generation/token 검사로 늦게 끝난 비동기 로딩과 오래된 종료가 결과를 덮지 않는다.

## 완료된 부분 / 임시 표현

완료: 결과 연결/순서/스킵/취소, 시간에 따른 밝기·실루엣·이름, 원본 도트 idle 재생, PNG FX 분리, 배경 에셋, 비율 대응, 개발 미리보기.

임시: 콘티의 큰 전신 일러스트 대신 기존 SD 전신 도트 사용. 원본 idle는 기존 작은 머리/옷 움직임을 그대로 사용하며 새로운 큰 일러스트 동작을 만들었다고 주장하지 않는다. 신전 구름은 배경 한 장에 포함되어 독립 유동 애니메이션은 없다. 번개는 기존 전투용8프레임, 후광은 얇은 기하학 링이다. 그림체/동작 완성본으로 바꾸려면 아래 분리 리소스가 필요하다. 콘티를 잘라 슬라이드로 사용하지 않는다.

배경: `assets/art/effects/gatcha/zeus/celestial_temple.png` (1672×941). 내장 imagegen 스킬/기본 생성 도구로 신규 생성. 프롬프트: ‘16:9 선명한 픽셀아트, 구름 위 흰 대리석·금색 그리스 신전, 먼 떠 있는 신전과 푸른 하늘, 중앙 전신 캐릭터를 위한 빈 소환 플랫폼과 하단 여백, 캐릭터/번개/후광/텍스트/UI/프레임 없음’. 원본 캐릭터 PNG 수정 없음.

## 완성 리소스 권장 규격 / 교체

| 리소스 | 규격 | 기준 |
|---|---|---|
| 큰 전신 idle | 투명 PNG512×720,4–8프레임,6fps | 몸통 중심x256/발바닥y700 고정; 지팡이·머리·발끝 모두 최소16px 안쪽; 머리카락/옷자락만 작게 변화 |
| 번개 기둥 | 투명 PNG320×720,8–12프레임,12fps | 바닥 중심x160/y680, 번개만 포함, 배경/캐릭터 없음 |
| 소환진 | 투명 PNG512×256,8프레임,12fps | 같은 캔버스·중심, 바닥 투영 타원, 중앙 비워도 됨 |
| 주변 전기 | 투명 PNG512×512,8–12프레임,12fps | 같은 중심, 캐릭터/배경/후광 없음 |
| 금빛 후광 | 투명 PNG512×512,1장 | 중심고정, 이름/배지/별 없이 링만 |
| 독립 구름 | 투명 PNG1280×720 전경/중경 별도 | 신전·캐릭터 없음; 추가 parallax 계층은 별도 구현 필요 |

`TranscendentCutsceneCatalog.ENTRIES`에 콘텐츠별 등록. 현재 `character_dir/prefix/count/fps/region/feet_y/scale/anchor`, FX 각dir/prefix/count, `effect_fps`, `background_path`, `halo_path`, `name/duration`을 교체한다. 큰 전신512×720 예: region(0,0,512,720), feet_y 각700, scale0.68, anchor(640,574). 캐릭터별 다른 타이밍/구름 전경은 공통 플레이어 확장 후 데이터로 지정한다. PNG 합성본은 캐릭터 슬롯에 넣지 않는다.

## 확률을 바꾸지 않는 미리보기

Godot 에디터에서 `src/dev/ZeusCutscenePreview.tscn`을 열고 F6 실행. 컷신만,1회 결과 연결,10+1회 중2/6/10번째 제우스3개 버튼을 제공한다. 모두 표시용 고정 결과, 실제 추첨/재화/계정 저장 없이 실행. 다시 뽑기는 구성하지 않아 비활성이다. PC 가로 미리보기:

```sh
godot --path . --resolution 1280x720 res://src/dev/ZeusCutscenePreview.tscn
```

## 자동 검증

```sh
godot --headless --path . --script tests/zeus_cutscene_smoke.gd
godot --headless --path . --script tests/pickup_probability_smoke.gd
```

컷신 회귀는 비로그인 개발 환경에서 실행. 고유 `user://zeus_fixture_*` 디렉터리에만 테스트 보상을 기록한다. 일반/픽업 각각1000골드·11개 지급을 실제 저장하고, 초월 첫 해금/후속2조각·잔액0 확인. 정상/개별 스킵/전체 스킵/로딩취소·3개 당첨 순서·결과 불변 및 표시 후 골드/수집 파일 byte 동일을 확인한다. 네 화면 비율에서 모든 프레임 영역이 화면에 포함되고 이름 위에 남는지 검사한다. 결정적 clock 검사에 더해 production _process clock의 실제5초 종료도 확인한다. Android 터치·회전 검증을 대신하지 않는다.

2026-10-07 Godot4.6 headless 두 회귀 PASS. 기존 결과 카드 `gacha_card_glow.gdshader`의 sampler helper에서 headless dummy shader compiler 경고1건 발생(컷신 신규 셰이더 오류 아님); Godot4.6 PC OpenGL compatibility(llvmpipe) 동일 회귀는 경고 없이 PASS,0.5/1.2/2.5/3.5/4.6초 실제 렌더 캡처에서 전신·분리 FX·이름 배치를 확인. Android 실기기는 미검증.
