# 제우스 초월 소환 컷신

## 현재 구현

확정·저장된 `reveal_entries`만 소비하는 5초 표시 계층이다. 일반/픽업 모두 기존 `award_shard_batch` 성공 이후 같은 `GachaRevealOverlay.present()` 경로를 사용한다. 확률0.5%, 픽업 풀 내부 가중치3, 골드100/1000, 첫 해금/반복 조각/프로필 사용권 및 내역 저장은 변경하지 않는다. 연출 파일에는 추첨·골드·보상 쓰기 호출이 없다.

- 0–1초: 어두운 신전, 분리 소환진·푸른 전기와 작은 입자.
- 1–2초: 중앙 번개 기둥, 화면 섬광, 신전 밝기 상승.
- 2–3초: 동일 발 기준점에서 전신 실루엣 공개.
- 3–4초: 색상 공개·금빛 후광, 독립 번개.
- 4–5초: 전신 유지·전기 감소, 하단 native Label ‘제우스’만 부드럽게 등장.

배경/캐릭터/이펙트를 분리한다. 사용자 제공 최종 전신 일러스트 `assets/art/effects/gatcha/zeus/portrait/idle_01.png`를 수정 없이 사용한다. 원본은768×1280 RGBA, alpha bounds(36,254)..(607,1200), 최소여백36px, 마지막 실제 픽셀 row1199(발바닥 경계Y1200). 몸통 기준X384은 사용자 제공 기준. 전체768×1280 영역과 기준발1200을 사용해 균일1.25배, 무대 발 위치(540,1570)에 배치한다. native 이름영역(240,1740,600,72)까지 전신 캔버스 하단과70px 간격을 확보한다. 캐릭터를 흔들거나 변형하지 않는다.

현재 캐릭터는1프레임 정지 이미지이며, 머리/옷 실제 동작은 idle_02..08이 제공되면 적용한다. FX 전용 셰이더는 분리된 기존 PNG 소환진/전기/번개만 푸른색으로 표시한다. 모든 텍스처nearest. 플레이어/FX/UI 재사용,texture cache와 고정18개 입자 유지. 공개/밝기/후광/이름은 시간에 따라 변화하고5초 표시 시간은 combat time_scale/FPS에 영향을 받지 않는 monotonic real-time clock을 사용한다.

1080×1920 세로 무대의 character contain과 배경 cover를 분리한다. 기존 가로 신전 배경은 화면을 가득 채우도록 비율 유지해 중앙 crop하며, 캐릭터는 세로/긴 세로/4:3/가로에서도 전체 프레임을 보존한다. 화면 방향은 변경하지 않는다. 세로 전용 배경이 오면 background_path만 교체할 수 있다. Android 노치/IME·실제 터치 품질은 실기기 확인 필요.

## 결과와 스킵

개별 결과를 획득 순서대로 공개하며 등록된 초월 결과 차례에만 컷신을 재생한다. 컷신 정상 종료와 자체 스킵은 그 결과의 기존 획득 카드로 연결한다. 카드 터치로 다음 획득을 진행한다. 제우스가 여러 번 나오면 각 순서에서 다시 재생한다. 기존 전체 스킵(`skip_to_results`)은 진행 중/로딩 중 컷신을 취소하고 한 번에 전체 결과 목록을 표시한다. generation/token 검사로 늦게 끝난 비동기 로딩과 오래된 종료가 결과를 덮지 않는다.

## 완료된 부분 / 임시 표현

완료: 결과 연결/순서/스킵/취소, 시간에 따른 밝기·실루엣·이름, 최종 전신 PNG 연결, PNG FX 분리, 배경 에셋, 비율 대응, 개발 미리보기.

임시: 캐릭터 동작은 현재1프레임 정지. 6–8프레임 동작이 완성되었다고 주장하지 않는다. 신전은 기존 가로 이미지의 비율 유지 crop이며 구름 독립 애니메이션 없음. 번개는 기존 전투용8프레임, 후광은 얇은 기하학 링이다. 콘티를 잘라 슬라이드로 사용하지 않는다. 나머지 캐릭터/세로 배경/독립 구름이 오면 아래 규격대로 교체한다.

배경: `assets/art/effects/gatcha/zeus/celestial_temple.png` (1672×941). 내장 imagegen 스킬/기본 생성 도구로 신규 생성. 프롬프트: ‘16:9 선명한 픽셀아트, 구름 위 흰 대리석·금색 그리스 신전, 먼 떠 있는 신전과 푸른 하늘, 중앙 전신 캐릭터를 위한 빈 소환 플랫폼과 하단 여백, 캐릭터/번개/후광/텍스트/UI/프레임 없음’. 원본 캐릭터 PNG 수정 없음.

## 완성 리소스 권장 규격 / 교체

| 리소스 | 규격 | 기준 |
|---|---|---|
| 큰 전신 idle | 투명 PNG768×1280,6–8프레임,6–8fps | 몸통 중심x384/발바닥y1200 고정; 지팡이·머리·발끝 모두 최소16px 안쪽; 머리카락/옷자락만 작게 변화 |
| 번개 기둥 | 투명 PNG320×720,8–12프레임,12fps | 바닥 중심x160/y680, 번개만 포함, 배경/캐릭터 없음 |
| 소환진 | 투명 PNG512×256,8프레임,12fps | 같은 캔버스·중심, 바닥 투영 타원, 중앙 비워도 됨 |
| 주변 전기 | 투명 PNG512×512,8–12프레임,12fps | 같은 중심, 캐릭터/배경/후광 없음 |

PNG 합성본은 캐릭터 슬롯에 넣지 않는다.

## 확률을 바꾸지 않는 미리보기

Godot 에디터에서 `src/dev/ZeusCutscenePreview.tscn`을 열고 F6 실행. 컷신만,1회 결과 연결,10+1회 중2/6/10번째 제우스3개 버튼을 제공한다. 모두 표시용 고정 결과, 실제 추첨/재화/계정 저장 없이 실행. 다시 뽑기는 구성하지 않아 비활성이다. PC 세로 미리보기:

```sh
godot --path . --resolution 540x960 res://src/dev/ZeusCutscenePreview.tscn
```


## 세로 전신 일러스트 제작용 최소 묶음 (2026-10-07)

세로 전체 화면 연출용 권장 규격이다. 기존 가로 무대 좌표는 해당 리소스를 연결할 때 세로로 재배치한다.

| 파일 | 권장 규격 | 내용 |
|---|---|---|
| temple_portrait.png | 1080×1920 PNG,1장 | 신전/구름 배경만; 중앙 인물 영역과 하단 이름 여백; 캐릭터/번개/글자 없음 |
| idle_01.png … idle_08.png | 각각768×1280 투명 PNG,6–8프레임 | 원본 비율 전신+지팡이; 같은 위치/크기; 머리·옷 끝만 작은 움직임;6–8fps loop |
| halo.png | 768×768 투명 PNG,1장 | 금빛 후광만; 기존 기하학 링 대체 선택 사항 |
| clouds_front.png | 1080×1920 투명 PNG,1장 | 독립 이동하는 구름만; 선택 사항 |

전신 프레임 공통 몸통 중심x384, 발바닥y1200 고정. 머리·장신구·지팡이까지 캔버스 안쪽 최소32px 여백. 프레임마다 얼굴/머리/체형/의상/장비 크기와 디자인을 유지하고, 마지막→첫 프레임이 이어져야 한다. 배경/번개/소환진/후광/글자를 캐릭터 PNG에 합성하지 않는다. 소환진과 번개는 기존 분리 PNG를 재사용할 수 있어 새 제작은 필수가 아니다. 이름은 게임 Label로 표시한다. manifest에는 셀 크기/프레임 순서/fps/loop/몸통 중심/발바닥 좌표를 포함한다.

5초 전체를150장의 캐릭터 프레임으로 만들 필요는 없다. 작은 idle loop를 캐릭터 공개 이후 반복하고, 밝기/실루엣 공개/번개/이름의 시간 변화는 게임 코드가 처리한다. 전신 정지 투명 PNG1장만 먼저 제공해도 세로 구도 연결은 가능하며, 실제 머리·옷 움직임은 프레임 확보 후 적용한다.
