# 용사 이동 패드 모드 — 2026-10-14

기준 feature/stage10-astra: 3ce59765148b892115b9c4609672b7ec3b0c3e23. main 변경 없음.

## 동작

용사 모드 설정의 게임플레이 탭에 이동 패드 선택을 추가한다. shared BattleSettings 원본은 수정하지 않고 용사 모드에만 설정 행과 설명을 연결한다. user://gameplay_settings.cfg의 gameplay.hero_pad_mode에 fixed/free를 저장한다. 기존 설정이 없거나 알 수 없는 값이면 고정형이며 저장 실패 시 현재 모드를 유지하고 선택 표시를 되돌린다. 프레임/마왕 카메라 등 다른 설정 키를 보존한다.

| 모드 | 표시/기준 | 해제 |
| --- | --- | --- |
| 고정형 | 기존 하단 높이(밑 여백45), 270×270 터치영역을 가로 중앙에 고정 | 손잡이 중앙 복귀, 이동0 |
| 자유형 | 평소 숨김; 실제 BattleView 안을 처음 터치한 위치에 원점 생성, 드래그해도 원점 유지 | 손떼기/취소 시 숨김, 이동0; 다음터치는 새원점 |

원/테두리/손잡이는 회색의 알파0.28/0.50/0.60으로 그린다. 반경105, 데드존0.12, 최대이동길이1은 기존 조작 규칙을 유지한다. 키보드 이동과 카메라 고정도 유지한다.

자유형 최초 입력은 실제 전투 SubViewportContainer의 현재 크기/변환으로 판정한다. 상단 HUD/설정 및 성벽 여백은 입력을 가져오지 않으며, 프레임을 끄면 전투 영역 확대를 즉시 따른다. 원점은 정확한 첫터치 위치이며 가장자리를 눌렀을 때 원을 안쪽으로 옮기지 않는다.

한 포인터가 잡은 동안 다른 손가락/마우스는 패드를 빼앗거나 해제하지 않는다. 터치에서 에뮬레이션한 마우스 이벤트는 패드에서 무시해 이중 소유를 방지한다. 이미 잡은 포인터는 패널 밖으로 이동/해제해도 정상적으로 정지하며 취소·포커스이탈·disabled 전환에서 입력을 초기화한다. 기존 로딩/증강/상자/정지/종료 흐름의 enabled/reset과 연결하고 계정변경 차단 화면에도 disabled를 적용한다.

기존 Control 하나를 재사용한다. 터치마다 노드를 만들거나 해제하지 않고 입력이 바뀔 때만 redraw한다. 배열/딕셔너리 생성 및 그룹 스캔을 전투 입력 경로에 추가하지 않는다.
