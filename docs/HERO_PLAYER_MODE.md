# 용사 모드 — 15분 생존 / 2026-10-13

## 현재 규칙

- 견습마도사(Stage1)는 기본 개방. Stage2~10 용사는 해당 스테이지 **어려움 클리어** 기록으로만 개방한다. 기존 쉬움 클리어·최고 해금 스테이지는 용사 해금으로 간주하지 않는다. `stage_progress.cfg/hard_cleared`를 계정별 저장하며, 잠긴 용사는 선택·입장 전에 거부한다.
- 어려움은 해당 쉬움 클리어 후 도전 가능. 마왕 전투에서 용사 HP ×1.6, 기본 공격 ×1.35, 이동속도 ×1.08. 실제 처치 시 어려움 클리어·용사 해금·첫 연구30을 한 cfg 저장으로 기록한다. 쉬움 군단 해금/보상과 구분하며 중복 지급하지 않는다. 재도전 시 난이도를 보존한다.
- 10종 모두 900초 생존. 직접 이동(패드/WASD/방향키), 무기 자동 공격, 레벨업 3후보 직접 선택. 고정 추적 카메라, 잠금 해제/팬 금지. 마왕 모드의 기존 AI 용사 기술은 유지한다.
- 팀편성은 자물쇠 아이콘과 disabled 상태로 막고 직접 탭 호출도 거부한다. 용사 선택은 메인의 용사 선택창/화살표에서 수행한다. 용사상점 준비중, 성장, 길드 배경은 유지한다.

## 무기 / 보조 증강

`hero_weapon_catalog.gd`에 10종 기본 무기와 기존 이름 있는 기술을 합친 52개 무기 정의, 보조5종을 둔다. 기존 기술의 자동 AI 동작을 용사 모드에서 실행하지 않고 별도 무기 런타임으로 재구성한다. 52개가 각각 원본 기술의 전체 연출/행동을 그대로 재현한다는 의미는 아니다.

- 무기3칸, 보조3칸. 기본 캐릭터 무기 Lv1로 시작한다. 이전 시작 증강 저장은 지우지 않으며 현재 전투에서는 적용하지 않는다. 편성 탭은 현재 잠겨 있다.
- 무기별 Lv1~10. 피해 +18%/레벨, 범위 +3.5%/레벨, 재사용 대기시간 -3.5%/레벨. Lv5·10에 타격 수 증가. 근접 부채꼴, 표적 마력타격, 직선 관통, 광역 폭발, 연쇄 타격, 회전 수호체, 보호막, 지속 독성 장판, 냉기 둔화, 회복 파동의 공격 유형·색을 구분한다.
- 레벨업마다 보유 무기 강화 후보가 있으면 하나를 보장하고 다른 후보를 섞는다. 슬롯이 차면 신규 무기/보조 후보를 제외한다. 모두 만렙이면 회복 후보를 준다. EXP 요구량은 용사 모드에서만 `12 + (레벨-1) × 4`.
- 상자: 미진화 Lv10 무기를 우선 무작위 진화. 없으면 보유 미만렙 무기 +1. 모두 완성되면 최대 HP25% 회복. 진화는 무기마다 한 번, 피해×1.8/타격수+2/범위+25%/대기시간-20%. receipt serial과 적용 플래그로 중복 적용을 막는다.
- 기존 처치 상자 + 엘리트/대형 몬스터 처치 상자. 상자는 용사 근처에 생성하고 무기로 부순다. 전투를 정지한 뒤 보유 무기 이름 릴이 2.4초 감속하고 결과를 한 번 적용한다. 계속 플레이로 재개한다. 상자 중복과 증강 선택 중 도착은 최대4 대기 큐로 순차 처리한다.

| 2~5분 | 1.25 | 2 | 36 | 14 |
| 5~10분 | 0.95 | 3 | 48 | 22 |

스테이지 압력은 `1 + 0.055 × (스테이지-1)`. 회복/활성 제한은 늘리고 간격은 줄이되 전체72 제한과 특수 몬스터2칸을 유지한다. 일반 공세는 실제 비용을 지불한다. 단계별 구성은 기본 군단→고블린→광신도→구미호로 달라진다. 동일 맵 시간표 복제 대신 선택 스테이지의 원래 맵을 사용한다.

첫 엘리트60초, 이후90초/압력. 대형 오우거180/360/540/720/840초. 활성 제한에 걸리면 나중에 재시도한다. 특수 HP·피해도 경과시간/스테이지 압력을 반영한다. 기존 마왕 캠페인의 stage director 이벤트는 용사 모드에서만 중지해 시간표 중복을 막는다. 실제 빌드를4초마다 부분 관측하고55% 대응·나머지 순환 탐색을 유지한다.

## 화면 / 성능 / 저장

- 상단 마왕 UI의 프레임을 재사용한 HP·EXP·분:초·레벨·처치·공세 단계·무기3칸·보조 표시. 무기를 누르면 정지하고 설명을 확인한다. 하단 정보 패널을 없애고 이동 패드만 전장 위에 표시한다.
- 무기 피격 조회는 기존 월드 레지스트리/공간그리드와 재사용 scratch 배열. 효과48칸·장판8칸을 전투 시작에 확보하고 재사용한다. 무기 최대3개, 범위 피해 최대24표적. 새 전투 핫패스에 그룹 전체 스캔/매 프레임 Dictionary 생성/투사체 instantiate/free를 추가하지 않는다.
- 15분에 맞춰 승리 연구100·골드60(이전 3분의5배), 30초/1처치 이상 실패 연구5·골드3 유지. 입장5·30초내 조기 복귀4 환급·실패 입장 환급·보상 receipt와 계정 소유 경계 유지. 새로운 서버/RPC/SQL 없음. 상자 룰렛은 기존 상자 효과음 재사용, 새 오디오 생성 없음.
