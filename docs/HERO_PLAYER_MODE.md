# 용사 모드 — 15분 생존 / 2026-10-13

> 최신 기술 무기/EXP/순차 전장/설정/실행 검증은 [후속 변경](HERO_SURVIVAL_REVISION_20261013.md)을 따른다. 아래 과거 검증 기록과 구분한다.

## 현재 규칙

- 일반 계정은 견습마도사 기본 개방, 나머지 해당 스테이지 어려움 클리어로 해금. 디버그 localtest의 격리 게스트는10종을 모두 선택/입장 가능하며 normaltest 복귀 시 기존 조건을 적용한다. 소유권은 캐릭터 ID로 관리한다. 캐릭터 편성은 활성화하며, 상단 선택 용사/전용 무기 소개 + 하단10종 카드 목록을 표시한다. 메인 용사 선택 버튼은 제거하고 편성한 용사의 초상과 이름을 표시한다.
- 캐릭터와 전장 스테이지는 독립이다. 용사 전장은 Stage1부터 시작해 15분 생존 승리마다 다음 단계를 개방한다. 마왕 캠페인과 독립된 연속 용사 승리 기록을 사용하고 해금 단계+2까지만 미리보기한다. 전장 스테이지는 기존 붕괴 성곽 맵·마왕 군단·압력만 결정한다. 예: 견습마도사를 편성한 채 Stage10에 입장해도 실제 용사는 견습마도사다.
- `hero_loadout.hero_id`와 `battle_stage` 별도 저장. 과거stage 선택은 캐릭터로 마이그레이션하고 성장stage_N키는 출신 캐릭터 키로 유지한다. 용사 입장시 Stamina.try_enter(...,update_campaign_stage=false)를 사용하여 마왕 캠페인의 current_stage_id를 덮어쓰지 않는다. 일반 마왕 입장의 기본 동작은 유지한다.
- 마왕 어려움은 해당 쉬움 클리어 후 도전. 용사 HP×1.6/기본공격×1.35/이동×1.08, 처치 시 hard_cleared·용사 해금·첫연구30 원자 저장/중복방지. 용사 모드의 전장 클리어는 이 어려움 해금과 별개다.
- 10종 모두900초. 직접이동/무기자동공격/레벨업3후보 직접선택·고정추적카메라. 기존 마왕AI 용사의 기술과 진행 규칙은 유지한다.

## 무기 / 보조 증강

`hero_weapon_catalog.gd`의 캐릭터별 전용6종, 총60종과 보조8종을 사용한다. 기존 용사 기술 전체의 공용 증강 변환을 대체한다. 습득/레벨업 후보에서 다른 용사 무기는 거부한다. [전체 무기 목록과 소유권 확장](HERO_CHARACTER_WEAPONS.md).

- 무기3칸, 보조6칸. 편성한 캐릭터의 전용 스타터 Lv1로 시작한다. 이전 시작 증강 저장은 지우지 않으며 현재 전투에서는 적용하지 않는다. 캐릭터 편성에서 용사만 선택하며 시작 무기 선택은 따로 하지 않는다.
- 무기별 Lv1~10. 피해 +18%/레벨, 범위 +3.5%/레벨, 재사용 대기시간 -3.5%/레벨. Lv5·10에 타격 수 증가. 근접 부채꼴, 표적 마력타격, 직선 관통, 광역 폭발, 연쇄 타격, 회전 수호체, 보호막, 지속 독성 장판, 냉기 둔화, 회복 파동의 공격 유형·색을 구분한다.
- 레벨업마다 보유 무기 강화 후보가 있으면 하나를 보장하고 다른 후보를 섞는다. 슬롯이 차면 신규 무기/보조 후보를 제외한다. 모두 만렙이면 회복 후보를 준다. EXP 요구량은 용사 모드에서만 `round(60 + 18n + 1.6n²)`, n=레벨-1. 획득EXP는 기존의25%이고 작은 구슬의 소수EXP를 누적해 분할 손실/최소1 우회를 막는다.
- 상자: 미진화 Lv10 무기를 우선 무작위 진화. 없으면 보유 미만렙 무기 +1. 모두 완성되면 최대 HP25% 회복. 진화는 무기마다 한 번, 피해×1.8/타격수+2/범위+25%/대기시간-20%. receipt serial과 적용 플래그로 중복 적용을 막는다.
- 기존 처치 상자 + 엘리트/대형 몬스터 처치 상자. 상자는 용사 근처에 생성하고 무기로 부순다. 전투를 정지한 뒤 보유 무기 이름 릴이 2.4초 감속하고 결과를 한 번 적용한다. 계속 플레이로 재개한다. 상자 중복과 증강 선택 중 도착은 최대4 대기 큐로 순차 처리한다.

## 마왕 공세

| 생존 시간 | 간격(초) | 한 번에 최대 | 활성 제한 | 지휘력 회복/초 |
|---|---:|---:|---:|---:|
| 0~2분 | 0.9 | 2 | 36 | 20 |
| 2~5분 | 0.8 | 3 | 48 | 30 |
| 5~10분 | 0.7 | 4 | 60 | 40 |
| 10~13분 | 0.6 | 5 | 68 | 50 |
| 13~15분 | 0.5 | 6 | 72 | 60 |

스테이지 압력은 `1 + 0.055 × (스테이지-1)`. 회복/활성 제한은 늘리고 간격은 줄이되 전체72 제한과 특수 몬스터2칸을 유지한다. 일반 공세는 실제 비용을 지불한다. 단계별 구성은 기본 군단→고블린→광신도→구미호로 달라진다. 동일 맵 시간표 복제 대신 선택 스테이지의 원래 맵을 사용한다.

첫 엘리트60초, 이후90초/압력. 대형 오우거180/360/540/720/840초. 활성 제한에 걸리면 나중에 재시도한다. 시작 지휘력48. 엘리트/대형 경험치 배율은2/4(이전4/8). 특수 HP·피해도 경과시간/스테이지 압력을 반영한다. 기존 마왕 캠페인의 stage director 이벤트는 용사 모드에서만 중지해 시간표 중복을 막는다. 실제 빌드를4초마다 부분 관측하고55% 대응·나머지 순환 탐색을 유지한다.

몬스터 원본에 생존전용 소환시간 곡선을 적용한다. 첫30초 HP18%/피해45%/이속80%로 시작해15분 HP1000%/피해170%/이속120%까지 선형 보간하며 새 소환에만 적용한다. 기존 적은 소환시점 스냅샷을 유지한다. AI마왕의 소환레벨에 따른 몸체/EXP 강화와 무작위 대형화는 용사에서 대체하고, 예약된 엘리트/대형은 유지한다. [최신 곡선과 15분 성장 목표](HERO_SURVIVAL_REVISION_20261013.md).

## 화면 / 성능 / 저장

- 증강 선택은 화면 중앙 가로3카드. 무기60·보조8 도트 아틀라스와 캐시된AtlasTexture·nearest 필터를 사용한다. 이름/레벨/효과/현재슬롯을 표시하고 중복선택 지연 잠금/전투정지/대기 레벨업 경계를 유지한다.
- 상단 마왕 UI의 프레임을 재사용한 HP·EXP·분:초·레벨·처치·공세 단계·무기3칸·보조 표시. 무기를 누르면 정지하고 설명을 확인한다. 하단 정보 패널을 없애고 이동 패드만 전장 위에 표시한다.
- 무기 피격 조회는 기존 월드 레지스트리/공간그리드와 재사용 scratch 배열. 효과48칸·장판8칸·투사체64칸을 전투 시작에 확보하고 재사용한다. 무기 최대3개, 범위 피해 최대24표적. 새 전투 핫패스에 그룹 전체 스캔/매 프레임 Dictionary 생성/투사체 instantiate/free를 추가하지 않는다.
- 발사체는720px/s의 실제 표적 추적 이동 후 적중한다. 투사체속도 증가를 실제 적중시간에 적용하고 세대별 엔티티 핸들로 풀 재활성화 대상 오타격을 막는다. 장판/검격/즉시 연쇄에는 적용하지 않는다. 회전 수호체는 기존 즉시 범위타격이다.
- 15분에 맞춰 승리 연구100·골드60(이전 3분의5배), 30초/1처치 이상 실패 연구5·골드3 유지. 입장5·30초내 조기 복귀4 환급·실패 입장 환급·보상 receipt와 계정 소유 경계 유지. 새로운 서버/RPC/SQL 없음. 상자 룰렛은 기존 상자 효과음 재사용, 새 오디오 생성 없음.
