# 불가살 전투·컬렉션 연결

## 구현

`bulgasal_behavior_catalog.gd`가 수치·해금 조건·프레임 경로를 소유한다. 초월/짐승/근접 탱커, 이속270·공격 간격1.6초·게이지60. 증강이 적용된 전투 지휘력 자연회복을100% 받아 초당15까지 충전한다. 일반/특수증강, 엘리트/대형 전환은 제외한다. 제우스도 회복100%/15cap·이속290·공격 간격1.3초로 변경했다.

실제 인구를 차지하는 플레이어 탱커 소환65회와 아군 사망100회의 AND 조건. 기술/증강 생성체 사망도 포함하고, 같은 개체 사망 알림은 성장/해금 집계에 한 번만 반영한다. 전투 재시작은 카운터를 초기화한다. 공격력은130+소환 전 탱커 사망 수×0.6(최종 정수 반올림), 소환 시 고정하며 이후 사망으로 공격력은 증가하지 않는다. 실제 사망 이벤트에서 Catalog role=tank만 집계하며 중복 알림은 제외, 재시작 시 초기화. 상세정보도 소환 전 예상값/소환 후 고정값을 표시한다. 소환 시 HP1850+누적 사망 수; 이후 아군 사망마다 최대HP+1, 현재HP는 회복하지 않는다. 기본 초월 무료1회 소환·사망15개 EXP스톤/총300EXP를 재사용한다.

## 뽑기·등록·보상

pending/active 튜토리얼 상태가 확인된 신규 계정은 진행·스킵 모두 누적10번째 몬스터 소환을 불가살1회로 교체한다. 10+1회 뽑기의10번째 결과에 기존 초월 연출·최초 해금을 적용하며 확정은 계정당1회. 누적 횟수/대상/지급 완료는 기존 계정 snapshot의 stage_progress.cfg monster_gacha에 보상/골드와 원자적으로 저장. 재접속·재시도·중간 배치·저장 실패를 구분하며 기존 일반 completed/skipped 계정은 자동 신규 등록하지 않는다. tutorialtest는 격리 첫 계정으로 등록하며, 이전 패치에서10회를 넘겨 확정이 누락된 preview는 다음 몬스터 뽑기 첫 결과에서1회 보정한다. 해당 예외 외 초월 전체0.5%와 픽업3배 가중치는 그대로. 두 초월 기준 일반 제우스/불가살 각각0.25%, 제우스 픽업 제우스0.375%/불가살0.125%. 첫 당첨 해금·중복 조각·골드 차감은 기존 원자적 컬렉션 트랜잭션으로 처리한다. 불가살 아이콘/배너는 기존 ProfileCosmeticStore가 해금 상태로 소유권을 유도한다. 초월등록에 추가하며 일반 팀에서는 제외한다.

사용자 승인 원본 메시 리그를 `src/ui/bulgasal_portrait_rig.gd`로 승격해 개발 미리보기·실제 뽑기·전투가 공유한다. 뽑기는 기존5초 전신 대장간 연출, 복수 당첨 순서/스킵/결과 연결을 재사용한다. 연출은 보상/골드를 쓰지 않는다.

전투 컷신은 우측하단 대각선 삼각형 배경, 처음부터 어깨/목/얼굴 구도. 검은 실루엣0.25~1.3초 공개→눈감음→1.78~1.92초 개안/금빛 화염→2.25초부터 작은 이름. 전투 카메라/집중 조명/슬로우/5초 복귀와 초월 사망 연출은 기존 공용 컨트롤러를 사용한다. 취소·메뉴·증강·사망 시 원래 카메라와 speed복원.
