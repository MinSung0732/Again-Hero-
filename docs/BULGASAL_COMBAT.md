# 불가살 전투·컬렉션 연결

## 구현

`bulgasal_behavior_catalog.gd`가 수치·해금 조건·프레임 경로를 소유한다. 초월/짐승/근접 탱커, 이속270·공격 간격1.6초·게이지60. 증강이 적용된 전투 지휘력 자연회복을100% 받아 초당15까지 충전한다. 일반/특수증강, 엘리트/대형 전환은 제외한다. 제우스도 회복100%/15cap·이속290·공격 간격1.3초로 변경했다.

실제 인구를 차지하는 플레이어 탱커 소환65회와 아군 사망100회의 AND 조건. 기술/증강 생성체 사망도 포함하고, 같은 개체 사망 알림은 성장/해금 집계에 한 번만 반영한다. 전투 재시작은 카운터를 초기화한다. 소환 시 HP1850+누적 사망 수; 이후 아군 사망마다 최대HP+1, 현재HP는 회복하지 않는다. 기본 초월 무료1회 소환·사망15개 EXP스톤/총300EXP를 재사용한다.

- 등장: 수직 낙하0.55초, effect1 16~20 착지, 고정8슬롯 돌기둥 풀 생성.
- 돌기둥: effect4 1~5생성/6유지/7~21소멸, StaticBody 충돌 장식물. 몬스터 레지스트리/용사 타깃 목록에서 제외. 업로드 manifest의 공통anchor는 Catalog로 옮겨 APK의 JSON 포함 여부에 의존하지 않는다. 근접 파괴150%여진 또는 섭취 최대HP5%중첩 쉴드. 사망 시 피해 없이 모두 소멸.
- 바위던지기:15/20초. effect1 1~9뽑기 후 대기, 용사 위치 스냅샷·공격 애니메이션,870속도/10~15비행,400지름16~20폭발. 지름300/600 두 표시; 내측300%·기절2초, 외측175%·50%둔화2초 중 하나만. 투사체 선분으로8기둥만 검사하여 경로상의 기둥 파괴.
- 바위돌진:15/25초,7초 잠입·이속+50%·피해60%감소. body숨김/effect2 1~9수명별 표시. 도달 시10~18등장/135%/치유감소25%3초, 만료 시 복귀. 기절 중 도달 공격은 하지 않는다.
- 강철도약:20/20초,2초 공용 ChannelRuntime과 오른쪽 세로 게이지. 기절/침묵/강제이동 잠금 시 취소하되CD유지. effect3 1~7상승→1초 공중(몸체/상태바 숨김·무적·충돌off)→0.25초낙하(원래 충돌mask/상태 복원). 원래 자리 지름250표시,8~9착지450%·기절3초. 8갈래700거리/10~20진동파130%·30%둔화2초는 전체 파동에서1회만. 착지를 실제 맞은 용사에게만 같은 기술 후속타 API를 사용하여 직후 피격 무적으로 파동이 누락되지 않게 한다.
- 전략후퇴: 피해10회마다 반대 방향 후퇴→effect3 1~9→모든 기둥 여진 파괴/최대HP3%쉴드→소멸 완료 후 재생성. 흡수된 쉴드 피격도 횟수에 포함, 무적 중 거부된 피해는 제외.

## 미지정 값 / 교체 지점

기본 공격150, 기둥 최대8·반경26·상호작용105·여진 반경150, 파괴/섭취50:50, 후퇴240거리/0.9초, 진동파900속도, 바위 준비0.9초+대기0.4초는 **임시 밸런스 값**이다. 모두 BehaviorCatalog에서 조정한다. HP 사망 성장 해석은 위와 같이 최대HP만+1이다. 큰 팔/고개 동작·별도 Cubism 리그는 포함하지 않는다.

## 뽑기·등록·보상

초월 전체0.5%와 픽업3배 가중치는 그대로. 두 초월 기준 일반 제우스/불가살 각각0.25%, 제우스 픽업 제우스0.375%/불가살0.125%. 첫 당첨 해금·중복 조각·골드 차감은 기존 원자적 컬렉션 트랜잭션으로 처리한다. 불가살 아이콘/배너는 기존 ProfileCosmeticStore가 해금 상태로 소유권을 유도한다. 초월등록에 추가하며 일반 팀에서는 제외한다.

사용자 승인 원본 메시 리그를 `src/ui/bulgasal_portrait_rig.gd`로 승격해 개발 미리보기·실제 뽑기·전투가 공유한다. 뽑기는 기존5초 전신 대장간 연출, 복수 당첨 순서/스킵/결과 연결을 재사용한다. 연출은 보상/골드를 쓰지 않는다.

전투 컷신은 우측하단 대각선 삼각형 배경, 처음부터 어깨/목/얼굴 구도. 검은 실루엣0.25~1.3초 공개→눈감음→1.78~1.92초 개안/금빛 화염→2.25초부터 작은 이름. 전투 카메라/집중 조명/슬로우/5초 복귀와 초월 사망 연출은 기존 공용 컨트롤러를 사용한다. 취소·메뉴·증강·사망 시 원래 카메라와 speed복원.

눈감음 PNG는 원본971×1619를 참조한 생성 에셋이며, 셰이더가 visible eye 주변 타원(center311,385 / radii29,16)에서만 RGB를 섞는다. 나머지 원본 디자인/투명도/UV는 유지한다. 별도 눈/눈꺼풀 파츠를 받으면 이 샘플러를 교체하면 된다. 원본 픽셀과 발/얼굴 고정 가중치는 변경하지 않았다.

## 실행 검사 / 한계

Godot4.5.1 실제 엔진, 필요한 원본 리소스를 포함한 격리 프로젝트에서 다음을 실행:

- `tests/bulgasal_combat_smoke.gd`: AND 조건/리셋, 게이지/정지, 피해 영역, 스냅샷, 쉴드, 정신집중 취소, 공중 무적/원래 충돌복원,8갈래1회, 사망 기둥 무피해.
- `tests/bulgasal_integration_smoke.gd`: 실제 Collection/Shop/Profile/Loadout/Battle/Hero 코드,1000골드11회 원자적 보상, 초월3회 당첨/정상·스킵/보상 불변, 실제 소환 계수·사망 집계·불가살 actor와 Hero 피해/상태.
- `tests/bulgasal_presentation_smoke.gd`:3비율 우측하단/실루엣/개안/이름, 카메라·줌·슬로우 복원, 메뉴/증강/사망/직접 취소. Linux OpenGL(Mesa)에서 실제 PNG 렌더 확인.
- `tests/pickup_probability_smoke.gd`, `tests/zeus_combat_smoke.gd`: 확률100%합·기존 제우스 전투 회귀와 바뀐 수치.

전체 앱/Android 실기기/APK export와 고밀도 장시간 전투 성능은 미검증. 격리 fixture의 기존 UID/path fallback 경고와 일부 종료 시 리소스 경고는 전체 앱 clean run을 의미하지 않는다. 전투핫패스에는 전체그룹스캔·노드 생성/해제·매프레임배열을 추가하지 않았고, 기둥8슬롯/파동8방향/FX텍스처캐시를 재사용한다.
