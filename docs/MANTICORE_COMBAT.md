# 만티코어 전투·획득 연결

## 등록·수치

`MonsterCatalog`의 초월/짐승/폭발형 `manticore`, `Manticore.tscn` 및 데이터 `manticore_behavior_catalog.gd`가 실제 뽑기 풀·도감·초월 편성·전투 소환에 연결된다. 초월 등급 확률 0.5%는 유지되며 등급 내 기존 균등 추첨에 포함된다. 최초 획득 아이콘/기본 배너, 실제 5초월 달성 별도 배너는 기존 컬렉션 소유·레벨로 판정한다. 신규 저장 플래그나 중복 지급 없음.

전투 중 용사에게 실제로 입힌 누적 HP 피해 400으로 전투당 1회 무료 해금. 다른 초월과 동일하게 소환 직전 피해 D를 스냅샷으로 고정한다. 각 타격 공격력 `round(35+D×0.15/2)`, 체력 `round(1550+D×0.5)`. 게이지100, 증강 적용 지휘력 회복100%, 초당 최대15. 일반/특수증강·엘리트·대형몹 제외.

## 공격과 기술

- **사냥/추적**: 기본 사거리 지름650=반지름325. 1초 정신집중 오른쪽 게이지 → 속도580 유도 돌진 → 0.12초 간격2연격 → 성공 시325 후퇴. 사냥은 attack01~03, 추적은04~06 및 effect4, 이동 방향을 바라본다. 돌진/후퇴는 충돌을 무시하고 공간 스냅샷 무효화. 후퇴 목적지는 공격 완료 때 고정하고 직선으로 이동한다. 후퇴 종료 후1.5초 동안 제자리에서 대기한 뒤 사거리 접근/다음 사냥을 시작한다. 종료 후1.5초 간격 적용, 정신집중 기절/침묵 취소. 전장 밖 목적지는 기존 경계로 제한.
- **재앙의 불꽃**: 50/60초, 30초 동안 좌우에 원본 머리1개. 실제 전방 불꽃 영역(최대125, 입 앞25부터 폭14+거리×0.28)에 접촉한 적에게1초100%. 연속1초 접촉마다1초 총75% 갱신 화상. effect1의02~05 공격/06~08 중지. 화상은 DOT와 공격 피해×0.5를 적용하며 기본 공격력 값을 직접 변경하지 않는다. T1 머리2개, T4 비용25/기본 지름+50(반지름+25), 파동 이동+50.
- **맹독유성**: 35/35초, 대상 위치를 고정한 지름600 안 균등 원판 무작위10발을2초에 걸쳐 발사. 속도580, 도착 전 지름175 얇은 예고선. effect2의01~02 투사체/03~08 폭발. 폭발175%, 같은 만티코어 출처·채널의3초 총200% 중독은 중첩·갱신 없음.2초 독구름은 계속 안에 있으면 초당 현재HP3%(총6% 시간 비율)를 감소시킨다. 현재HP는 매 틱 갱신하므로 시작HP의 정확히6% 고정 피해는 아니다. 기존 전갈 독구름 사용.
- **지각분쇄**: 30/30초, 5초 파동 모드. 명시된 기술 이동 거리680을 기본 지름650과 구분한다. 속도450, 원본 effect3의01~04가 직선으로 이어짐. 끝에 도달하면 시작점부터05~08 소멸. 각 파동은 swept segment 판정으로 대상당1회200%/3초30%둔화. T5 속도500/7.5초/공속×1.5, 공격 후 대상 중심 최대 파동 거리로 무작위 도약.
- **살을 찢는 공포**: 기본 타격5회(2연격 포함)마다10초 총 최대HP3% 출혈, 기본 갱신/중첩 없음. 출혈 대상3타는50%, 3연격 모두 성공하면 최대HP4% 쉴드 중첩. 첫 치명상은 죽음 직전HP0 기준 잃은HP15% 회복 및2배 후퇴; 두 번째 치명상은 정상 사망. T2 조건4회/출혈 갱신, T3 회복 뒤5초40%피감/20%쉴드.

등장 effect2의03~08 연기에서 본체 공개. 등장 폭발 범위는 미지정이므로 같은 연기 기술의 지름175를 사용하며135% 피해는 적과 아군 모두, 본인 제외. 아군은 기존 공간그리드로 한 번 조회한다. 주 대상은 기존 초월 관례대로 용사이며, 광역 기술은0.25초 간격 활성 용사 소환체 레지스트리 캐시에도 적용한다. 비활성 풀 전체를 훑지 않는다.

## 연출·성능

실제 소환 성공 신호 이후 기존 `BattleSummonCinematic`을 사용한다. 우하단 삼각형 컷인, 전신 원색→눈감음/얼굴 확대→눈뜸/독폭발→전신 복귀/이름, 5초 실제 시간. 전투 카메라·슬로우·스포트라이트 복원과 독 광륜/3중 연기 고유 월드 효과를 연결한다. 뽑기는 기존 강화 네이티브 Live2D 방식 리그/독기 셰이더를 유지한다. Cubism 모델은 아니다. 월드 연출은 피해를 추가하지 않는다. 사망은 기존 공통2.8초 카메라 연출/15스톤 총300EXP를 사용한다.

유성/구름10슬롯, 파동12슬롯, 머리2슬롯, 텍스처팩 캐시. 매 프레임 배열 생성·그룹 조회·전투 장면 instantiate/free 없음. 용사 소환체용 화상/중독/둔화 컴포넌트는 최초 적중 때1회 생성하여 풀 재사용 시 초기화한다. 보조 적별 접촉 누적/파동 비트마스크를 재사용한다. 이미 Pixabay 출처가 기록된 불가살 진동/암석 SFX를 재사용하며 런타임 Base64 디코딩 없음.

F6: `src/dev/ManticoreBattleSummonPreview.tscn`, `src/dev/manticore_cutscene_preview.tscn`. 두 예시는 실제 보상이나 전투 진행 저장을 호출하지 않는다.

## 검증

Godot4.5.1 헤드리스의 `tests/manticore_combat_smoke.gd`, `tests/manticore_integration_smoke.gd`, `tests/manticore_battle_summon_smoke.gd`, 격리 `tests/run_manticore_cutscene_smoke.py`를 실행한다. 실제 획득/5단계 강화/배너·실제 Battle 피해 신호/무료 소환/죽음15스톤·Hero 화상·Scout 광역/풀 초기화, 모든 기술과5초월 수치, 컷인 신호/카메라/속도/중단/재사용/화면비율 및 기존 뽑기 순서를 검사한다. 제우스·불가살·이자나미 전투 및 인구/소환사 회귀 검사도 실행한다.

실제 GPU 화면·Android 터치/청취·프로파일링·export는 미검증. 전체 프로젝트 기존 일부 리소스의 이미지 fallback 경고 및 기존 컷인/소환사 테스트의 종료 시 리소스 잔존 경고는 별도 제한사항이다.

## 사냥 접촉/불꽃 가독성 보완 (2026-10-09)

사냥 시작 시 실제 CircleShape2D 반지름 합을 캐시한다(기본 만티코어16+용사28=44). 직전 용사 위치를 유지하며 양측 상대 이동 경로의 접촉을 검사하고 접촉 즉시 연격 상태로 전환한다. 중심16까지 파고들어야 했던 좁은 판정을 제거한다. 돌진/후퇴 시 collision_layer/mask를 모두0으로 하여 용사 쪽 충돌도 무시하고, 종료 시 기존 설정을 복원한다. 유도 속도580·2연격/출혈3타·후퇴/대기·용사 회피AI는 유지한다.
