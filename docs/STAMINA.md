# 스테미너 v1

## 규칙
- 최초/기존 미저장 계정 모두 30에서 시작. 기존 진행도·골드·연구는 유지.
- 일반 던전 입장, 일시정지 재시작, 결과 재도전, 다음 스테이지마다 5 소모.
- 활성 순차 튜토리얼 연습과 localtest는 차감 면제. tutorialtest 완료 후 일반 전투는 정상 차감.
- 자연회복은 6분당 1 (1시간당 10), 최대 30. 앱 종료/백그라운드 시간도 저장된 Unix 시각으로 한 번에 계산. 부분 경과시간은 입장/소량 지급 뒤에도 유지.
- 30 이상에서는 자연회복 정지. 30 미만으로 떨어지는 순간 새 6분 타이머 시작. 가득 차 있던 시간을 이후 회복으로 비축하지 않음.
- 선물/구매 지급은 상한을 넘겨 보유 가능. 초과분도 정상 차감. `StaminaStore.grant(amount, stable_source_id)`를 검증 완료된 보상/구매의 지급 단계에서 호출. 같은 ID는 재지급하지 않음.

## 저장과 입장
- balance rules: `src/data/stamina_catalog.gd`; wallet: `src/systems/stamina_store.gd`.
- `stage_progress.cfg`의 `[stamina]`: version/amount/recovery_at/entry_serial. `[stamina_grants]`에는 처리 완료 지급 ID를 저장.
- 새 파일/서버 테이블을 추가하지 않고 기존 AccountSaveScope/클라우드 snapshot에 포함. 계정 bundle과 guest write-ahead journal 경로를 그대로 사용.
- 입장 stage ID와 차감은 하나의 트랜잭션. 저장 실패/잔액 부족에는 진행하지 않음. UI 진입 pending guard로 중복 탭 차단.
- 즉시 실패한 scene 전환/reload는 입장 ID별 한 번 환불. 공통 SceneTransition이 수락한 로딩은 기존 재시도 화면에서 같은 요청을 재사용하고 추가 차감 없음. 수락 이후 앱을 강제 종료한 입장은 소비 처리되며 이어 하기/환불은 별도 정책 없음.
- 실제 전투 시작(입장/용사 연출 완료) 후 **30초 이내(30000ms 포함)** 로비 복귀 시 4를 1회 반환. 일시정지/백그라운드 시간도 monotonic/wall 경과 중 큰 값으로 포함(시각 후퇴로 늘리지 않고 Android deep sleep도 포함). 결과창의 로비 복귀도 같은 조건 적용. 30초 초과/앱 종료/재도전·다음 스테이지 버튼에는 이 부분 반환 없음. Godot에서 Main 씬을 직접 F6 실행하는 개발 경로는 비용 진입 UI를 거치지 않음.
- 표시용 원본 값 캐시를 계정/guest 경로·snapshot revision·write serial 변경 시 무효화. 입장/지급은 최신 ConfigFile을 다시 읽고 저장. UI는 1초 Timer로 산술·문자 표시만 갱신하며 매 프레임 파일 읽기/그룹 탐색 없음.
- 현재 시각은 기기 Unix clock. 뒤로 변경해도 추가 회복을 주지 않지만 서버 권위의 시각/영수증 검증·시간 조작 방지는 아직 없음. 실제 유료 지급 전에 서버 보상 ledger와 검증 API를 연결해야 함.

## UI / 에셋
- `lobby_stamina_view.gd`가 244px 높이의 로고·재화 두 줄 헤더에 로고 / 골드 / 스테미너 / 기존 최고 해금(상점에서는 기존 연구 표시)을 독립 영역에 배치.
- 스테미너 숫자/번개 아이콘: 현재량·입장 비용·다음 1 회복·30까지 충전 완료 시간 안내 카드. 충분하면 자연회복 정지 안내.
- 옆 +와 안내의 충전 상품 보기: 상점의 전용 스테미너 영역으로 이동/스크롤. 상품 가격·재화·결제 정책이 미정이므로 구매 준비 중 비활성 버튼. 가짜 결제/임의 가격·무료 지급 없음.
- 입장 버튼: `던전 입장` + 번개 아이콘/`-5`를 한 행으로 중앙 정렬. 무료 연습은 무료 표시. 실제 차감 성공 후 기존 Label/Tween으로 0.45초 상승/페이드, 입력 차단과 pending guard 후 로딩. 소모가 없는 연습/잔액 부족에는 음수 연출 없음.
- `commerce_v2`의 전용 PNG 프레임/원본 SVG는 균일한 레일과 고정 모서리만 nine-patch로 늘림. 헤더/상점 섹션/상품/CTA에 적용, 패키지 2열 및 내용 여백 확대. SOURCE.md에 규격 기록.
- 번개: `assets/art/UI/lobby_header/stamina.svg`, 기존 HUD 색상으로 작성한 crisp pixel vector. 금/보라 프레임은 새 commerce PNG 캐시 재사용. 새 캐릭터 아트 없음.
- 튜토리얼의 대상 차단/레이어 우선권 유지. 충분하지 않은 전투 재시작은 확인창으로 안내하고 로비 +로 연결 설명.

## 검증
- 29999/30000/30001ms 반환 경계, claim/반환 1회·무료/이전 입장 제외, 실제 Main 로비 복귀 및 차감 애니메이션/중복 터치 검사.
- `tests/stamina_smoke.gd`: 신규/기존 기본값, 359/360 경계, 1시간 10 회복, 여러 시간/장기 오프라인, 부분 시간 보존, 자연 한도/overflow 전환, 기기 시각 후퇴, 정확한 비용/부족, 면제, 선물·구매 ID 재시도, 1회 환불, 저장 실패, 다른 재화/클리어 보존, 계정 격리와 snapshot 설치 후 갱신.
- 신규 paid entry ticket은 Main 준비 시 한 번만 claim. early exit/full loading failure는 같은 입장 환불 receipt를 사용해 혼합/중복 반환 차단. 계정 변경·다음 입장·debug reload에 오래된 ticket 적용 불가.
- 실제 Lobby 헤더 영역·안내 카운트다운·+ 상점 스크롤·가격 미정 차단, double-tap 입장 1회 차감/실패 복원, Main 재도전/다음 스테이지 부족 차단.
- Godot 4.5.1 headless 실행 및 기존 튜토리얼/키보드 회귀. 부분 리소스 체크아웃의 기존 missing portrait 경고와 종료 잔류 리소스 로그가 있음. 실제 Android 터치/화면 렌더·사람 계정 다중기기/클라우드 호출·유료 구매는 미검증.
