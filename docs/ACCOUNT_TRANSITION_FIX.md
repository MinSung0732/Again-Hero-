# 계정 전환·로컬 테스트 진행도 보존 (2026-10-12)

## 확인한 원인과 변경

기존 `normaltest`는 로컬 테스트를 종료하면서 일반 게스트 진행도를 지우고, 테스트 시작 전 로그인 계정 ID를 `pending_reset_id`에 남겼다. 다음 OAuth 검증에서 그 계정의 진행도를 초기화한 뒤 `initialize("local")`로 클라우드에 업로드했다. 따라서 테스트에서 일반 계정으로 돌아오는 동작으로 실제 저장이 초기화될 수 있었다. 별도로 OAuth 성공 경로는 `LocalTestMode.active`를 종료하지 않아 계정 로그인 후에도 테스트 권한/표시가 남을 수 있었다. 사용자의 모든 클릭 순서나 기존 진행 수치는 확인할 수 없으므로 해당 초기화 경로가 이번 0골드 저장의 유일한 원인이라고 단정하지 않는다.

- `normaltest`는 기존 일반 저장으로 복귀한다. 정상 계정에서 일반 진행도를 초기화하지 않는다. 테스트/첫 가입 미리보기의 새 파일 초기화만 유지한다.
- 명시적 OAuth 시작·검증과 클라우드 재시도에서 테스트 종료를 저장하고, 옛 초기화 예약은 실행하지 않고 제거한다. 저장 실패 시 테스트 상태/저장 경로를 보존하고 계정 수락을 거부한다.
- 클라우드 요청·초기화·업로드는 로그인 계정 ID와 저장 소유자가 같고 테스트/미리보기가 아닌 경우만 허용한다. 다른 계정/게스트로 전환된 뒤 돌아온 응답도 적용하지 않는다. 같은 계정의 정상 오프라인 변경·버전 충돌 처리·명시적 서버/기기 저장 선택은 유지한다.
- 게스트 전환은 비동기 인증정보 삭제 전에 기존 로그인과 요청을 무효화한다. 이전 게스트 요청 완료가 새 로그인 상태를 지우지 않으며, 새 인증정보 저장은 이전 삭제 완료를 기다린다.

## 서버 확인과 복구 범위

배포된 탈퇴 함수는 계정을 비활성화하고 인증 세션을 취소한 뒤 720시간(30일) 보관한다. 10분 주기로 만료 계정을 완전 삭제한다. 보관 중 동일 OAuth ID 로그인/재가입은 차단된다. 이 패치에서는 탈퇴 정책·계정 차단·서버 데이터를 변경하지 않았다.

읽기 전용 확인에서 Google 계정 최신 스냅샷은 0골드/최대1스테이지였다. 별도의 과거 스냅샷/백업 이력 테이블은 발견되지 않았으며 기존 legacy 진행도도 1스테이지/연구0이었다. 이전 수치를 임의로 생성하거나 계정을 복구하지 않았다. 이것만으로 플랫폼 전체 백업/PITR 존재 여부까지 판단할 수는 없다.

기기의 `user://accounts/<UUID>/save_bundle.json.before_cloud.bak`와 `save_bundle.json`을 별도 복사하여 변경 없이 검사해야 로컬 복구 가능성을 판단할 수 있다. 이 백업은 단일 파일이므로 과거 진행도를 포함한다고 보장하지 않는다. 앱/기기의 로컬 파일은 이번 환경에서 읽을 수 없었다. 테스트용99999 재화는 정상 계정의 복구 근거가 아니다.

- Godot4.5.1 격리 fixture의 실제 LoginGateway/CloudStore/LocalTestMode/AccountSaveScope 및 fake OAuth/vault/RPC로 `tests/account_transition_smoke.gd` 33검사 PASS. 서로 다른 계정/게스트의 재화 보존, 테스트 종료·직접 OAuth, 옛 초기화 예약, 저장 실패, 미리보기, 지연 응답과 인증정보 삭제 경합 포함.
- `tests/cloud_save_smoke.gd` PASS: 오프라인 보존, 버전 충돌, 명시적 서버 복원, 잘못된 사용자/페이로드 거부. Linux에서 Windows DPAPI 실호출은 제외.
- 변경한 `tests/progression_coupon_smoke.gd`의 실제 계정 테스트 구간 추출 회귀 PASS:500골드/최대3스테이지 계정이 localtest/normaltest/재로그인 후 그대로 유지되고 초기화 업로드0회. 전체 로비 화면 구간은 미실행.
- 변경7 GDScript 구문 및 `git diff --check` 통과. 서버 SQL은 조회만 수행. 실제 Google/카카오 OAuth·Windows/Android 단말·전체 Startup/Lobby UI 및 데이터 복구는 미검증.
