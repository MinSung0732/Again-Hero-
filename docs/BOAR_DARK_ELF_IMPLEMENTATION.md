# 멧돼지·흑요정 궁수

## 멧돼지

일반/짐승/폭발/근접. 비용8, 원본HP120/공격74/이속175/공격간격1.4/사거리반경275(지름550). 기존 등급·연구·강화·마왕레벨 배율을 소환 경로에서 적용한다.

사거리 내 목표를 향해0.3초 정신집중하고 방향을 고정한 채 직선 최대900을 이동한다. 시작50, 초당375 가속하여 기본1초에425 도달. 종료 후 공격간격을 적용한다. 접근 중 목표를 추적하지만 집중 시작 후에는 유도하지 않는다. 이동 선분으로 선택 대상을 확인하고 충돌한 용사/용사소환수도 맞출 수 있으나, 돌진 한 번의 피해 시도는 한 번뿐이다. 몸체/벽 충돌 시 종료한다. 기절·강제이동 잠금은 돌진을 취소하고, 침묵은 집중/엘리트 연결을 차단한다. 둔화·속박 배율도 이동에 반영한다.

| 증강 | 효과 |
|---|---|
| 분쇄의 엄니 | 공격력30% 증가 |
| 본능의 돌격 | 정신집중 삭제 |
| 세 번째 격노 | 3번째/6번째/9번째... 실제 출발한 돌진의 시작속도200, 최대425 유지 |

저돌맹진 선쿨3초/CD20초,10초 지속. 사용자가 적은 “그 후 공격속도 적용”에 따라 일반 돌진 종료→집중/대기 없이 추가 돌진1회→정상 공격간격으로 구현한다. 지속 중 각 일반 돌진 뒤 다시 추가1회가 가능하다. 추가 돌진이 끝없이 재귀 연결되지는 않는다. 지속 종료 후 이미 시작한 돌진은 끝까지 진행한다.

밸런스 몸체지분1.5/화력지분0.9. 평상시 돌진900 이동2.559초+정신집중0.3초를 `cycle_extra_seconds=2.8588235294`로 포함했다. 접근 실패/이동 목표 회피, 즉시 돌진/세 번째 가속/엘리트 추가돌진은 별도 기여다. 체력·공격은 감사에서 원본120/74로 정규화된다.

## 흑요정 궁수

고급/인간형/원거리. 비용12, 원본HP97/공격30/이속180/간격1.4/사거리반경375(지름750)/화살속도280.

공격 후 최대85 거리의 안전한 위치로 기본 이동속도2배로 이동한다. 적과 거리를 벌리는 자리를 우선하고 사거리 끝에서는 측면으로 이동한다. 사거리/전장 경계 안에 목표를 잡으며 벽에 부딪히면 종료한다. 순간이동은 하지 않는다.

3초 동안 피격 없이 준비하면 은신에 들어가 도트만 불투명도40%로 표시한다. 상태바/충돌/표적 가능 여부는 유지한다. 은신 상태 피해50% 감소, 첫 일반 사격150% 후 즉시 해제. 사격 후 준비시간을0으로 되돌려3초 후 재진입하며, 피격은 준비시간을 초기화한다. 이미 은신이면 피격 직후에도 다음 사격까지 은신/피감을 유지한다. 이 해석은 무피격 조건으로 매프레임 재진입하여 쉴드가 생기는 현상을 막는다.

| 증강 | 효과 |
|---|---|
| 어둠을 꿰뚫는 눈 | 사거리50% 증가: 지름1125, 화살 이동거리562.5 |
| 그림자 징집 | 생산비용25% 감소: 다른 비용 배율 전12→9 |
| 그림자 장막 | 은신 진입 때 최대체력10% 원거리쉴드, 기존잔여량과 비교하여 갱신 |

4연사 선쿨2초/CD15초. 공격력125% 화살4발, 첫발즉시/다음0.18초 간격. 각 사격은 현재 목표 위치를 향해 발사하고 공격 후 이동한다. 은신150%와 중복하지 않는다. 기존 Hero `take_followup_damage` 경로로 피격 무적을 무시하지만 피해감소/쉴드는 유지한다. 발사 전 기절/침묵/강제이동 잠금, 사거리 이탈/목표 사망은 남은 연사를 취소한다. 이미 발사한 화살은 계속 진행한다.

밸런스 몸체지분0.55/화력지분0.8. 은신피감/첫발 강화/후퇴/엘리트 연사 기여와 확장된 사거리의 안전성 및 느린 화살의 회피 여지을 검토했다. 승률을 자동 보장하지 않는다.

## 에셋·공통 연결

몬스터 카탈로그 ORDER/기본값/씬/설명/증강/엘리트와 증강 이름 등록으로 일반/고급 뽑기·보유·편성에 자동 포함한다. Battle 개별 ID 분기는 추가하지 않는다. 엘리트는 기존 `runtime=monster`/`try_cast_elite_skill`에서 선쿨/CD를 관리한다. 둘 모두 통합 상태바를 사용하며 사용하지 않는 노란게이지를 만들지 않는다.

기존 PNG94 캐릭터프레임,12화살/적중프레임을 사용한다. 멧돼지 일반/엘리트 idle4/move6/attack6/hit3/death4, 흑요정 일반 attack7/death5와 엘리트 attack6/death4를 각각 연결한다. 화살은 일반 흑요정의 effect1/projectile6/impact6을 양쪽에서 공유한다. 멧돼지 일반/엘리트 표시높이157.3/181.5(기존130/150의121%), 흑요정165.2/188.8(기존140/160의118%), 화살/적중 프로필높이39.24(기존36의109%). 원본 PNG/충돌 수정 없음, nearest 균일 스케일 적용. 런타임 Base64 없이 PNG 리소스를 참조한다.

화살은 기존 Battle 풀을 사용한다. 중복 적중을 차단하고, 수명revision으로 예전 애니메이션의 지연 반환이 재사용한 화살을 끄지 못하게 한다. 선택 목표의 선분 교차를 확인하여 프레임 이동 사이 접촉을 놓치지 않는다. 재사용 시 source/목표/무적무시/active/impact/거리/그룹/모니터링을 초기화한다. 새 전체 그룹 스캔/매프레임 임시배열은 없다.
