## 무기의 구분과 기존 기술 활용

캐릭터별 6종/전체 60종 ID, 무기 3칸·보조 6칸, Lv.10 상자 진화를 유지한다. 이름/수치/원형 기술/연출 경로/연격·장전·상태 효과는 `hero_weapon_catalog.gd`에 둔다. 기존 기술을 생존용 무기로 재해석하며 원본 게이지·AI 자동이동·전체 기술 트리를 그대로 활성화하지 않는다.

| 용사 | 구별되는 전투 방식 / 활용한 기존 기술 |
|---|---|
| 견습 | 마력탄, 실제 마력 관통포, 따라오는 비전 집중, 마력 장벽 |
| 날렵 | 단일 표적 시간차 찌르기, 난도질 검무, 급습-암살 연격/10% 마무리 |
| 검방 | 다수 전방 검격, 관통 창격, 막기 보호막/둔화 충격파 |
| 권총 | 3발 속사·6발 장전, 데드아이 집중 속사, 실린더 스트라이크, 도탄 |
| 대마법 | 연소·아이스볼트·체인대거·땅의 가시·폭풍·신성력의 서로 다른 지속/범위/연쇄 |
| 광기 | 혈검술 연격·혈흔 흡혈·현재 HP 소모 혈폭, 낮은 체력에서 화력 상승 |
| 화학 | 빠른 산성 피해, 넓고 긴 촉매 혼합장/둔화, 따라오는 독 가스, 비약 |
| 이계 | 실제 투견·정찰병·감시자·문지기 소환, 총 3체 제한/14초 스냅샷 |
| 정화 | 구체 궤도, 신성보호, 독/화상/둔화 정화, 궁그닐 관통 |
| 대현자 | 별빛 탄, 실제 스타라이트 운석·빙점폭발 기둥·소멸 영역/끌어당김/마무리 |

마력 관통포·운석·기둥·소멸 및 이계 소환수는 원본 씬의 판정/연출/기존 오디오를 재사용한다. 다른 무기도 각 용사의 기존 기술 PNG 시퀀스를 설치 시 캐시한다. 새 캐릭터 아트/오디오는 추가하지 않았다. 마왕의 원본 기술 파라미터는 변경하지 않았다.

64발 고정 발사체 풀·세대 핸들에 지연 발사/근접 연격을 연결한다. 근접 후속타는 표적 생명·현재 사거리·침묵을 확인한다. 효과 48/장판 8을 유지하고, 원본 기술 배우는 시작 시 패턴당 2~6개를 준비해 포화 시 생략한다. 소환수는 기존 레지스트리/공간 조회/시작 풀을 재사용하고 레벨업으로 추가 풀을 늘리지 않는다. 새 전체 그룹 탐색이나 매 프레임 파일 로딩을 추가하지 않는다.

얼음 기둥의 deferred monitoring 직후 첫 physics_frame에서 겹침 목록이 비어 첫 피해가 빠질 수 있던 문제를 두 번째 physics_frame에서 검사하도록 수정했다. 재사용 revision을 확인해 이전 생명의 대기 콜백을 무효화한다. 용사 모드의 원본 기술 배우/기둥 애니메이션도 기존 Battle 일시정지 전환에 연결했다.

## 성장 수치 전후

`n = 현재 레벨 - 1`, 다음 레벨 요구 EXP는 `round(60 + 18n + 1.6n²)`이다. 이전 `round(20 + 10n + 0.5n²)`를 대체한다. 첫 요구량 20→60, Lv.10 151→352, Lv.30 731→1928. Lv.30 누적 21,390 / Lv.40 누적 46,108 EXP. 획득 25%·소수 누적·선택 큐는 유지한다. EXP 보조는 레벨당 +8%→+3%, 최대 +80%→+30%로 줄여 경험치 보조로 목표 구간을 크게 벗어나지 않게 한다. 레벨 상한을 강제하지 않는다.

| 소환 시간 | HP 이전→이후 | 피해 이전→이후 | 이속 이전→이후 |
|---|---:|---:|---:|
| 0~30초 | 0.18→0.18 | 0.45→0.45 | 0.80→0.80 |
| 2분 | 0.50→0.85 | 0.65→0.65 | 0.85→0.90 |
| 5분 | 1.10→2.80 | 0.95→0.95 | 0.95→1.00 |
| 10분 | 2.10→6.00 | 1.25→1.30 | 1.05→1.10 |
| 15분 | 3.20→10.00 | 1.60→1.70 | 1.15→1.20 |

소환 시점 스냅샷/선형 보간·기존 적의 상처/엘리트 재계산을 유지한다. Stage1 첫 슬라임13/거미14/오크47과 26 피해 1/1/2타 처치 유지. 15분 일반 HP는 슬라임720/거미800/오크2600. 원본 HP를 구분한 값이며 엘리트/대형/증강은 별도다. 물량·지휘력 재생·72개체 상한을 추가 확대하지 않는다.

`tools/hero_survival_budget.gd`는 실제 Catalog 비용/EXP, 5단계 공세/지휘력, 55% area 대응·고정 시드로 900초 공급을 계산한다. 모든 일반 소환을 처치한다고 가정하고 인구 포화·전투 피해/이동·마왕 증강·특수 보상을 생략한 **공급 모델**이다. 70/85/100% 수집률에서 예상 레벨은 Stage1 31/34/36, Stage4 32/34/36, Stage7 34/37/39, Stage10 36/38/41. 최대 EXP 보조와 100% 수집 가정은 39~45이므로 30~40을 절대 보장하거나 상한으로 주장하지 않는다. 실제 처치·이동·상자 습득·빌드별 15분 완주 밸런스는 추가 플레이 확인이 필요하다.

## 스테이지와 저장

용사 전장은 Stage1부터 시작하고 순서대로 15분 생존 승리 시 다음 단계가 열린다. 기존 마왕 UI처럼 해금 단계+2까지만 미리보기한다. 로비 선택 저장·입장 함수·HeroMode 직접 진입·보상 정산 모두 잠긴 단계를 차단한다. 승리 횟수와 보상은 기존 두 cfg의 단일 트랜잭션에 저장한다. 실패/중도 종료/중복 영수증은 단계를 열지 않는다.

기존 `hero_progress.stage_N_wins`의 연속 클리어만 인정한다. 과거 자유 선택으로 저장한 Stage10은 해금 근거가 아니며 잠겼다면 Stage1을 선택한다. 마왕 캠페인 진행과 용사 캐릭터 해금/컬렉션은 별도 유지한다. 정상 승리 결과에는 다음 단계 도전 버튼을 제공하고 스테미너·전환 실패 시 기존 재도전 대상을 보존한다. 서버/클라우드 저장 스키마는 변경하지 않았다.

## 설정

마왕 Main의 원본 설정 패널을 `src/ui/BattleSettings.tscn`으로 분리해 두 전투 모드에서 함께 사용한다. 배경음/효과음 1~10·각 음소거·게임플레이 시야 고정/전투 프레임·뒤로가기를 제공한다. 일시정지는 계속/다시 시작/설정/로비 메뉴 및 현재 전투 정보를 제공한다.

용사에서는 시야 고정 체크가 켜진 채 비활성화된다. 로비의 기존 게임/소리/알림/계정/기타 메뉴도 유지하며 용사 모드일 때 시야 고정만 같은 제약을 적용한다. 마왕의 카메라 저장 값을 덮어쓰지 않는다. 프레임 표시는 실제 전장 좌우 성벽과 폭에 적용하며 오디오는 기존 AudioSettings와 BGMManager에 즉시 반영한다.
