## 1. 플레이 경험·난이도 철학

**쉬움은 영웅의 능력을 배우는 난이도. 어려움은 영웅의 강점과 고유 약점을 읽어 몬스터 운용으로 이기는 난이도.**

각성은 단순한 스탯 배율이 아니라 시각적으로 식별되는 강화 패턴을 제공한다. 대신 모든 영웅은 다음 두 통로로 공략 가능해야 한다.

1. **자연 약점:** 기술 사용 직후 반드시 드러나는 빈틈. 특정 희귀 몬스터가 없어도 노릴 수 있다.
2. **심화 카운터:** 방향 유도, 진형, 둔화, 후방 공격, 치유 감소 등 몬스터 편성으로 자연 약점을 더 확실하게 활용한다.

**성장 기대치:**
- **Stage 1~5:** 연구 **또는** 몬스터 강화 중 한 분야에 어느 정도 투자했으면, 고생하거나 패턴을 활용해 클리어할 수 있는 수준. 양쪽 모두 성장하면 비교적 수월. 유물 불필요.
- **Stage 6~10:** 연구·몬스터 강화·향후 유물을 어느 정도 갖추면 수월하고, 성장 부족 시 세밀한 몬스터 운용과 약점 공략으로 겨우 이길 수 있는 수준. **유물이 아직 없더라도** 실력으로 승리할 가능성은 남긴다.
- 실제 성공 확률, 필요한 강화 레벨, DPS 목표는 플레이 테스트 전까지 **미확정**. 무조건 클리어 불가능한 성장 장벽·희귀종 필수 조합은 피한다.

| 성장 상태 | Stage 1~5 목표 | Stage 6~10 목표 |
|---|---|---|
| 연구·강화 거의 없음 | 상당히 어려움 | 극한 도전 |
| 연구 또는 강화 중간 | 비틀며 클리어 가능 | 숙련자급 극한 도전 |
| 연구·강화 모두 충분 | 비교적 수월 | 어려우나 공략 가능 |
| 연구·강화 충분 + 유물 중간(추후) | 수월 | 수월 |
| 모든 성장 높음 | 매우 수월 | 안정적 클리어 |

## 2. 공통 전투 규칙

### 2.1 영웅 스탯

| 항목 | 어려움 배율 | 비고 |
|---|---:|---|
| 최대 체력 | **×1.88** | 기존 Stage/프로필 기본값에 단 한 번 적용 |
| 공격력 | **×1.88** | 레벨 성장의 기준 공격력도 일관되게 처리 |
| 이동속도 | **×1.10** | 각성 중 별도 이동 감소는 곱연산 |
| 일반 공격속도 | **×1.10** | 일반 공격 간격 ÷1.10, 기술 쿨타임은 별도 |
| HP 지속 재생량 | **×1.10** | 기존 주기적 HP 회복만. 없는 자연 재생을 신설하지 않음 |
| 기술 쿨타임·사거리 | 기본값 | 각성 패턴 자체의 예외만 별도 설계 |
| 기존 증강 | 원본 유지 | 각성 약점에 의해 삭제·초기화하지 않음 |

재생력은 주기적 HP 회복에 적용한다. 즉시 회복·체력 아이템·흡혈·보호막·가스·마력 게이지 재생은 일괄 배율 대상이 아니다. 현재 Stage 1·2의 공통 어려움 재생 배율은 설정되지만, 각 기술의 실제 회복 처리에 통합되는지는 별도 검증한다.

옛 어려움 배율(HP 1.6·공격 1.35·이속 1.08)은 **새 배율에 중복해서 곱하지 않는다**. 각성 때 HP를 전부 회복하거나 ×1.88을 다시 곱하지 않는다.

### 2.2 입장·컷신

- 해당 스테이지의 **마왕 모드 쉬움 클리어** 이후에만 그 스테이지의 어려움을 선택할 수 있다.
- 로비에서 **stage_id와 difficulty를 함께 전달**한다. 전달 실패를 쉬움 입장으로 대체하지 않고 실패 안내·스태미너 환불.
- 어려움 입장 시 이미 쉬움에서 본 **시작 대화 컷신은 자동 생략**. 영웅 등장 연출은 유지한다.
- Stage 1~6은 **최초 체력 50% 이하 도달** 시 기존 영웅 컷신으로 전투 중 각성. 사망 전 유효한 최초 임계값에서만, 전투당 1회.
- Stage 7~10은 **기존 고유 기술 해금 이벤트**를 조기 활성화하고 해당 해금 컷신을 재사용한다. 이 구간에 HP 50% 중복 컷신을 추가하지 않는다.
- 컷신 중 전투 시간·피해·몬스터·투사체·상태이상 타이머가 멈추도록 기존 외부 일시정지 경로 활용.
- 죽음·부활·장면 전환·다중 이벤트에서도 컷신 중복 실행 금지. 컷신 리소스 실패 시 fail-soft.
- 별도 어려움 상태값은 전투 단위로 초기화. 용사 모드·쉬움·온라인 AI에 유출 금지.

### 2.3 약점 규칙

- 공격 예고/표적/위험 범위는 작은 화면에서 읽히게 표현한다.
- 자연 약점은 보통 **1.5~3초**, Stage 10 마지막 페이즈만 **4초** 제안. 실제 플레이로 조정.
- 취약 상태의 받는 피해 증가와 기존 상태이상·방어력·보호막의 합성 규칙을 명시하고 무한 중첩을 방지.
- 특정 증강이 약점을 영구 삭제해서는 안 된다. 약점은 **기술의 실제 완료 이벤트** 또는 별도 각성 상태에서 판정한다.
- 취약 시간에 일방적으로 무적을 줘서 공략 창을 소멸시키지 않도록 기존 무적·접근 차단과 충돌 테스트를 실시한다.
- 공략 몬스터는 진행에 따라 해금이 다르므로 **기본 공략 가능 여부**와 추천 조합의 실제 해금 시점을 별도 검증한다.

## 3. 보상 경제

### 3.1 일반 전투 연구·골드 보상 [구현됨]

기존 전투 기여도·조건부 부분 정산·Stage 배율과 상한은 유지한 채 **어려움에서만** 다음 배율을 일반 Run 보상에 적용한다.

| 결과 | 어려움 일반 Run 보상 |
|---|---:|
| 승리 | **×1.75** |
| 패배 | **×1.30** |
| 중도 포기 | **×1.00** (어려움 추가 보너스 없음) |

기존 정상 패배·중단의 최소 전투 시간/소환/피해 충족 조건과 부분 지급 상한은 유지한다. 일반 Run 골드는 실제 지급된 Run 연구 보상의 **60% 환산** 경로를 사용한다. **최초 클리어 보상은 여기서 제외**한다.

### 3.2 각 스테이지 어려움 최초 클리어 [구현됨]

- **골드 1,000**
- **마왕 토큰 30개**
- **연구 포인트 500**
- Stage 1~10 **각각 최초 1회**만. 기존 어려움 연구 30 지급은 **500으로 대체**하고 중복 지급 금지.
- 반복 클리어에는 별도 최초 보상 없음. 일반 Run 정산만 지급한다.
- 결과 화면의 마왕 토큰은 기존 currency/demon_token.png 아이콘을 사용한다.

### 3.3 어려움 10개 전부 최초 완료 [지급 로직 준비 / 현재 달성 불가]

- 올클리어 최초 1회 **골드 3,000 + 마왕 토큰 100개** 추가.
- 마지막 스테이지의 최초 보상과 함께 받을 수 있다.
- 중복 방지 완료 플래그와 보상은 같은 저장 처리에서 관리한다.
- **전10개 누적 총합:** 골드 **13,000**, 마왕 토큰 **400**, 연구 포인트 **5,000**. 일반 Run 보상 제외.
- Stage 3~10은 아직 개방되지 않아 현재 정상 진행으로는 이 보상을 획득할 수 없다.

## 4. Stage 1~10 상세 기획

### Stage 1 — 견습 마도사 / 마력 과부하 [구현됨]

- **발동:** HP 50% 최초 도달 → 기존 Stage1 컷신 1회.
- **강화:** 기본 마력탄 최소 3갈래. 기본 공격 3회마다 방향을 예고하는 **0.70초** 관통포 패턴.
- **자연 약점 ‘마력 역류’:** 관통포 종료 후 **2.0초간** 새 마법 공격 제한, **받는 피해 +20%**. 기존 마력 장벽·보호막은 강제 삭제하지 않는다.
- **기본 파훼:** 오크 등 튼튼한 소환체로 관통포 방향을 유도한 후 나머지 부대를 집중 투입. 위험 직선을 피하는 위치선정.
- **심화:** 거미 둔화로 거리 확보 방해, 해금된 폭탄쥐로 취약 시간 폭딜. **폭탄쥐 보유를 클리어 필수 조건으로 두지 않음.**
- **증강 주의:** 속공·장벽·회복 증강을 유지. 관통포 실종, 각성 반복, 장벽 종료 시점과 취약 타이밍 겹침을 실전 검증.
- **검증 기록:** 사용자가 Stage1 어려움 결과에서 시작/누적 피해 **677 HP**와 최초 보상 연구 500·골드 1000·토큰 30 표시를 확인. 실제 전체 상태 조합 회귀 검증이 끝났다는 뜻은 아님.

### Stage 2 — 날렵한 용사 / 그림자 사냥 [구현됨]

- **발동:** HP 50% 최초 도달 → 기존 Stage2 컷신 1회.
- **강화:** 기존 **급습-암살** 타격 수에 **2타 추가**. 기존 고유 증강의 추가타와 합산한다.
- **예고:** 마지막 타격의 예상 표적/착지 지점을 **0.45초** 보라색으로 표시한다. 안정성 복구 후 현재는 예상 위치만 표시하며, 실제 마지막 타깃 강제 고정은 추후 검증한다.
- **자연 약점 ‘그림자 탈진’:** 급습 연계 종료 후 **1.8초**, 이동속도 **×0.55**, 신규 **급습·난도질 사용 불가**, 받는 피해 **+20%**.
- **기본 파훼:** 전방 탱커로 급습을 빼고 마지막 착지 위치에 뒤쪽 소환체를 대기. 표적 몬스터를 처치하거나 타깃 범위 밖으로 빠뜨려 마지막 급습을 취소시키는 공략 가능.
- **심화:** 거미의 둔화/속박과 빠른 추격 몬스터로 탈진 시간 집중 공격.
- **증강 주의:** 연격 가속·추가 급습·난도질 보호막. **실제 마지막 추가타 완료/조기 종료를 기준**으로 탈진을 시작한다. 일반 연격과 급습을 동일 기술로 합쳐버리지 않는다.
- **상태 (2026-10-31 회귀 대응):** Stage2 쉬움·어려움 모두 이동/공격/게이지 정지 제보 발생. 공용 rogue 아키타입을 Stage2 구현 전 안정본으로 복원하고 어려움 전용 연출·추가타·탈진을 hero.gd에서 처리하도록 격리. **Godot 실행/실전 재확인 전에는 고친 것으로 단정하지 않는다.** 시작 HP는 기존 600 기준 **1,128** 기대(추가 프로필·Stage 보정이 없다면).

### Stage 3 — 검과 방패의 용사 / 불굴의 수호자 [기획]

- **강화:** 각성 방어 자세 **4초**, 정면 피해 **50% 감소** 및 반격. 자세 중 이속 **-30%**.
- **자연 약점:** 방어 자세 자연 종료 후 **1.5초** 회복 공백.
- **심화 파훼 ‘방패 붕괴’:** 후방에서 유효 공격 **3회** 적중 시 각성 방어 자세 붕괴, **2.0초** 각성 방어/반격 봉인 및 **받는 피해 +20%**.
- **기본 전술:** 탱커로 정면 고정 후 다른 방향에서 공격. 초반 기본 몬스터만으로도 방어 종료 공백 활용 가능해야 함.
- **추천 조합:** 오크 + 해골 궁수(보유 시) + 거미. 후방 판정·탄도·방향 표시 필수.
- **증강 충돌:** 견고한 방패·수호 숙련·가시 방패·복수의 방패. **기존 막기 보호막 HP와 새 각성 자세는 완전 분리**; 방패 붕괴가 원래 방패/반사·보호막을 무단으로 삭제하지 않음.

### Stage 4 — 권총의 용사 / 데드아이 폭주 [기획]

- **강화:** 강화 데드아이로 사격 궤도 분리/집중 연사. 탄창과 일반 재장전 규칙 보존.
- **자연 약점 ‘총열 과열’:** 강화 연사 후 **2.0초**, 새 사격과 백스텝 금지. 재장전 여부와 독립.
- **기본 전술:** 탱커로 데드아이를 유도하고 과열 때 빠른 부대 투입.
- **심화:** 거미 둔화 + 늑대 추격(해금 후). 붉은 총열/연기 예고로 약점 가시화.
- **증강 충돌: 매우 높음.** 속사 실린더·속전속결·확장 실린더·전술 후퇴·장전 엄호. **과열을 재장전 타이머로 구현하면 퀵드로가 취약 시간을 삭제할 수 있음** → 독립 hard_overheat 상태로 처리. 백스텝 무적 후 실질 공략 시간이 확보되는지 검증.

### Stage 5 — 대마법 용사 / 육원소 폭주 [기획]

- **강화:** 기존 6원소를 활용한 서로 다른 **원소 2회 연계 시전**. 예: 얼음+대지 / 화염+바람. 실제 지원 기술/타겟 규칙을 기반으로 조합 확정.
- **자연 약점 ‘원소 불안정’:** 실제 마지막 연계 시전 완료 후 **2.5초**, 강화 마법 사용 제한·**받는 피해 +25%**.
- **기본 전술:** 부대 분산으로 여러 원소 사용 유도 → 마지막 마법 뒤 빠른 병력 투입.
- **심화:** 탱커+고속 근접+제어 몬스터 혼합. 원소 연계 사전 바닥 표시 및 피할 공간 보장.
- **증강 충돌:** 다중시전·고속영창·긴급탈출·기존 ‘원소공명’ 증강. **예약된 다중시전까지 종료 후** 취약 시작. 순간이동해도 취약 상태 유지. 기존 증강명과 **새 상태 ID 구별**.

### Stage 6 — 광기의 용사 / 피의 폭주 [기획]

- **강화:** 혈검술의 공격 범위·연계 일부 강화; 강화 혈검술에 **추가 HP 소모**.
- **자연 약점 ‘피의 반동’:** 강화 혈검술 **3회 사용 시** **3초** 반동. **회복 효율 -40%, 받는 피해 +15%**, 강화 연계 일시 제한.
- **기본 전술:** 단단한 몬스터로 자해형 혈검술을 반복 유도, 소모 누적·반동 순간 폭딜.
- **심화:** 치유 감소 계열 몬스터(신규 효과 필요) + 폭탄쥐 등 폭발형 조합.
- **증강 충돌: 매우 높음.** **동상이몽**은 영구 광기이므로 ‘광기가 끝나면 탈진’ 구조를 **금지**. 광기 유지 여부와 무관한 혈검술 사용횟수 반동으로 구현. 불사의 광인의 부활 뒤에도 컷신 재생 금지, 혈검술 제8식 소모·흡혈 보존.

### Stage 7 — 화학의 용사 / 불안정한 현자의 돌 [기획]

- **기존 해금:** 연금술 재료 **24개** → 현자의 돌.
- **어려움 해금 제안:** 재료 **16개**로 단축, 기존 해금 컷신 및 현자의 돌 효과 유지. **아직 코드 미적용.**
- **강화:** 독자취/촉매 혼합장·화학 반응을 공격적으로 운용.
- **자연 약점 ‘반응기 배출’:** 강화 화학 반응 종료 후 **2.5초**, 신규 촉매 설치 제한 및 이속 **-15%**. 남은 독장판/기존 독 피해는 유지.
- **기본 전술:** 독장판 밖 대기→촉매 반응을 유도→배출 중 진입.
- **심화:** 둔화·속박·높은 체력/저항으로 퇴로 차단.
- **증강 충돌:** 등가교환의 법칙·빠른조제·압축 화학가스, 재료 보충/가스 회복. 배출은 **현재 가스량이 아니라 실제 강화 반응 종료 횟수**로 판단. 현자의 돌 자체의 기존 HP/공격/이속 증폭과 어려움 입장 배율의 중복 적용 관계 검증.

### Stage 8 — 이계의 용사 / 폭주하는 이계의 문 [기획]

- **기존 해금:** 누적 소환 **50회** → 이계의 문 개방.
- **어려움 해금 제안:** **30회**로 단축, 기존 소환수/포화 방벽/해금 컷신 유지. **아직 코드 미적용.**
- **강화:** 개방된 문에서 강화 소환 공세. 원래 소환수 및 슬롯/보호막 관련 증강 유지.
- **자연 약점 ‘차원 연결 불안정’:** 강화 공세 **2회** 이후 **2.0초** 추가 강화 공세 불가, 영웅 **받는 피해 +15%**. 이미 소환된 개체는 정상 잔존.
- **기본 전술:** 저비용 몬스터를 파상적으로 투입하여 소환 공세를 버티고 연결 불안정 때 주력 투입.
- **심화 후보:** 적 이계 소환수를 정리한 수만큼 취약 시간 소폭 연장. **실제 몬스터 대상 지정·피해 판정이 가능한지 검증 전에는 확정/구현 금지**.
- **증강 충돌:** 철벽의 문지기·증설된 감시망·포화 방벽 강화 등 슬롯·방벽 변경. 소환 슬롯·기존 쿨타임·유지시간을 어려움 상태로 덮어쓰지 않음.

### Stage 9 — 정화의 용사 / 심판의 성역 [기획]

- **기존 해금:** 정화 누적 **40회** → 궁그닐.
- **어려움 해금 제안:** **24회**로 단축, 기존 해금 컷신·정화 구체·궁그닐 보존. **아직 코드 미적용.**
- **강화:** 정화 구체 연결 연쇄/궁그닐 위험 범위를 더 적극적으로 사용, 연결선과 발사 방향을 명확히 표시.
- **자연 약점 ‘성역 소진’:** 정화 구체 **3개 이상 연쇄 폭발 종료** 또는 궁그닐 종료 후 **2.5초**, 신규 구체 설치 제한, **받는 피해 +20%**.
- **기본 전술:** 언데드만으로 구성하지 않고 부대를 분산. 구체 폭발 뒤 빈 영역에 진입.
- **심화:** 고속 진입/집중 화력·제어 효과로 성역 소진 창 활용.
- **증강 충돌:** 연쇄 정화·프리즘 현상·정화의 서·신이시여. **구체 수가 아닌 실제 연쇄/궁그닐 종료 이벤트로** 약점 발동. 기존 정화·회복·실드 효과 무단 제거 금지.

### Stage 10 — 대현자 용사 / 아스트라: 별의 붕괴 [기획]

- **기존 해금:** 마력응축 **2회 완료** → 후반 기술/컷신.
- **어려움 해금 제안:** **1회 완료**로 단축. 기존 스타라이트·소멸·흑점폭발·마력 영구 성장 유지. **아직 코드 미적용.**
- **1페이즈:** 마력응축·기본 마법 성장. 플레이어가 조기 압박 또는 자원 비축을 선택.
- **2페이즈:** 후반 기술 개방 후 대형 천체 기술 강화. 위험 범위에 안전 회피 경로를 제공.
- **3페이즈:** HP **25% 이하** 최초 도달 시 한 번만 특별 천체 연계. **추가 전면 컷신 없이** 전투 연출만. 연계 후 **4초 과부하**.
- **자연 약점 ‘마력핵 노출’:** 스타라이트 또는 소멸의 **주요 공격 종료** 후 **3초**, **받는 피해 +20%**.
- **특수 파훼 ‘별 궤도 교란’:** 노출 중 영웅 최대 HP의 **3.5% 이상 실제 피해**를 입히면 다음 **어려움 전용 대형 공격 제한**을 **7초** 연장. 전투당 **최대 2회**.
- **기본 전술:** 대형 기술 유도→예고 범위 회피→생존 병력을 분산 대기→마력핵 노출에 집중 소환.
- **증강 충돌:** 마력응축 영구 성장·추가 시전·지연 피해. 기존 마력응축 스택을 없애거나 원래 기술 쿨타임을 강제로 교체하지 않음. 기술의 **실제 마지막 종료** 기준으로 취약 시작.

## 6. 몬스터 카운터 및 신규 효과

### 기존 몬스터를 이용한 전략 (역할 중심 추천)

| 카운터 유형 | 역할 / 예시 | 대상 |
|---|---|---|
| 공격 유도·버티기 | 오크 등 탱커 | 1·3·4·6·7·10 |
| 둔화·접근 차단 | 거미 | 1·2·4·5·7 |
| 빠른 추격 | 늑대 등 고속 근접 | 2·4·5·10 |
| 순간 폭발 | 폭탄쥐 (해금 확인) | 1·2·6·10 |
| 다방향/후방 압박 | 해골 궁수·기본 근접 분산 | 3·5·9 |
| 상태이상 보조 | 유령의 공포(엘리트), 메두사 석화, 망령 기사 기절(엘리트) | 후반 공략 보조 |

실제 몬스터 해금 상태, 일반/엘리트 차이, 각 효과의 누적·저항 규칙을 먼저 확인하고 추천 UI에 표시한다. **기본 공략은 특수 몬스터가 없어도 성립해야 한다.**

### 새로 추가할 후보 효과 [미구현]

1. **치유 저해:** 미라/저주형 몬스터 후보, 약 4초 동안 회복 효율 -30~40%. Stage 6 중심, Stage 7·9 보조. 기존 회복 감소 처리 경로 재사용 검토.
2. **집중 교란:** 유령 계열 후보, 어려움 전용 강화 시전 준비시간만 짧게 지연. Stage 1·5·10. 침묵과 중첩해 무한 봉인하지 않음.
3. **자세 붕괴:** 후방 공격 또는 오크 특성 후보, Stage 3 각성 방패 자세에만 파괴 진행도 부여. 일반 보호막 데이터 변경 금지.
4. **회로 압박:** 다단히트/원거리 압박형 후보, 취약 중 유효 타격 시 최대 **0.5초** 연장. 틱 다중 카운트 금지, 재적용 주기와 연장 상한 필요.

새 효과는 **강력한 선택지**여야 하고 그 자체가 클리어 필수 열쇠가 되어서는 안 된다.

## 7. 증강과 각성 충돌 방지 매트릭스

| Stage | 위험 증강·계통 | 방지 규칙 |
|---|---|---|
| 1 | 속공 훈련·마력 장벽 | 관통포 종료 별도 취약 상태; 장벽 HP 보존 |
| 2 | 연격 가속·추가 급습·난도질 방어 | 실제 마지막 타격/조기 종료 기준. 추가타 합산 |
| 3 | 견고한 방패·수호 숙련·반사 | 각성 자세만 파괴, 기존 막기 보호막 유지 |
| 4 | 속사 실린더·속전속결·장전 엄호 | **과열 타이머를 재장전과 분리** |
| 5 | 다중시전·고속영창·긴급탈출·원소공명 | 예약 시전 종료 후 약점, 텔레포트 후에도 지속 |
| 6 | **동상이몽**·혈검술 제8식·불사의 광인 | 영구 광기에서도 반동; 부활 뒤 컷신 재발동 금지 |
| 7 | 등가교환·빠른조제·압축 화학가스 | 가스 수치가 아닌 강화 반응 종료로 약점 |
| 8 | 소환수 수·방벽·유지시간 증강 | 원본 소환 슬롯/보호막/쿨타임 수정 금지 |
| 9 | 연쇄 정화·프리즘 현상·정화의 서 | 구체 개수 아닌 실제 연쇄/궁그닐 종료 기준 |
| 10 | 마력응축·추가 시전·대형 기술 연계 | 영구 성장 유지, 어려움 전용 제한만 독립 |

**구현 공통 규칙**
- 원래의 스킬·증강 로직을 복제하지 말고 필요한 시작/종료 이벤트에만 어려움 상태를 걸 것.
- 각성 활성화와 재생 중 플래그, 취약 타이머, 중복 발동 가드는 전투 한 번마다 초기화.
- 상태이상 저항·회복/흡혈·보호막·무적·부활 처리의 원래 우선순위를 보존.
- 시전 중 기절·침묵·사망·타깃 소멸 시 이벤트 누락과 무한 취약/무한 강화 상태 검사.
- 용사 모드와 온라인/연습/튜토리얼에서는 어려움 스크립트가 아무 영향을 주지 않아야 함.

## 8. 사용자 UI·연출

- 어려움 선택 시 **강화된 용사 / 전용 각성 패턴** 및 최초 보상을 표시.
- 쉬움 입장 대화는 생략하지만 영웅 등장/각성 컷신·기술 이펙트는 유지.
- 강한 공격의 예고, 기술 종료, 약점 노출을 색/사운드/링으로 읽을 수 있어야 함. 작은 모바일 화면에서 몬스터 무리와 겹쳐도 구분되게 한다.
- 취약 표시와 관련 타이머는 실제 판정과 정확히 동기화한다.
- 클리어 결과에 일반 연구/골드와 최초 보상 연구500·골드1000·마왕토큰30을 **각각 분리** 표시하고, 토큰 전용 아이콘 사용.
- 10개 올클리어는 마지막 스테이지 보상과 추가 골드3000·토큰100을 함께 보여 준다.
- 화면 표시 이슈가 재발하면 **UI 아이콘 매핑 문제와 실제 재화 지급/저장 문제를 별개로 진단**한다.

## 10. 후속 개발 세션 인수인계

**현재 개발 브랜치:** feature/stage10-astra. **main 병합은 사용자 요청 전까지 하지 않는다.**

1. 위 상태표를 확인하고 최신 GitHub 브랜치의 코드·CHANGELOG와 먼저 대조한다. **기획값을 곧바로 구현 완료로 간주하지 않는다.**
2. Stage 1·2에 이미 반영한 스탯/보상/로비 코드를 복제하지 않고, Stage 3의 데이터와 필요한 직업 이벤트만 추가한다.
3. Stage 3 방패 파괴는 **각성 자세**에만 걸고, 원래 막기 보호막 및 증강을 삭제하지 않는다.
4. Stage 4 이상도 기술/타이머 복제 대신 별도 약점 상태를 유지한다. Stage 7~10 원본 조건 수정을 피하고 **마왕 어려움 전용 오버라이드**로 해금 시점만 단축한다.
5. 매 단계: 설계 수치 확인 → 최소 파일 수정 → 기존 단계 회귀 + 새 단계 테스트 → Godot 실행 가능 여부 명시 → CHANGELOG 짧게 갱신 → 커밋 → 사용자 실전 피드백.
6. 향후 유물 실제 효과·몬스터 해금 진행도에 따라 Stage 6~10의 공격/생존 예산은 **체감 난이도 목표를 유지하는 선에서** 재조정한다.

### 설계 핵심 문장

> **강해진 마왕은 힘으로, 숙련된 마왕은 전략으로 승리할 수 있어야 한다.**
> 영웅의 강점을 관찰하여 약점을 유도하고, 알맞은 몬스터를 제때 투입하는 것이 어려움 난이도의 핵심 재미다.
