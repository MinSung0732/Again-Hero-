# 모바일 HUD 후속 확대 — 2026-10-14

현재 레이아웃은 전투 시작 Y420/헤더 하단400이다. 아래 최초 구현 기록의 Y330은 이전 값이다. 무기·보조는 여전히 6+6이며 슬롯 높이76/레벨24, 용사/시간/상황 글자26, HP36/EXP32, 설정116×72다. 스탯은 펼침폭310, 접힌 버튼132×64, 아이콘34/글자23~26이다. 가로 여섯 칸을 유지하면서 모바일 표시와 탭 영역을 조금 키웠다.

상단 초상화가 없던 것은 HUD에 초상화 컨트롤/로딩 연결이 없었기 때문이다. 현재 선택 영웅의 고정 ID로 HeroCharacterCatalog의 Stage를 찾고 StageCatalog의 기존 portrait_path를 사용한다. 선택 전장과 초상화 Stage를 섞지 않는다. 실제 사용 영역을 AtlasTexture로 잘라 투명 여백 영향을 줄이고 비율 유지/nearest로88×88에 표시한다. 파일/이미지/아틀라스 작업은 영웅별 첫 조회에만 하고 이후 같은 Texture2D를 재사용한다. 로딩 예열은 선택된 초상화1장만 추가한다. 기존 초상화 원본을 수정하거나 새로 생성하지 않는다.

상단 상황 표시 앞쪽은 처치 N · 현재 몬스터 M이다. 처치 수는 기존 사망 계측을 합산한다. 현재 수는 active_monsters 레지스트리 크기를 O(1)로 읽는다. 직접 소환 인구뿐 아니라 등록된 분열/추가 소환도 포함하고 _unregister_monster에서 제거되면 반영한다. 실제 자식 트리/그룹 전체 순회는 없다. 고유자원 요약이 길어도 숫자를 먼저 표시한다. 갱신 주기는 기존250ms다.

프레임 시작, BattleView 위치/뷰포트 높이, 스탯 위치는 HUD.BATTLE_TOP을 공유한다. 자유패드는 실제 BattleView만 입력 영역으로 삼는 기존 규칙을 그대로 따른다.

# 용사 HUD 개편 — 2026-10-14

첨부 디자인은 배치 참고이며 전체 그림 복제는 하지 않는다. 상단 로고/용사 이름·레벨·시간/설정과 HP·EXP를 유지하고 아래에 무기와 보조를 각각 가로 6칸씩 두 줄로 배치한다. 전투 시작 Y330, 좌우 프레임90폭은 유지한다.

무기 장착 상한은 3→6, 보조는 6이다. Catalog 상수를 런타임·후보·로비·HUD가 함께 사용한다. 기존 64투사체/48효과/8장판/24파동·소환3 상한은 확대하지 않는다. 풀이 포화되면 기존 생략 규칙을 따른다. 더 많은 무기 조합의 실제 부하/성장 난이도는 실전 확인이 필요하다.

슬롯은 아이콘과 레벨만 표시한다. 무기는 Lv10에서도 상자 진화 전까지 Lv.10이고 진화 후 MAX다. 보조는 각각의 한도(일반10, 투사체개수2)에 도달하면 MAX다. 빈칸은 —, 슬롯을 탭하면 상세가 열리면서 전투가 정지한다. 즉시 회복은 장착 효과가 아니므로 슬롯에 남지 않는다.

스탯창은 왼쪽 Y342의 작은 능력치 버튼으로 시작한다. 펼치면 폭280/8항목을 표시하고 다시 접을 수 있다. 기본 공격(고유자원 기본피해와 공격 보조 포함), 피해 감소, 기본 이속, 공속 보너스, 최대 체력, 보조 피흡, 범위 보너스, 경험치 보너스다. 무기별 배율/현재 공격 횟수/고유 무기의 자체 흡혈은 공통 스탯에 합치지 않는다. 자유패드 원점 검사에서 현재 표시된 스탯창 영역을 제외한다. 고정패드 동작은 유지한다.

## 리소스

`assets/art/ui/hero_hud/hero_hud_atlas.png`는 built-in image generation으로 생성한 1254×1254 RGBA PNG이다. 원본을 복사해 저장하고 런타임 Base64는 사용하지 않는다. 4×4 셀의 첫 줄은 기둥4종, 나머지는 기본공격/방어/이속/공속/HP/피흡/범위/사거리/투사체개수/투사체속도/지속/EXP 아이콘이다. 현재 스탯창은8종을 사용하고 나머지는 같은 캐시에 준비되어 있다.

기둥 셀은 중앙34% 폭을 AtlasTexture로 참조하고 같은 가로세로 배율로 반복한다. 화면 끝의 마지막 타일만 소스 영역을 줄여 크롭한다. 아이콘도 AtlasTexture 캐시를 재사용하고 nearest 필터를 적용한다. 로딩 준비에 새 아틀라스를 포함한다.
