# 용사 공통 연구 투자 효율 조정 — 2026-10-15

기존 비용과 최대 레벨은 그대로 두고 모든 용사의 연구 효과를 1.5~3배 상향한다. 기존 저장의 연구 레벨·투자 포인트를 보존하며 다음 도전의 스냅샷부터 새 효과가 적용된다. 초기화나 재구매가 필요 없고, 이미 진행 중인 전투의 스냅샷은 바꾸지 않는다. 마왕 연구·랭킹 프로토타입·연구 포인트 지급량은 변경하지 않는다.

비용은 기존과 같은 `기본비용 × (현재레벨+1)`이다. 최대까지 10레벨은 기본비용×55, 5레벨은 ×15, 전체 합계 88,000P다. 첫 단계부터 체력5%/공격3%/공속2%로 체감 폭을 높인다. 비용을 그대로 두므로 기존 구매 원장과 초기화의 레거시 비용 재구성도 유지한다.

## 중첩 예산과 정산

- 공격력·공속 MAX의 명목 처리량은 1.3×1.2=1.56배다. 기존 1.1×1.1=1.21배 대비 약28.9% 상향이며 명중률·고유 자원·공격 방식에 따라 실전 DPS는 다르다.
- HP1200의 생명력 MAX는 1800HP, 두 연구 MAX 재생은 5.4HP/초다(기존 1440HP에서 1.44HP/초). 회복 정수 미만은 기존 bank에 보존하고 죽은 용사는 부활시키지 않는다. 실제 피해 1000당 MAX 흡혈15HP이며 광역/다중타격 고유 회복과 별도 합산이다. 이동속도는15%, 흡혈은1.5%로 상대적으로 보수적 상향한다.
- 보호막은 실제 생성량에1.5배를 한 번 적용한다. 추가 기본 보호막/지속시간/무적은 주지 않는다.
- 범위는 반경1.2배(원형면적1.44배), 사거리는 원거리만1.25배다. 기존 range가 탐지·반경을 겸하는 원격장판은 최대1.5배 반경(원형면적2.25배)이므로 추가 상향은 보류한다. 기존 투사체/설치체/소환수 풀 상한은 유지한다.
- 골드 지급 경로의 고정15% 상한을 Catalog의 `growth_max_bonus("gold")`로 바꿔 상자와 고정 보상 모두30%까지 실제 적용한다. 30% 연구 상자2개는20.8골드 누적 → 승리20/패배8/중단6 지급, 승리 고정78+20=98골드다. 중복 receipt·단회 정산·저장 실패 재시도·비율100/40/30은 유지한다. 이전15% 스냅샷도 기존 지급량을 유지한다. 과대 입력은30%로 제한한다.
