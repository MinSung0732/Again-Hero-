# 용사 무기 겹침 감사 (2026-10-31)

대상: `src/data/hero_weapon_catalog.gd` 용사 10명 × 무기 10종 = 100종.
기준: 뱀서라이크식으로 무기마다 **누구를 노리나(대상 규칙)** × **어떤 모양인가(형태)** 조합이 한 용사 안에서 겹치지 않아야 한다.

## 공통 원인 (모든 용사)
1. **색이 하나뿐**: 7명은 무기 10종이 전부 같은 색(예: 견습마도사 `85dcff`), 나머지도 2~3색. 이펙트가 겹치면 어느 무기인지 구분 불가.
2. **범위 도형이 아트 위에 항상 그려짐**: `hero_weapon_runtime.gd` `_draw_area`·베기/광선 분기가 아트 프레임이 있어도 반투명 채움(`AREA_FILL_ALPHA 0.10`, `SHAPE_FILL_ALPHA 0.13`) + 3px 외곽선(`OUTLINE_WIDTH`)을 같은 색으로 덧그림. 장판·베기·광선이 동시에 터지면 같은 색 원·부채꼴이 여러 겹 쌓여 범위 표시가 헷갈림.
3. **패턴 쏠림**: 독/장판 13, 탄환 13, 베기 11, 원형 폭발 11 = 전체의 48%.

## 필요한 공통 기반 (새 동작)
기존: 직진·곡선·관통·왕복·도탄·부채·궤도·장판·이동경로·투척·설치·포탑·지연폭발.
추가: ① 무작위 대상 낙하 ② 화면 벽 반사 ③ 회전 지속 광선 ④ 양옆 교차 베기 ⑤ 떠도는 이동체(회오리) ⑥ 대상 규칙 저체력/최대체력 ⑦ 구르는 투척체 ⑧ 소환수 위치 기준 발동.

## 범위 표시 규칙 (제안)
- 아트 프레임이 있는 공격은 채움·외곽선을 그리지 않는다(아트가 곧 범위).
- 외곽선은 **예고**(투척 착탄 지점, 지연 폭발)에만, 무기 색이 아닌 공통 경고색 점선으로.
- 무기마다 대표 색을 따로(용사 테마 안에서 명도·채도 차이), 카탈로그 `color`를 무기별로 재지정.

## 진행 순서
1. 범위 표시 규칙 + 무기별 색 (전 무기 즉시 효과, 수치 변화 없음)
2. 공통 기반 ①~⑧
3. 용사별 무기 변경 1명씩 + `docs/HERO_BALANCE_STANDARD.md` 전후표 + 관련 테스트
