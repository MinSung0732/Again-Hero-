## Milestone 3 — Build AI v1

완료 조건: AI 선택 이유를 플레이어가 이해할 수 있다.

현재 v1은 **기본 선호도 + 주변 적 수 + 현재 HP + 가장 가까운 적 거리 + 몬스터 타입/역할 비율 + 빌드 관성 + 작은 랜덤값**을 점수화해 선택한다.
슬라임/거미/오크 역할 대응까지 들어갔고, 증강 간 시너지와 판단 지연은 이후 확장한다.

- [x] 주변 적 개체 수 측정
- [x] 몬스터 타입 비율 측정
- [ ] 현재 빌드 시너지 점수
- [x] 빌드 관성
