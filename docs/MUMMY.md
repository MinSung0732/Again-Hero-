# 미라

고급 / 언데드 / 탱커 / 근거리 / 코스트 7. 기본 0레벨 HP 125, 이동속도 92, 공격력 13, 사거리 76, 공격 간격 1.1초. 기존 등급·수집·연구·마왕·증강 성장을 사용한다. 기존 mummy 일반/엘리트 캐릭터 프레임 재사용.

## 소환 실드

최종 최대 체력의 50%를 소환 시 1회 부여한다. 먼저 실드가 피해를 흡수하고 남은 피해가 HP에 적용된다. 최대 체력 성장 시 남은 실드 비율도 조정하지만 구성 새로고침으로 회복하지 않는다. 이미 파괴된 실드는 다시 생성되지 않는다. 파란 실드 게이지를 표시한다.

## 특수증강

1. **불멸의 붕대**: 최대 체력 +70%. 기존 공통 능력치 배율 계산에 포함하며 새로고침 시 반복 곱하지 않는다.
2. **깨진 봉인**: 소환 실드 파괴 순간 개체당 1회, 실드 전체 용량만큼 현재 용사에게 피해를 준다. 여러 번 맞아서 파괴되더라도 마지막 남은 실드가 아닌 전체 용량을 사용한다. 무적에 막혀도 1회 사용을 소모한다. 체력 피해가 함께 들어와 사망하는 경우도 파괴 반격 후 사망한다. 증강 없이 실드가 깨진 뒤 증강을 획득해도 소급 반격하지 않는다.
3. **메마른 상처**: 실제 HP/실드 피해를 준 대상에게 2초간 30% 치유감소. 타격마다 갱신하며 합산하지 않는다.

## 엘리트 — 미라의 저주

선쿨/재사용 0초 패시브. 접근 속도 상시 1.3배. 실제 피해를 준 대상에게 2초간 받는 피해 +20%, 갱신형. 발동한 첫 공격에는 새 저주를 소급 적용하지 않고 후속 피해부터 적용한다. 일반공격과 실드 반격 모두 실제 피해 판정을 공유한다. 무적에 막힌 공격은 치유감소/저주를 발생시키거나 갱신하지 않는다.

## 공통 상태 계산

- `apply_healing_reduction(duration, reduction)` / `apply_damage_taken_increase(duration, increase)`로 기간·비율 지정. 활성 상태 중 더 강한 비율과 더 긴 남은 기간을 유지한다. 동일 효과 다수 개체는 수치 합산 없이 기간 갱신. 사망/프로필 초기화 시 정리.
- 치유감소는 회복 아이템, 공통 직접 회복, 스킬/증강 회복 및 연금술사·대현자 별도 처리를 포함한다. 기존 광전사 회복 계수 적용 후 감소한다. 반올림하며 100% 감소는 회복 0. 최대 HP 성장에 따른 현재 HP 증가·변신 능력치 배율·부활 HP 설정은 회복으로 보지 않는다.
- 받는 피해 증가는 방어/실드 계산 전에 일반·스킬·기존 상태 피해에 적용한다. 메두사가 기록한 중독 실피해 예산에는 이미 원래 타격의 보정이 포함되어 있어 재증폭하지 않는다.
- 전용 상태 이펙트는 아직 연결하지 않는다. 스턴/석화 중에도 상태 기간은 진행하고 전투 일시정지 중에는 정지한다.
