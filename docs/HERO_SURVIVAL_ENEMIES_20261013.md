## 문제와 변경

용사 생존은 시작 공격력26인데 몬스터의 마왕 모드 원본 체력을 그대로 사용했다. Stage1 Lv1 마력탄26 기준 슬라임72/거미80/오크260은 각3/4/10타가 필요했다. 소환 밀도를 늘린 뒤에는 AI마왕 소환EXP로 오른 레벨의 몸체 강화와 무작위 대형화도 겹쳤다.

용사 모드에서만 몬스터의 역할·등급 원본에 아래 생존 전용 곡선을 적용한다. 첫30초 유지 후 각 점 사이를 선형 보간한다. 무기/용사 피해를 실시간으로 따라가는 자동 난이도 보정이 아니므로 무기를 강화하면 처치가 쉬워지는 의미가 유지된다.

표는 Stage1 일반몹·증강0·추가능력0의 값이다. 실제Godot Battle 씬에서 첫 슬라임13은1타, 거미14는1타, 오크47은2타의26피해로 사망했다. 엘리트/대형은 기존 별도배율과 예약된 시간표를 적용한다. 후반 용사의 실제 빌드/무기레벨/진화/피해감소/AI증강에 따라 처치 타수는 달라진다.

`hero_survival_spawn_seconds`를 소환 시 저장한다. 후속 마왕레벨업/증강 재계산은 같은 소환시점 곡선을 사용하여 오래 살아 있던 적이 갑자기 강화되거나 상처가 초기화되지 않는다. 고정0레벨 광신도 증원도 같은 생존곡선만 적용하고 증강제외를 유지한다. 폭탄쥐 폭발 피해는 증강 재계산 후에도 곡선을 유지하고, 엘리트 특수배율도 재계산 시 보존한다.

AI마왕의 관측/증강 선택·소환비용·공세밀도는 유지한다. 용사 모드에서만 AI레벨의 HP/피해/이속 배율을 위 곡선으로 대체하고 처치EXP 레벨배율은1로 고정한다. 기존25%·소수EXP·레벨요구곡선과 엘리트/대형EXP2/4 유지. 일반소환의 레벨 기반 무작위 대형화는 용사에서 끄고 엘리트60초·대형180초부터의 기존 시간표를 사용한다. 마왕 캠페인의 원본/레벨강화/대형확률/보상은 변경하지 않는다.

## 로컬 테스트

`LocalTestMode.has_all_heroes_unlocked()`는 디버그 빌드·localtest 활성·비튜토리얼·게스트·정확한 테스트 저장폴더일 때만 참이다. `HeroModeStore.character_unlocked()`에 공통 연결하여 카드/선택 저장/전투 입장이 모두10종을 허용한다. 기존localtest 저장도 재초기화 없이 적용된다. 편성 화면에 '로컬 테스트 · 모든 용사 선택 가능'을 표시한다.

실제 어려움 클리어/컬렉션 소유권은 위조하거나 저장하지 않는다. normaltest로 복귀하면 기존 해금 조건과 일반 계정 편성을 읽는다. 튜토리얼 미리보기·다른 게스트·일반 계정·배포 빌드는 이 우회를 사용하지 않는다.
