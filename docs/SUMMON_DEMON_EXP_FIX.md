# 소환 마왕 경험치 누락 수정

최근 추가한 멧돼지/흑요정 궁수/아누비스 Catalog에 `summon_exp`가 없었고, 기존 `get_summon_exp`의 누락 기본값0으로 인해 정상 소환 후 경험치를 얻지 못했다. Battle `_perform_summon`→`_gain_demon_exp` 및 진행 UI 신호 경로 자체는 유지한다.

- 세 몬스터에 기존 비용 기준 정책대로 소환EXP8/12/24를 명시한다.
- `get_summon_exp`는 필드가 없을 때 `base_cost`로 대체한다. 초월 등 명시적0, 별도로 지정한 다른 보상값은 그대로 존중하고 음수는0으로 제한한다. 알 수 없는 ID는0이다.
- 생산비용 할인과 무관하게 기본 소환EXP를 지급한다. 연구의 경험치 배율은 Battle에서 적용한다. 성공한 주 소환만1회 지급, 추가 소환/실패 소환에 보상을 더하지 않는다.
- 튜토리얼의 의도된 마왕 레벨업 억제, 전투 종료 후 지급 차단, 초월 소환EXP0은 유지한다. 저장/서버/보유몬스터 스키마 변경은 없다.

Godot4.5.1 격리 실제Battle `_perform_summon`/`_gain_demon_exp`/레벨 요구량 함수 및 실제Catalog 함수53검사 통과. 전체35종EXP 정책, 미래 누락/명시적0/커스텀값/음수/unknown, 자동·수동·할인 소환, 레벨업·증강 대기열·UI신호, 추가몹 중복지급 방지, 소환실패 비용환불/EXP0, 초월0, 튜토리얼 억제, 종료 억제, 연구배율을 확인했다. spawn/metrics/UI는 어댑터로 대체하며 전체Battle 화면/Android는 미검증이다.

같은 패치에서 멧돼지 크기121%, 흑요정 궁수118%, 기본사거리 지름750/화살속도280/크기109% 및 사거리증강 지름1125를 적용했다. 실제배우/PNG 기반76검사와 기존밸런스411검사 통과,35종 감사 issues0. 원본PNG·충돌·HP/공격·코스트·엘리트 기술은 유지한다.
