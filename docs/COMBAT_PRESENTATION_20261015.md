## 발·그림자·체력바

- source_idle_bounds와 공통 offset은 유지. Visual.position.y와 GroundShadow.position.y를 모두30에 맞춰 정상/엘리트에서 발밑이 같은 월드 점에 닿는다.
- 활동 모션 idle/move/attack/hit 전체의 source_animation_top으로 HP바를 배치, 가장 높은 픽셀보다 월드12px 위. 쉴드바는 기존 공통 렌더러가 그 위에 쌓는다. Orc의 고정-59바를 중복으로 그리지 않는다.
- 엘리트 이미지 높이×개체 visual_scale 이중 확대를 제거. 개체 스케일은 충돌/전투 기준으로 보존하면서 Visual의 로컬 스케일에서 역보정한다. 새 엘리트의 기본 실루엣은 일반의1.12배, 명시된 giant_size_multiplier는 별도 유지.
- 그림자 폭은 본체 폭에 비례하되34~86px로 제한, 각 개체 스케일로 역보정. 공격 범위·HP·이동속도·몬스터 충돌 모양은 그대로다.
- 변경 범위는 이번 신규8종의 일반/엘리트. 기존 다른 몬스터/초월의 고유 체급은 수정하지 않는다.

## 투사체 수 증강

- 최대2중첩 유지. 스타터뿐 아니라 실제 전달 방식으로 분류: 일반 bolt/burst, 관통포, 운석, 자동사격 설치체, 실물 회전무기, 감시자/문지기 원거리 소환수.
- 일반 bolt는 대상이1명이어도 추가탄을0.08초 간격으로 발사. 원래 다중표적 수와 별도로 추가2발을 한 번만 더해, 기본 탄마다2발씩 곱해지는 중복 증가를 방지.
- 연사는 기존 탄약으로 실행 가능한 기본 발사량을 계산한 뒤 보너스탄을 더한다. 설치체도 설치물 수를 늘리는 대신 각 사격에 추가탄. 소환수는 고정 자체풀의 기본탄을 유지하고 추가탄만 용사 공통풀을 사용. 기존 소환수도 현재 증강값을 사용하며 AI마왕의 기존 용사 소환수는 변하지 않는다.
- 회전 개체는 최대8→10까지(진화8+증강2), 접촉 판정/타격 주기 공유. 관통포6·운석8로 시작 풀을 준비해 후반에도 증강이 기존4/6상한에 막히지 않음. 일반 투사체64/설치체24/소환 한도3은 유지. 포화 시 발사를 생략하며 런타임 추가 할당 없음.
- 근접/직선빔/즉시사슬/회복/방패/장판은 임의로 복제하지 않는다. 무작위 장판으로 바뀐 투척무기는 실제 전달 방식에 맞춰 제외. 증강 후보 조건/안내도 같은 분류 사용.

## 투사체 표시

- 용사 공통 투사체: 캔버스 지름24px→일반56px·탄환44px, 폴백도 같은 크기. 한 프레임당 크기 계산 대신 발사 시 표시 반지름 캐시. 원본 프레임 비율/중심과 애니메이션 유지.
- 원거리 소환수 기본탄은 용사모드에서만 실제 알파 범위를 기준으로 비행52px/적중56px에 맞춤. 새 몬스터 임프·주술사 탄의 표시도1.5배 확대.
- 확대는 렌더링만. 용사 공통 명중 반지름12px·소환수 기본탄30px·사거리·피해·히트 판정은 유지. 기존 관통포/운석의 자체 표시는 유지.
