# 이자나미 뽑기 컷신

## 실행
Godot에서 `src/dev/IzanamiCutscenePreview.tscn`을 열고 F6. 컷신만 /1회 결과 /10+1 초월3개 순서 메뉴. 합성된 표시 결과만 사용하고 추첨·골드·지급·저장 API를 호출하지 않습니다.

현재 이자나미는 MonsterCatalog/실제 뽑기 대상에 없습니다. 이번 변경은 공통 컷신 Catalog 등록과 표시/결과 연결입니다. 이후 플레이어블 등록 시 기존 일반·픽업 확정 결과에 monster_id=izanami/rarity=transcendent를 전달하면 자동으로 재생합니다. 확률·픽업 가중치·보상 정책은 변경하지 않습니다.

## 연출과 리소스
5초/세로 유지:0–1s 신사/실루엣,1.05–2.3s 위부터 본모습 공개,0.7–2.4s 기도 충전,2.4–3.6s 손에서 영적 기운 방출,3.8–4.3s 하단 작은 이자나미 이름,5s 기존 결과 공개. 전신/무릎/옷끝과 이름 간 여백 유지. 큰 얼굴 줌·초월 글자 없음.

ZIP README/manifest 기준11개768×1280 원본 PNG 보존, 합성 픽셀 차이0. 원본 조립 이미지의 공통 UV 메시로 경계가 연결된 상태를 유지하고 원본 파츠 마스크로6영역 바람 가중치를 지정합니다. 머리·왕관·기도 손·무릎은 고정, 머리카락/소매/하단 옷만 작은 국소 리깅. 전신 scale로 호흡을 만들지 않습니다. Cubism/완전한 Live2D 모델은 아닙니다.

큰 머리 회전·팔을 벌리기·눈뜨기에는 가려진 머리/목/어깨/옷 바탕, 관절 겹침과 분리된 눈꺼풀/열린 눈/입 추가 PNG가 필요합니다. 동일768×1280좌표 유지. 현재 파츠를 프레임처럼 순차 재생하지 않습니다.

생성 배경·효과와 프롬프트/원본 출처는 assets/art/effects/gatcha/izanami/SOURCES.md. 실제 PNG만 사용, nearest 필터, 런타임Base64 없음. 효과는4개 정적atlas + 기존effect1/3프레임으로 캐릭터와 독립 재생하며 기도 손의 좌표에서 충전/방출합니다.

## 검증
`godot --headless --path . --script tests/izanami_cutscene_smoke.gd`.
정상 종료/스킵/취소/뷰 재사용, 일반·픽업 표시 결과11개 중1/5/9순서, 최종 결과와 원본 결과 불변,4비율 stagecontain/이름 여백, WAV/SFX/충전·방출 정리 검사. Fixture source/preload closure로 실제 컷신/결과 코드를 실행했습니다. 실제 이자나미 보상 계정 테스트는 콘텐츠가 미등록이라 적용되지 않습니다.
전체 앱/Android/export와 주관적 청감 미검증. 기존 headless 결과카드 shader compiler 경고는 남아 있습니다.

Linux OpenGL 실제 컷신 렌더 확인: 전신·하단 이름·실루엣 공개·효과/배경 확인.
