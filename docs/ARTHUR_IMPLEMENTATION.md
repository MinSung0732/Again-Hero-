## 전투 계약

- `arthur`: 초월 / 인간형 / 근접 탱커. 공격력170 + 실제 탱커 소환수×1.5, 체력2000 + ×15를 소환 직전에 고정한다. 이동300, 공격간격1.75, 게이지150, 증강 포함 지휘력 회복량으로 초당 최대15 회복.
- 실제 탱커40회 소환과 아군50회 사망을 모두 달성해야 전투당 한 번 소환된다. 증강·분열 소환은 성장/탱커 조건 제외, 사망은 기존 집계에 포함한다. 로컬 해금은 테스트 조건만 충족하며 성장 카운터를 조작하지 않는다.
- 등장 보호막: 현재 생존 아군 모두에게 아서왕 최대HP20%를 최초 physics 한 번에 부여한다. 예열용 비활성 인스턴스에서는 부여·소리를 실행하지 않는다.
- 엑스칼리버50/50초: 10초 강화, 0.5초 정신집중과 오른쪽 게이지, skill_01 유지. 직선1000거리/900속도. 선분 판정으로 고속 이동 누락을 방지하고 각 돌진에서 대상당 한 번250% 피해, 아군에는 아서왕 최대HP15% 보호막. 용사와 활성 적 소환수 모두 판정한다. 공격간격은 강화 중1.8로 나누며 정신집중/돌진 도중에도 대기시간이 진행되어 완료 후 불필요한 추가 대기를 붙이지 않는다.
- 5초월: 추가 두 번의 돌진은 첫 피해의80%이며 무적을 무시한다. 빠른 후속 돌진 속도는1350으로 정했다. 주 대상에 세 번 모두 적중하면 잃은HP15% 회복. 충돌 레이어/마스크는 돌진 종료·강제 이동 중단·사망 시 복원한다.
- 원탁100/100초: 1초 정신집중, 게이트30초, 반지름600(지름1200)의 얇은 선과 수명바. 생성01~05 / 유지05~06 / 소멸07~08. 무적·비대상 Node2D.
- 게이트 안 아군: 공격속도+50%, 이동속도+25%, 주는 공격 피해+50%. 5초 주기 시작 체력을 기준으로 잃은HP5%를 5초에 나누어 회복한다. 주기 시작 시 최대 체력이면 현재HP5%의 보호막으로 전환한다. 원탁 강화 인원당 아서왕 공격력+0.45%. 공격력 증가를 피해 배율로 적용해 영구 성장/증강의 원본 능력치를 훼손하지 않는다. 나가거나 사망·만료·씬 종료하면 버프를 해제한다. 3초월은40초/소모80.
- 축복40/50초: 지름500 안 자신 포함 아군 각각의 최대HP100%,3초. 문구의 최대체력은 보호막 수령 대상 기준으로 해석했다. 4초월은170%,5초. 일반 중첩 보호막과 별도 수치로 먼저 흡수한다. 피해로 전부 깨진 경우 원래 축복 용량50%를 파괴자에게 한 번 반격한다. 시간 만료는 반격하지 않는다.
- 가호:15%,1초월30%,2초월 이후50% 확률 피해 방어. 보상·사망 처리는 기존 공통 초월 경로를 사용한다.

## 확장성과 성능

게이트는 공간 그리드를0.2초마다 조회한다. 반환 후보는 실제 반지름으로 다시 검사한다. 후보/탈퇴 배열을 재사용하고 신규 진입자만 Dictionary/WeakRef를 만든다. 보호막 컴포넌트는 수령자당 한 번 생성해 재사용한다. 돌진은 재사용 후보와 대상ID 집합으로 중복 타격을 막는다. 전체 아군 순회는 등장 최초 한 번뿐이다. 효과 프레임과 오디오는 기존 정적 캐시, 고정 AudioStreamPlayer를 사용한다.

일반 몬스터의 기존 한 인자 피해 API는 유지한다. 공통 `damage_monster_from`으로 피해 소스를 잠시 보존해 슈텐도지 안개·만티코어 등장폭발·상태 피해가 축복을 부술 때 실제 시전자에게 반격한다. 스코프 종료 후 메타를 원래 상태로 복원한다. 상태 결과/행동당 집계 계약은 변경하지 않는다.

## 연출·획득 연결

- 실제 뽑기 결과 → 기존 공통 컷신 → 아서왕 뷰. 푸른 성당의 실루엣, 원탁12개의 빛, 성검의 서약과 금빛 공개, 이름.
- 원본768×1280 재조립 일러스트를 공유 메시로 변형한다. zip의 리본·머리카락·양쪽 망토·하단 옷6개 가시 파티션은 가중치 마스크로만 사용한다. 얼굴·손·다리 원본을 보존한다. 완전한 Cubism Live2D 모델이 아니라 기존 프로젝트와 같은 Godot Bone2D/Polygon2D 리그다.
- 실제 전투 소환 후 우하단 삼각형, 전신→눈감기→얼굴 확대→눈뜨기→전신/이름. 눈은 원본 UV에서 런타임 눈꺼풀 shader로 처리한다. 월드 성광은 시각 전용이며 추가 피해를 주지 않는다. 공통 카메라·슬로우·스킵·재사용·중단 복원 흐름을 사용한다.
- 도감 일러스트, 팀편성/도감 기술4개 아이콘, 상점 일반 초월 풀/로컬 확정 뽑기 목록, 해금 시 프로필 아이콘/배너 모두 Catalog에 연결.
- 5초월 배너는 아서왕·불가살·이자나미·슈텐도지 추가. 기존 제우스·만티코어와 합쳐6종 모두 조건5에서 표시된다. 컬렉션 기반 기존 세이브에도 별도 중복 지급 없이 적용한다.
