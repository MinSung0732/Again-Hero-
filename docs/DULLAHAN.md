# 망령 기사 / Dullahan

전설 · 언데드 · 탱커 · 근접 · 코스트 12. 기존 Dullahan 일반/엘리트 원본 도트를 그대로 사용한다.

## 임시 밸런스

기본 HP 420 / 이동속도 58 / 공격력 32 / 공격 간격 1.2초 / 사거리 88 / 처치 EXP 90.
실전에서는 기존 전설 등급 보정, 수집·연구·마왕 레벨 및 증강을 적용한다. 수치 확정 전 플레이 밸런스 조정이 필요하다.

## 기본 동작

- 개체당 한 번, 사망 애니메이션과 역재생 후 최대 HP의 15%로 부활한다. 부활 과정은 최종 사망·처치 EXP·환급으로 집계하지 않는다. 두 번째 사망은 기존 정산을 따른다.
- 실제 대상 HP/보호막에 준 피해의 40%만큼 회복한다. 무적 등으로 거절된 피해·초과 피해로 회복하지 않는다.
- 위험감지: HP 20% 이하, 쿨 20초. 이속 +225% = 기본의 3.25배로 이탈한다. 거리 300 도달 또는 지형 때문에 2초 경과 시 휴식으로 전환한다.
- 휴식 중 3초에 걸쳐 최대 HP 50%까지 회복하고 다시 전투한다. 휴식 중에도 피해를 받으며 사망할 수 있다. 생존한 경우 종료 시 회복 목표까지 보충한다.

## 특수증강

| 이름 | 효과 |
|---|---|
| 망자의 성벽 | 접근 이속 -30%. 용사에게 첫 실제 피해를 주기 전 최대 HP 200% 보호막. 획득 시 한 번 부여하며 증강 갱신이나 부활로 재충전하지 않는다. 최대 HP 변경 시 남은 보호막 비율을 유지한다. |
| 열두 원혼의 족쇄 | 공격 적중마다 대상별 스택을 모든 망령 기사가 공유한다. 12스택 소모 시 2초 기절. |
| 불멸의 갈망 | 부활 HP 30%, 피해 회복 비율 50%로 대체. 부활 횟수는 그대로 한 번. |

기절은 용사의 이동·공격·스킬 진행과 몸 애니메이션을 멈춘다. 상태저항으로 지속시간이 감소하고 재적용은 남은 시간과 새 시간 중 큰 값으로 갱신한다. 출혈·독·공포·둔화 지속시간과 무적 시간은 기절 중에도 진행한다. 이미 발사된 투사체·설치 효과는 유지한다. 기존 기절 도트 4프레임을 캐시해 표시한다.

## 엘리트

- 진격: 선쿨 10초 / 쿨 40초. 현재 자신 중심 반경 250에 해골 전사 또는 해골 궁병을 0.5초 간격으로 10마리, 5초 동안 소환한다. 전장 유효 영역으로 보정하며 기존 공통 스폰 경로를 사용한다. 소환 해골은 0레벨 기본 스탯을 고정 사용하며 수집 강화·영구 연구·마왕 레벨·일반/특수/전역 증강을 적용하지 않는다. 이후 성장 갱신에서도 제외된다. 소환 비용·직접소환 수·소환 EXP는 추가하지 않는다. 죽음 프레임 역재생을 모두 마친 뒤 행동한다. 피격은 역재생을 끊지 않지만 사망은 가능하다.
- 망령돌진: 소환 시 한 번. 5초간 대상 접근 속도 200% = 기본의 2배. 성벽 접근 페널티와 곱연산하며 위험감지 이탈에는 적용하지 않는다.
- 강타: 선쿨 5초 / 쿨 30초. 사거리 안 대상에게 0.35초 붉은 예고 후 공격. 공격 프레임 종료 시 사거리 안에 남은 대상에게 공격력 2배 피해와 1.5초 기절. 공격 종료 시 몸 색상을 복구한다. 대상이 사거리 밖이면 시전 대기를 유지한다.

## 연동

MonsterCatalog 등록으로 수집·편성·일반/특수증강·엘리트 이벤트·localtest 전체 해금에 연결된다. 전설 실제 뽑기 풀이 활성화된다. 목표 확률 30/30/30/9/1 중 비어 있는 희귀·초월을 제외하고 정규화하므로 현재 일반/고급 각 43.47826%, 전설 13.04348%다. 전설 조각 2~4개, 25개 해금 기준 및 보라색 연출은 기존 정책을 따른다.

## 검증

`tests/dullahan_smoke.gd`는 실제 Battle/Hero 스폰 경로에서 피해·흡혈·보호막·공유 스택·기절·회복·부활·엘리트 선쿨·1회 돌진·강타 애니메이션·10마리 순차 소환·역재생 행동 잠금을 확인한다. 가챠 정책/전환/문 연출과 상세정보 테스트도 수행한다. Windows Godot OpenGL 검증이며 Android 실행·장시간 밸런스 검증은 별도다.
