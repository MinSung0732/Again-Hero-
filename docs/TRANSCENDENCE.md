# 초월 등록

팀 편성의 세 번째 탭 `초월 등록`에서 전체1슬롯을 계정별로 저장한다. 다른 몬스터 등록은 기존1슬롯을 교체하며 등록 해제로 비울 수 있다. 소장 해금된 초월 등급(`rarity: transcendent`)이며 실제 소환 씬이 있는 몬스터만 등록 가능하다. 일반 팀 목록·일반 소환 슬롯·이전 일반 편성 세이브에서는 제외한다. 상세정보와 조각 강화는 기존 기능을 사용한다.

사용자 첨부의 설녀·발키리·드래곤·사도는 디자인 예시다. 제우스는 초월 수집·뽑기·등록용 뼈대로 추가되었다. 원본 도트 미리보기만 연결했으며 `combat_enabled=false`일 때 조건 해금과 실제 전투 생성은 차단된다. 능력치·기술 구현 후 전투를 활성화한다. 기존 희귀 설녀와 고급 늑대의 등급/능력치는 변경하지 않는다. 실제 몬스터 추가 시 MonsterCatalog의 기존 ORDER/MONSTERS에 등급·씬·도트·설명을 등록하고 아래 규칙을 설정하면 전용 목록과 전투가 연결된다.

## 개체별 조건

MonsterCatalog 항목에 선택적으로 `transcendence` 데이터를 둔다. 생략 시 기본값은 다음과 같다.

```gdscript
"rarity": "transcendent",
"transcendence": {
    "mode": "any",
    "conditions": [
        {"metric": "monsters_summoned", "amount": 200},
        {"metric": "mana_spent", "amount": 500},
    ],
},
```

`any`는 OR, `all`은 AND다. 한 조건만 두거나 각 수치를 바꿀 수 있다. 알 수 없는 지표/모드, 비양수 목표, 빈 조건 목록은 발동하지 않는다. 추가 지표는 TranscendenceRuntime의 집계/판정과 Catalog의 설명을 확장한다.

- `monsters_summoned`: 이번 전투에서 실제 생성에 성공한 일반 군단 개체 수. 직접 소환·추가 소환·마왕 기술/지원 군단을 포함한다. 준비용 도트 예열, 용사 소환물, 슬라임 분열 개체, 초월 소환은 제외한다. 소환 실패·상한/지휘력 부족은 집계하지 않는다.
- `mana_spent`: 이번 전투에서 성공한 마왕 기술이 실제로 소모한 마력 총량. 지휘력 소모/마력 획득/실패한 기술은 포함하지 않는다.
- 전투 시작 시 등록ID를 스냅샷하고 두 집계와 사용 플래그를 초기화한다. 이번 전투의 조건 해금과 계정의 몬스터 소장 해금은 별개다.

## 전투 버튼

미등록/조건 미달이면 버튼은 보이지 않는다. 조건을 처음 달성하면 전투 영역 오른쪽 화면 밖에서144×156 논리픽셀의 도트·문구 버튼이0.24초 슬라이드로 들어온다. 기존 금색 픽셀 프레임을 사용한다. 우측 정보 버튼과 하단 소환 영역을 가리지 않으며 터치가 카메라 이동/일반 수동 소환으로 전달되지 않는다.

등록 몬스터는 전투당1회만 실제 소환한다. 성공 시 버튼을 숨기고 사망해도 다시 소환할 수 없다. 지휘력은 기존 해당 몬스터 코스트 계산을 사용하며 일반 추가 소환·거대화로 복제하지 않는다. 비용 부족·모달 일시정지·증강 선택·전투 종료·개체 상한·씬 실패는 사용권을 소모하지 않는다. 일반/자동 군단 생성 경로에서 초월 몬스터를 직접 생성할 수 없다. 추후 초월 콘텐츠의 무료 소환/특수 비용 규칙이 정해지면 별도로 데이터에 확장한다.

등록 화면은1슬롯 요약, 안내, 레벨 양방향 정렬,2열 스크롤 목록을 제공한다. 소환 조건은 실제 몬스터 데이터에서 설명하며 등록/상세/강화는 버튼으로 조작한다. 미해금 카드는 어둡게 표시하고 등록/강화는 제한한다.

## 성능과 검증

집계는 실제 생성 성공/마력 소모 이벤트에서만 갱신하며 전체 그룹 검색이나 매 프레임 조건 배열 생성을 하지 않는다. 런타임은 이번 등록 개체의 조건만1회 복사한다. 조건 해금 신호는1회만 발생한다. 전투 버튼/트윈은 재사용하고, 등록 목록은 화면 열기·등록/강화/정렬 시에만 재구성한다.

`python tests/run_transcendence_smoke.py <Godot 실행파일> [--native]`는 배포 빈 목록과 임시 테스트 콘텐츠를 차례로 검증한다. 임시로 기존 설녀·늑대의 카탈로그를 테스트용 초월로 바꾸고 실행 후 원본 바이트를 finally에서 복구한다. 편집기나 다른 카탈로그 작업과 동시에 실행하지 않는다. 테스트 세이브는 임의의 격리 게스트 폴더를 사용한다.

검증 범위: 빈 화면, 전체1슬롯 교체/해제·비초월 거절·일반 편성 저장 제외·전용 목록·탭 전환,200개체/500마력 OR와AND 경계, 잘못된 규칙, 실제 소환에 따른 해금·실제 마력 사용 해금, 버튼 최초 숨김/슬라이드/터치 차단, 일시정지 시 사용권 보존, 실제 비용/1회 소환/중복 거절·일반 생성 우회 방지·새 전투 초기화. Windows Godot4.7.2 실제 네이티브 화면 확인 및 기존 편성 터치/정렬·로비 모드·증강 갱신·설녀·늑대 회귀 확인. Android 실기기와 실제 초월 전투 밸런스는 미검증이다.
