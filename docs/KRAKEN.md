# 크라켄

- 전설 / 짐승 / 원거리 / 코스트 15. 기본 HP 155, 공격력 66, 이동 0, 공격 간격 5초, 반경 1000. 엘리트가 없는 대신 높은 기본 공격력. 등급·연구·수집·마왕 성장 보정은 기존 공통 계산 적용.
- 모든 소환 경로에서 용사 기준 유효 최대 사거리 원 위에 배치. 전장 경계 때문에 원 위에 둘 수 없는 경우 32개 방향 중 유효한 최장 거리 선택. 고정형은 자력 이동하지 않음.
- 공격 시작/1초/2초에 촉수. 매 타격 시 현재 대상 위치 반경 100 안에 즉시 소환, 판정 반경 115. 공격 총합을 3회에 분배하며 정수 나머지를 앞 타격에 분산. 투사체 없음. 범위 이탈 시 그 회차는 빗나감.
- 실제 HP/보호막 피해 3회마다 개체별 공격력 +0.1% 누적. 분수 배율을 보존하고 최종 공격력만 반올림. 증강·레벨 재계산 뒤에도 성장 유지. 사망 일격은 성장 제외.
- 사망 시 죽은 본체 반경 155의 8방향에 촉수 즉시 생성, 각 공격력의 1/3 피해. 용사 위치를 따라가지 않으며 기존 용사 무적시간이 연속 피해를 제한.

## 특수증강

1. **심연 잠항**: 대상이 반경 220 접근 시 개체당 1회. dead 1→4 후 반대 방향 최대 사거리 배치, dead 4→1 종료 후 전투. 진행 중 공격 취소, HP 유지, 피해 면역 없음.
2. **촉수의 대홍수**: 공격력 2배, 2초간 6촉수(0.4초 간격). 공격 총합을 6분할.
3. **심해의 거신**: 체력·공격력·공속·사거리 2배, 본체 크기 1.5배, 이동 0 유지. 모든 소환 경로에 생존 3개체 제한. 기존 4개체 이상 상태에서 획득해도 강제 제거하지 않으며 3 미만이 될 때까지 추가 소환 제한. 차단 시 자원·EXP 없음. 코스트·보상·증강 발동 거리·분산 반경은 능력치 배율에 포함하지 않음.

촉수 SpriteFrames는 사전 캐시, 반복 이펙트는 Battle transient pool을 사용. 개체 수는 생성·사망·트리 이탈 레지스트리로 추적. 원본 에셋은 수정하지 않음.
