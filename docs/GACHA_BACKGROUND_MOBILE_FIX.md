# 모바일 초월 뽑기 배경 채움 수정

불가살/이자나미/만티코어/슈텐-도지/아서왕의 배경 Sprite2D가540×960 무대 안에 고정되어 있었다. 무대는 `min(width/540,height/960)`로 화면에 모두 들어오게 맞추므로9:16보다 긴 모바일 화면 또는 넓은 태블릿에서 환경 이미지에 빈 띠가 생겼다. 제우스 및 공통 fallback 플레이어는 이미 전체 Control 크기로 배경을 cover한다.

`cutscene_background_layout.gd`의 공통 함수가 화면 중심/크기를 기존 무대 좌표로 역변환하고 PNG 가로세로 비율을 유지하는 cover 배율을 적용한다. 캐릭터 무대의 contain 배율/위치와 이름·기술효과·타이밍은 유지한다. 환경 이미지의 일부 가장자리는 화면 비율에 맞게 잘리지만 빈 띠는 남기지 않는다. 아서왕의 반투명 배경 셰이더도 동일 화면 영역을 채우도록 맞춘다.

다섯 뷰의 기존 resized→_layout 경로에 연결하여 최초 표시/크기변경/재사용에 적용한다. 이미지 누락 또는0크기/0배율에서 나눗셈을 하지 않는다. PNG·스킵·보상·확률·재화·제우스·전투 소환/사망 연출은 변경하지 않는다. 크기 변경 때만 계산하고 렌더 핫패스에 새 배열/텍스처 생성은 추가하지 않는다.
