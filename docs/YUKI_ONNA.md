# 설녀

희귀 / 인간형 / 제어 / 코스트5.5. 기본 HP100, 이동100, 공격12, 공격주기1.6초, EXP30. 공격 사거리 지름400은 중심 반경200으로 처리하며 투사체속도250, 이동거리248이다. 업로드된 일반·엘리트 도트와 각각8프레임 투사체를 사용한다. 뽑기·수집·팀 편성·일반증강은 기존 카탈로그 경로를 공유한다.

## 기본 공격과 둔화

- 실제 HP 또는 실드 피해가 발생한 적중만10% 둔화를 추가한다. 무적에 막힌 공격, 중복 충돌, 체력이 없는 무적 소환물에는 적용하지 않는다.
- 모든 설녀가 대상별 중첩을 공유한다. 기본 최대10중첩, 증강 시15중첩. 기본 이동계수는 `0.9^중첩수`이며 기존 다른 둔화 계수와 곱해진다.
- 미지정 지속시간은5초로 정했다. 적중 시 전체 중첩의 단일 타이머를 갱신하며 최대중첩에서도 시간을 갱신한다. 한기로 강화된 타격은 해당 타격의 둔화 강도를 곱해 저장한다. 발사 후 원본 설녀가 삭제되어도 투사체는 유지된다.
- 기존 용사 둔화 저항을 강도·시간에 적용한다. 일반 둔화와 설녀 둔화는 각자 만료되므로 다른 효과를 지우지 않는다. 용사 모든 이동 경로와 이동하는 용사 소환물에 반영한다.

## 사망 전달 한기

- 설녀 사망 시 반경250 안의 다른 살아 있는 설녀에게 한기1중첩. 미지정 주변 범위는250으로 정했다. 각 중첩은 독립적으로5초 유지하며 기본 최대5중첩, 증강 시8중첩이다. 최대중첩에서는 추가하거나 기존 시간을 갱신하지 않는다.
- 중첩마다 공격속도×1.10, 투사체속도×1.05, 둔화 강도×1.02. 곱연산 요청에 따라 둔화효과+2%는10%→10.2%로 해석했다. 예:5중첩의 둔화는 타격당 `10% × 1.02^5`이다.
- 한기는 능력치 원본을 변경하지 않고 유효 공격주기와 발사 시점 투사체에 적용한다. 증강·성장 능력치 갱신 중에도 보존된다.
- `freezing_frames/freezing_01..04.png`를 사용한다. 기존 실제 불투명 픽셀 범위 캐시로 몸 크기에 맞추며 상태 종료 시 숨긴다.

## 특수증강

| 이름 | 효과 |
|---|---|
| 영원의 한기 | 한기 최대중첩+3 (5→8) |
| 끝없는 겨울 | 둔화 최대중첩+5 (10→15) |
| 삼중 설풍 | 공격마다 중심·좌우15도 부채꼴 투사체3개 |

각 증강은1회 선택하며 일반·엘리트에 함께 적용한다. 세 투사체는 각자 실제 충돌 대상에게 정상 공격 피해와 둔화를 적용한다.

## 엘리트 패시브 설화

대상에 설녀 둔화가 최대중첩이면 살아 있는 엘리트 설녀가 즉시 발동한다. 마지막 공격자가 엘리트면 해당 개체, 아니면 대상과 가장 가까운 살아 있는 엘리트를 선택한다. 별도 발동 사거리·쿨다운은 없으며 이미 최대중첩인 대상에 엘리트가 새로 생겨도 다음 런타임 갱신에서 발동한다.

중첩을 전부 소모하고 선택된 엘리트의 현재 공격력200% 피해 및2초간99% 둔화를 적용한다. 같은 적중 직후 생긴 피격 무적이 추가 피해를 버리지 않도록 기존 후속 타격 피해 경로를 사용한다. 일반 피해 경감·실드 계산은 유지한다. 발동 피해 자체는 둔화를 다시 쌓지 않는다. 99% 둔화 중 새 중첩을 모을 수 있으며 두 설녀 효과 중 더 강한 이동계수를 사용한다. 용사 둔화 저항은 여기도 적용된다.

## 성능과 검증

전투 전용 설녀/엘리트 등록부, 사망 좌표 공간 그리드, 재사용 버킷으로 사망을 일괄 처리한다. 전체 그룹 검색을 하지 않으며 중첩이 가득 찬 개체는 주변 검색을 건너뛴다. 한기 타이머는 개체당 고정8슬롯, 배율 거듭제곱은 중첩 수가 바뀔 때만 계산한다. 활성 둔화 대상만 갱신하며 반복 제거용 배열을 재사용한다. 투사체 풀과 일반/엘리트 프레임 공유 캐시를 기존 전투 준비에서 예열한다. 용사 소환물의 새 생명 세대 번호로 재사용 시 이전 둔화/이펙트를 즉시 제거한다. 전투 모달 정지와 새 전투 reset을 따른다.
