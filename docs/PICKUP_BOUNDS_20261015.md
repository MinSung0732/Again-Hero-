# 용사모드 아이템 이동 경계 — 2026-10-15

첨부 화면의 상단 성벽에 자석이 배치되는 문제. 회복/자석의 무작위 생성은 Y150부터지만 성벽이 있는 전장의 Hero는 `190 + 190/2 + 72 = 357` 위로 이동하지 못한다. 경험치 역시 몬스터 사망 좌표 그대로 떨어지며 분산 속도로 벽을 넘을 수 있었다.

`src/systems/pickup_placement.gd`가 Hero의 `_get_battlefield_movement_bounds()`를 직접 읽고 Battle 로컬 좌표에서 보정한다. 새로운 Y 상수로 벽/영웅과 별도 규칙을 만들지 않는다. 다른 맵에서도 현재 영웅의 실제 Rect를 사용한다. 용사모드만 적용한다.

- Battle의 회복/자석/상자/경험치는 생성 즉시 영역 내 배치한다.
- 아이템을 외부에서 생성한 경로도 첫 물리 틱에 한 번 보정한다. 상자는 한 번 처리 후 물리 업데이트를 끈다. 경험치는 풀 setup마다 이 검사를 재설정한다.
- 경험치 분산/일반흡인/전체자석 이동 후에도 경계 내 좌표를 유지한다. 긴 프레임이나 높은 흡인 속도로 용사 반대편 성벽을 넘어간 뒤 남는 경우를 막는다.
- 연금술 가마솥의 회복 아이템, 재료 생성/착지도 같은 함수로 보정한다. 비행 중 포물선 연출은 유지한다.
- 전체 아이템 그룹을 매 프레임 스캔하지 않는다. 정지한 아이템은 위치검사를 반복하지 않는다. 경험치 위치 이동이 있는 구간에만 상수시간 보정한다. 수량·생성주기·회복·EXP·자석 시간·마왕모드의 기존 좌표는 유지한다.
