# 아누비스 구현 및 밸런스

전설 / 신인형 / 폭발 / 근접. 생산비용24. 밸런스 감사 기준 원본 HP472, 공격25, 이속35, 공격간격4초, 사거리80, 경험치65. 등급·마왕레벨·연구·일반증강 배율은 기존 소환 경로에서 적용한다. 매우 높은 체력과 기존 낮은 공격력을 함께 유지하기 위해 밸런스 계산만 방어형(tank) 예산으로 적용하고, 몸체지분0.7142857143/화력지분0.25로 설정했다. 게임 역할은 폭발을 유지한다. 기존 코스트12→24는 높은 체력·희생성장·분노·사망쉴드의 기여를 고려한 조정이다. 전설 전투 배율 적용 시 HP약576, 공격약31(마왕/연구/강화 전). 실전 승률은 검증하지 않았다.

## 군단 시너지

- 카탈로그 이름에 `미라`가 포함된 살아있는 아군 모두를 센다. 미라/미라 주술사, 일반/엘리트/분열 소환 포함, 거리 제한 없음.
- 한 마리마다 HP·공격력·이동속도·공격속도 원본 대비5% 가산. 사거리·경험치·비용은 늘리지 않는다. 스탯 갱신은 원본에서 재계산하며 현재 체력 비율을 보존한다. 인원 감소 시 같은 방식으로 하락한다.
- 미라 한 마리마다 시각적 크기0.3% 가산, 화면 점유 방지를 위해 표시3배 상한. 충돌 크기는 그대로다. 일반/엘리트 기본 표시높이191.8/219.2(기존140/160의137%), 비율 동일 확대.3배 상한은 미라 생존 인원에 의한 표시성장만 제한하며, 희생/분노 크기 증가는 별도 배율로 적용한다.
- 아누비스 이름 포함 생존 개체(자신/엘리트 포함)가10/20/30 이상일 때 전투스탯 배율0.9/0.8/0.5. 구간 배율은 누적하지 않고 교체한다.
- 미라가 실제 사망할 때 생존 아누비스마다 근거리쉴드15·원거리쉴드20 중첩. 트리에서 조용히 제거된 미라에는 쉴드를 주지 않는다. 동일 사망/트리 이탈은 한 번만 처리한다.

## 특수 증강 — 셋 중 하나

| 이름 | 앞으로 미라 사망 때 생산 | 현재 잔여 쉴드 임계 |
|---|---|---|
| 사막의 장막 | 원거리35 | 원거리300 |
| 수호자의 갑주 | 근거리35 | 근거리300 |
| 영혼의 결계 | 일반17.5 | 일반200 |

임계 이상이면 네 전투스탯25% 상승, 임계 미만으로 소모되면 해제한다. 해당 종류의 외부 쉴드도 잔여 총량에 포함한다. 기존 쉴드를 소급 변환하거나 다른 아군이 부여하는 쉴드를 바꾸지 않는다. 17.5는 소수 생산량을 이월하여17/18씩 지급한다. 후보 생성과 실제 선택 모두 배타 그룹을 확인한다. 기존 타몬스터 증강의 복수 선택은 유지한다.

## 엘리트 — 사념 중첩

선쿨/재사용0의 지속 패시브. 공격마다 고정7 누적, 첫 공격은 기본공격+7, 둘째는 기본공격+14. 누적 부분은 공격력 배율에 곱하지 않고, 기본타격과 한 근거리 피해로 전달하여 피격 무적 때문에 별도 추가타가 누락되지 않게 한다. 대상의 기존 피해감소·쉴드·무적은 유지한다. 미라 생존 한 마리당 추가 공속3% 배율을 일반 시너지와 곱한다. 누적은 개별 아누비스 수명 동안 유지한다.

## 엘리트 — 아누비스의 분노

선쿨10초/CD30초.7초간 표시크기15%, HP·공격·이속·공속30% 상승. 주황빛으로 상태를 구분한다. HP 갱신은 체력비율을 보존하며 종료 시 분노 배율만 해제한다. 희생 영구 증가와 미라/쉴드/군집 배율은 유지한다. 기절/침묵/강제이동 잠금 시 시전하지 않는다. 지속 중 재시전은 거부한다.

## 엘리트 — 희생하거라

선쿨3초/CD3초. 자신을 제외한 전장 생존 아누비스/미라(주술사·엘리트 포함) 한 마리를 등록순 순환 선택하여 정상 사망시킨다. 쉴드/피해감소로 희생이 막히지 않게 HP를0으로 하고 기존 사망 진입/신호/연출 경로를 호출한다. 따라서 Battle의 기존 사망 효과·EXP가 적용되고 미라 사망쉴드도1회 지급된다. 이미 사망/삭제 예정/다른 시전자에 예약된 대상은 제외한다. 대상이 없으면 재사용시간을 소모하지 않고0.5초 간격으로 대기한다.

- 아누비스 흡수마다 영구 전투스탯12%, 표시크기5% 가산.
- 미라 흡수마다 영구 전투스탯9%, 표시크기3% 가산.
- 예: 각각1마리 흡수 시 영구 스탯1.21배/크기1.08배. 이 합산 영구 배율에 미라 생존/군집/쉴드/분노 배율을 곱한다. 사거리·EXP·코스트와 사념 고정7은 성장시키지 않는다.
- 새 소환은 영구/임시 증가를 물려받지 않는다. 희생 후 생존 인원도 감소하므로 해당 생존 시너지/군집 페널티를 다시 계산한다.

## 성능 및 에셋

카탈로그 이름을 초기화 때 분류하고 소환/사망/트리 이탈 레지스트리를 유지한다. 전투 재시작에 초기화, 전투 도메인 일시정지에 갱신 중지. 프레임마다 최대8리더를 순환 확인하고 값이 달라질 때만 스탯/시각자료를 갱신한다. 미라 사망은 해당 생존 리더에 즉시 전달한다. 희생은 이 레지스트리의 지속 WeakRef 후보목록에서만 선택하고 새 그룹 스캔이나 후보배열을 만들지 않는다. 사망 신호/트리 이탈/희생 후 fallback retirement는 동일ID에 멱등 처리한다. 매 프레임 전체 몬스터 그룹 스캔은 추가하지 않는다.

기존 `assets/art/monsters/anubis/frames` 22프레임과 `assets/art/elitemonster/anubis/frames` 23프레임을 사용한다. idle4/move6/hit3/death4 공통, 일반attack5/엘리트attack6. 원본 PNG를 수정하지 않는다. 인원/희생/분노 크기 갱신은 Visual.scale만 바꾸어 공격/사망 애니메이션과 공유 SpriteFrames를 유지한다. 상태바는 공통 최신 버프 위쪽 적재 경로를 사용하며 노란게이지는 만들지 않는다.
