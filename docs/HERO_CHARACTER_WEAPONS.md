## 화면과 저장

캐릭터 편성 상단은 선택한 용사의 초상/이름/성향/6무기 소개다. 하단은 3열 카드·10종 목록이며 하단만 스크롤한다. 잠긴 카드는 조건을 표시하고 선택을 거부한다. 메인 용사 선택 버튼은 제거했으며 메인 초상은 편성한 용사다.

`hero_loadout.hero_id`와 `hero_loadout.battle_stage`를 별도로 저장한다. 기존 `hero_loadout.stage`는 과거 캐릭터 선택으로만 읽어 마이그레이션하고, 성장키 stage_N은 캐릭터의 출신 단계 키로 계속 읽는다. 캐릭터 선택이 전장/난이도를 바꾸지 않고 전장 선택이 캐릭터를 바꾸지 않는다. 용사 전장은 Stage1부터 연속 생존 승리로 순차 개방하며, 기존 성곽 붕괴 단계와 마왕 공세만 달라진다.

## 향후 용사 뽑기 확장

캐릭터 카탈로그의 안정적인 ID와 `hero_collection.<hero_id>` 소유권을 분리했다. 현재는 견습 기본/해당 어려움 클리어가 해금 원천이고, 소유권 플래그도 동일한 선택 검사에 반영된다. `HeroModeStore.set_character_owned_in_config(config,id)`는 ID를 검증하고 전달된ConfigFile에 소유권을 설정한다. 향후 뽑기 호출자가 통화 차감과 이ConfigFile을 기존AccountSaveScope.save_configs 트랜잭션에 함께 넣을 수 있다. 이번 변경은 소유권 훅이며 실제 뽑기 상품·확률·중복 조각·결제는 추가하지 않았다.

## 효과와 검증 한계

60개는 개별 테마·소유권·성장 수치의 무기 정의다. 최신판은 시간차 연격·장전 속사·흡혈·정화와 실제 이계 소환수/마력 관통포/기둥/운석/소멸 배우를 연결한다. [최신 무기 구분과 검증](HERO_SURVIVAL_REVISION_20261013.md). 아래 공용10유형 설명은 초기 구현 이력이다. 60개의 신규 무기 선택용 도트 아이콘과8개의 보조 아이콘을 생성·아틀라스로 연결했다. 원본 고유기술 애니메이션을60개 재현한 것은 아니다. 기존 캐릭터 도트/초상을 재사용하고 공용10종 공격 유형(표적·검격·관통·광역·연쇄·회전·방벽·장판·냉기·회복)의 재사용 효과를 적용한다. 약병별 장판 지속/간격/범위, 소환 수호체의 수/회전 속도/반경도 데이터로 구분한다.

정적 데이터 연결·GDScript 구문·diff 및 Godot4.5.1 headless 캐릭터편성121/성장1041검사 통과. 실제 HeroMode 가로카드의 화면내배치/아이콘/정지재개도 검증했다. 실제 렌더·터치·10종×전장 조합·15분 밸런스·모바일 성능은 미검증이다.

## 공용 보조 증강 — 8종 중 최대6종

| 종류 | 레벨당 효과 | Lv10 효과 |
|---|---|---|
| 공격력 증가 | 전체 무기 피해 +8% | +80% |
| 이동속도 증가 | 시작 속도 +3% | +30% |
| 투사체속도 증가 | 실제 발사체 속도 +10% | +100% |
| 공격속도 증가 | 전체 무기 빈도 +5% | +50% (대기시간 ÷1.5) |
| 경험치 증가 | 획득EXP +3% | +30% |
| 경험치 범위 증가 | 시작 획득반경 +15% | +150% |
| 최대체력 증가 | 시작 최대HP +5% / 증가분 회복 | +50% |
| 받는피해 감소 | 받는 피해 -3% | -30% |

기존5종 ID는 유지한다. 현재 생존무기의 발사체형(`bolt`/`burst`)과 실제 마력 관통포에 투사체속도가 영향을 주며 즉시 검격·장판·연쇄에는 적용되지 않는다. 체력/이속/획득반경은 영구성장 적용 후 시작값을 기준으로 가산한다. 일반/상태/후속 피격은 보조감소를 한 번 적용하고 이미 방어 계산된 피해는 다시 감소하지 않는다.
