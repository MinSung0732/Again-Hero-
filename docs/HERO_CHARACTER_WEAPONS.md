# 용사 전용 무기 6종 / 캐릭터 편성

현재 10종 용사 × 전용 무기6종 = 60종이다. 기존 용사 기술 전체를 공용 증강으로 변환하던52종 정의를 대체한다. ID·소유 용사·스타터·레벨/진화·효과 유형·쿨타임·범위·피해·타격 수는 데이터에 두고, 런타임은 해당 용사의6종만 후보/습득에 허용한다. 보조 증강5종은 공용이며 무기3/보조3·Lv10 상자진화 규칙은 유지한다.

## 화면과 저장

캐릭터 편성 상단은 선택한 용사의 초상/이름/성향/6무기 소개다. 하단은 3열 카드·10종 목록이며 하단만 스크롤한다. 잠긴 카드는 조건을 표시하고 선택을 거부한다. 메인 용사 선택 버튼은 제거했으며 메인 초상은 편성한 용사다.

`hero_loadout.hero_id`와 `hero_loadout.battle_stage`를 별도로 저장한다. 기존 `hero_loadout.stage`는 과거 캐릭터 선택으로만 읽어 마이그레이션하고, 성장키 stage_N은 캐릭터의 출신 단계 키로 계속 읽는다. 캐릭터 선택이 전장/난이도를 바꾸지 않고 전장 선택이 캐릭터를 바꾸지 않는다. 용사 모드에서는1~10 전장이 자유 선택이며, 기존 성곽 붕괴 단계와 마왕 공세만 달라진다.

## 향후 용사 뽑기 확장

캐릭터 카탈로그의 안정적인 ID와 `hero_collection.<hero_id>` 소유권을 분리했다. 현재는 견습 기본/해당 어려움 클리어가 해금 원천이고, 소유권 플래그도 동일한 선택 검사에 반영된다. `HeroModeStore.set_character_owned_in_config(config,id)`는 ID를 검증하고 전달된ConfigFile에 소유권을 설정한다. 향후 뽑기 호출자가 통화 차감과 이ConfigFile을 기존AccountSaveScope.save_configs 트랜잭션에 함께 넣을 수 있다. 이번 변경은 소유권 훅이며 실제 뽑기 상품·확률·중복 조각·결제는 추가하지 않았다.

## 효과와 검증 한계

60개는 개별 테마·소유권·성장 수치의 무기 정의다. 각기 다른60개의 신규 도트 이미지/원본 고유기술 애니메이션을 제작했다는 의미는 아니다. 기존 캐릭터 도트/초상을 재사용하고 공용10종 공격 유형(표적·검격·관통·광역·연쇄·회전·방벽·장판·냉기·회복)의 재사용 효과를 적용한다. 약병별 장판 지속/간격/범위, 소환 수호체의 수/회전 속도/반경도 데이터로 구분한다.

정적 데이터 연결·GDScript 구문·diff 검사 통과. 회귀 스크립트는 작성했으나 Godot 실행파일이 없어 실행하지 않았다. 실제 레이아웃·터치·10종×전장 조합·15분 밸런스·모바일 성능은 미검증이다.
