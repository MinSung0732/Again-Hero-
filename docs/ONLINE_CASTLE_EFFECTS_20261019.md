# 온라인 마왕성·투사체·추가 공격 PNG — 2026-10-19

## 변경

- `stage1_battlefield.gd`의 기존 배치·텍스처 처리·바닥 손상·벽·왕좌·기둥을 표현 전용으로 재사용한다. 기본값은 기존 충돌체 생성이며, 온라인 클라이언트만 충돌체 생성을 끈다. 배치 설정을 복사하지 않는다.
- matched 패킷에서 기존 stage/bounds를 준비하고 ready를 보낸다. 같은 전장 descriptor면 정적 노드/명령을 재사용한다. 초기 배경 준비는 1회 동기 처리이므로 실제 모바일 입장 시간은 측정 필요하다.
- 기둥/왕좌는 원래 접지점 Y로 캐릭터와 정렬한다. 클라이언트 UI 위치/축척을 제거한 월드 좌표를 캐시한다. 배경은 뒤쪽 레이어, 깊이 장식은 캐릭터 명령과 함께 정렬한다.
- Battle의 온라인 활성 투사체 레지스트리를 acquire/풀 복귀/tree exit에 연결한다. 거미줄·해골 화살은 원본 PNG/프레임/변환을 전달한다. 전체 그룹·전투 트리 반복 검색 없이 활성 목록만 샘플링한다. 기존 용사 고유 풀과 중복 수집하지 않는다.
- 공통 beam/capsule/slash/combo/orbit PNG 어댑터 추가. 크기 계산은 기존 렌더링 수식을 공유 함수로 옮겼다. 전투/피해/판정/증강/AI 수식·원본 PNG는 변경하지 않았다.
- protocol 4: PNG 명령에 접지점 Y 1개 추가(22필드), 검증된 stage/bounds descriptor 전달. 서버와 두 게임 모두 업데이트/서버 재시작 필요. 기존 명령128/텍스처512 제한과 바디 우선순위 유지. 정적 장식 명령은 클라이언트에서 1회 생성한다.
