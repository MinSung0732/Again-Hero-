# 원형 피해 범위·사전예고 조사 (2026-10-09)

범위 탐색/버프/소환 위치 반경과 실제 원형 피해 판정을 구분한다. 이번 패치는 기존 준비·비행·퓨즈 시간에 시각 예고만 연결했다. 공격 지연, 피해, 대상, 판정 중심이나 증강 계산은 바꾸지 않는다. 모든 공격에 사전예고가 완성된 상태는 아니다.

## 이번 적용

| 공격 | 예고 구간 | 표시와 판정 |
| --- | --- | --- |
| 폭탄쥐 자폭 | 기존 자폭 퓨즈 | 개체 중심, 실제 explosion_radius와 화약 과부하 증가량 공유. 스케일을 역보정해 월드 반경 유지 |
| 엘리트 고블린 투척병 폭탄 | 비행부터 기존 퓨즈 종료까지 | 확정된 target_position, 실제 explosion_radius. 폭발/풀 반납 시 표시 종료 |
| 불가살 강철도약 | 기존 정신집중부터 | 현재 자리 반경125. 이후 기존 상승/공중/낙하 착지 예고 유지. 정신집중 취소 시 종료 |
| 연금술사 기본 독병 | 기존 곡선 비행 | 확정 landing_position, poison_radius×압축 범위 증강. 착지 후 기존 독장판으로 연결 |

공통 CircularAttackTelegraph.draw_area는 전체 피해 경계의 얇은 원, 옅은 채움, 시간 진행 호를 그린다. 주황은 몬스터 기술, 푸른색은 용사 기술. 기존 전투 tick/풀을 사용하고 매 프레임 노드 생성·그룹 탐색은 추가하지 않는다. 폭탄쥐 경고는 생애에 한 번 만든 고정 자식 draw층에 표시한다.

## 기존 표시 또는 후속 작업 대상

| 실제 공격 경로 | 현재 상태 / 후속 작업 |
| --- | --- |
| 불가살 바위던지기 | 기존 스냅샷 중심 내/외 반경150/300 예고 유지 |
| 불가살 돌기둥 여진·전략후퇴 | 즉시 파괴 시 반경150 피해. 준비 시점과 개별 기둥 피해 중심을 구분한 후속 예고 필요 |
| 크라켄 연속 촉수·사망 촉수 | 현재 공격 시점에 산개 위치 확정/즉시 피해. 위치를 미리 고정하거나 피해를 늦추는 별도 설계 없이 사전예고를 추가할 수 없음 |
| 전갈 사멸의 독늪 | 생성된 지속 장판 반경 원과 실제 tick 피해가 이미 연결됨 |
| 엘리트 해골 궁병 화살비 | 기존 telegraph_delay와 반경 선 유지 |
| 현자 별빛 유성·소멸점·빙주 | 기존 낙하/생성/지속 반경 표시 경로 존재 |
| 현자 흑점 폭발 | 애니메이션 DAMAGE_FRAME4에 원형 피해. 프레임1~3 사전예고 후속 적용 대상 |
| 연금술사 대성공 병·혼합 장판·긴급 폭발 | 기본 독병과 다른 피해 반경/즉발 또는 설치 방식. 이번 독병 표시를 이들에게 재사용하지 않음; 별도 후속 대상 |
| 대마법사 빙결탄/빙주·화염 충전·지면 돌기 | Hero의 resolve_archmage_ice_bolt_hit/_resolve_archmage_ice_pillars/_cast_archmage_combustion/_cast_archmage_earth_spikes에 실제 반경 피해. 충돌 즉발과 시간차 공격을 구분한 후속 대상 |
| 일반 용사 기본탄 광역/대마법사 지면탄 | 충돌 위치가 피해 중심인 splash. 고정 착탄점 예고와 다르므로 후속 대상 |
| 정화 용사 구체·프리즘 폭발·정화 중심 | 구체 자체 blast_radius 표시는 기존 존재. 체인/프리즘/정화는 별도 확정 시점 조사 후 후속 대상 |
| 이계 용사 자폭 드론 | 근접 도달 즉발 폭발, 반경100. 기존 도달 판정을 보존하면서 준비 시간 추가 여부 별도 설계 필요 |
| 권총 용사 실린더·날렵한 용사 연속공격/회전베기·광기의 용사 기술4 | Hero의 실제 원형 피해 경로. 이동 중심/즉발 시점을 구분한 후속 대상 |
| 검방 용사 돌진 착지·가드 해제·원형 궁극기 | 도착/해제/즉발 중심 피해. 준비 상태와 피해 시점 연결을 별도 조사할 후속 대상 |

메두사 오라, 설녀 냉기 공유, 늑대 울부짖기, 전갈 섭취, 고블린 지휘, 듀라한 소환 반경은 피해 원이 아니므로 위험 범위 예고 대상으로 취급하지 않는다. 제우스 심판/천둥구체는 현재 Hero1개에게 즉시 피해를 주는 단일 타깃 경로이며 사거리나 낙뢰 이미지 크기를 AoE 피해 반경으로 표시하지 않는다.

## 제우스 표시

CombatEffects는 월드 Z8 고정층으로 대상 몸체보다 앞에 그린다. 심판/천둥구체 방출은 공격 시점 Hero.get_combat_feet_position()에 고정하며, 용사 profile의 GroundShadow 위치를 바닥 접촉점으로 사용한다. 없는 타깃은 원점 fallback. 피해는 기존 Hero에 그대로 적용한다. 천둥가르기 표시 크기는130×1.75이며 속도650, 거리1500, swept hit radius32는 유지한다.
