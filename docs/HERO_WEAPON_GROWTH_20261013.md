# 용사 무기별 성장·상자 진화 — 2026-10-13

기준 로컬/원격 작업 브랜치 `feature/stage10-astra` / `af4ee14e9eeea2b9876a2b1b374df61f60199063`, 최신 원격 main `52052c6d9b986d290a63ca41edb28b92ba72924a`. main 병합 없음. 기존의 공통 Lv5/10 타격 수 증가와 모든 무기 동일 상자 진화 효과를 아래 규칙으로 대체한다. 60종 ID/소유 용사별6종/무기3칸·보조6칸/EXP·15분·전장 해금·저장·보상·마왕 AI는 유지한다.

## 성장과 진화

기본 피해 `1+0.18×(무기Lv-1)`, 탐지 사거리 `1+0.035×(Lv-1)`, 재사용 `1-0.035×(Lv-1)`은 유지한다. 기존 공통 `base_hits+floor(Lv/5)` 대신 무기별 Lv3/6/10 패치를 적용한다. 연격/연사, 도탄 증폭, 폭발, 복수 장판, 재타격, 회복/보호막/정화, 소환수 속사·연격·집중 강화 등 고유 기능이 달라진다. Lv2/4/5/7/8/9는 기존 기본 수치 성장이다. 모든 레벨마다 새 기믹을 하나씩 추가하는 규칙은 아니다.

Lv10에 도달해도 즉시 진화하지 않는다. 상자를 열면 미진화 Lv10 보유 무기 하나를 우선 진화시킨다. 없으면 기존 무기+1레벨, 모두 완성되면 HP25% 회복. serial/중복 적용 방지·룰렛 중앙 결과와 실제 지급 일치를 유지한다. 고유 이름과 강한 기능을 주고, Lv10 대비 기본 피해+30%/재사용-10%를 보탠다. 이전 공통 피해×1.8/타격+2/범위+25%/CD-20%는 제거한다. 네이티브 운석·기둥·소멸의 반경+25%는 각 프로필에 명시했다.

새 데이터는 `hero_weapon_growth_catalog.gd`에 모았다. 원본 Catalog와 별도로 성장 패치를 누적 병합하고, 무기 레벨 또는 진화가 바뀔 때만 결과를 캐시한다. 이미 발사된 탄/장판/재타격은 시전 당시 데이터를 보존한다. 카드에는 Lv3/6/10과 진화 이름, 무기 상세에는 진화 효과, HUD/룰렛에는 실제 진화 이름을 표시한다. 상자 설명은 결과에 해당하는 짧은 문구로 제한해 기존620높이 모달을 유지한다. 기존 PNG/SFX를 재사용하고 새 자산·런타임 Base64 디코딩은 추가하지 않았다.

## 실제 판정과 상한

- 원본 도적 연격 길이는 임시 보너스를 넣어 실제4/5/6타로 변경한다. 대현자의 고유 관통탄 주기는3→2→진화1로 바뀌며 원본 설정은 호출 후 복원한다. 대마법 원소 순환/마지막 원소 중복 회피·마력, 권총12발 공유탄창/장전, 광기/부활, 화학 가스/재료/변신을 유지한다. 레벨이 올라도 탄약·가스 없이 공격하지 않는다.
- 후속 파동은24개 고정 슬롯, 최대3회/시전·16대상/회. 폭발은12대상 상한, 폭발에서 폭발로 재귀하지 않는다. 기본탄 폭발은 원래 표적을 제외해 주변만, 마지막 연격/속사 폭발은 마지막 실제 적중 시 표적까지 타격한다. 표적이 죽거나 사거리 밖으로 벗어나 마지막 탄이 소실되면 그 탄의 마무리 폭발도 없다.
- 2~5방향 광선은 모든 광선에 같은 geometry를 적용한다. 겹친 광선은 한 표적을1번만 때린다. 각 광선/파동/폭발은 실제 중심·원형 반경/검격각/광선폭/회전 띠와 표시가 일치한다. 그리드의 넓은 후보는 최종 판정에서 거리와 도형을 다시 확인한다.
- 장판은 기존8슬롯에서 최대3개를 측면에 배치하며 각 원을 직접 그린다. 포화 시 추가 생성을 생략해 살아 있는 장판을 덮어쓰지 않는다. 기존64발/48효과·원본 관통4/기둥3/운석6/소멸2 풀을 유지한다. 매 프레임 배열/Dictionary 생성, 전체 그룹 탐색, 새 instantiate/free 경로를 추가하지 않는다. 기존 피해 숫자 풀의 지연 준비는 기존 경로다.
- 실제 이계 소환수 총3체·스냅샷/원본 풀 유지. 원본 augment 설정 생성기가 후속타/집중 값을0으로 재계산하므로 최종 activate 직전에 **용사 성장 override가 있는 설정만** 병합한다. 마왕 설정에는 이 키가 없고 기존 수치/동작을 유지한다. 성장 config의 깊은 복사는 업그레이드 시점에만 추가된다. 원본 helper의 기존 시전당 snapshot 복사는 유지한다.

## 수치와 검증 한계

[300행 예산 스냅샷](HERO_WEAPON_GROWTH_BUDGET_20261013.tsv)은 각60종의 Lv1/3/6/10/진화를 기록한다. 1타 ATK배율·CD·탄/기술 배우 수·장판 지속/간격/수·후속 파동/배율·소환 지속을 분리했다. 마지막 열은 패턴별 명목 합계다. 장판 지속시간/틱과 연격 수, 연쇄 증폭, 후속 파동을 합치지만 **광역 대상 수·폭발 주변 적 수·모든 네이티브 평타·소환수 실효 DPS·탄창/가스·치유/보호막·포화·빗나감·이동·치명타·캐릭터 고유 버프/영구 성장·원본 기술 후속 상태**는 합산하지 않는다. 단일 표적 실측 DPS/전체 피해 상한/승률로 사용할 수 없다.

예: 마력탄은 기본1발→Lv3 2발→Lv10 3발/폭발30%→진화5발/폭발65%이며, 1타 배율은1→1.36→2.62→3.406이다. 도탄은 연결마다 배율을 누적하고, 화학은 다중 장판·틱·수명이 늘어 총량이 더 크게 증가한다. 서로 다른 무기를 동일 DPS로 맞춘 패치가 아니며, 강한 진화와 고유 기능의 구현을 우선한다. 실제15분 완주/10종×10전장/빌드별 난이도와 모바일 부하는 추가 플레이 검증이 필요하다.

Godot4.7.2 실제 프로젝트에서 신규 통합1,479검사 PASS: 60종 Lv3/6/10/진화 실제 cast·원본 배우 수·소환 설정·고유 평타·실제 상자1회 적용, 공간그리드 폭발/파동 경계±1·광선 겹침1회·지연/포화·연쇄 증가·60종 진화 모달 배치. 기존 성장1,041/표시943/60기술344/고유기믹182와 진행·저장실패/중복·보상 회귀 및 마왕 용사·몬스터 검사도 통과했다. 실제 OpenGL540×960에서 성장 카드와 화학 진화 결과를 캡처해 확인했다.

구문/import·`git diff --check` 수행. 기존 raw PNG fallback/Windows 실제UI와 Git의ui 경로 대소문자 경고/종료 리소스·빈Tween 경고가 남아 있다. 이번 작업에서 실제 청감·15분 완주·Android 터치/성능/export·클라우드 검증은 하지 않았다. 테스트 결과는 그 검증을 대신하지 않는다.

재현: `godot --headless --path . --script res://tests/hero_weapon_growth_smoke.gd`, `godot --headless --path . --script res://tools/hero_weapon_growth_audit.gd`. 캡처는 headless 없이 통합 테스트에 `-- --capture`를 붙인다. 격리 게스트 저장소를 사용하고 실제 계정 진행은 건드리지 않는다. 롤백은 이번 커밋 revert.
