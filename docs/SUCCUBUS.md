# 서큐버스

- 전설 / 인간형 / 제어 / 근접 / 코스트13.5. 초기 수치: HP240, 공격28, 이속155, 공격 간격0.65초, 사거리76, 처치EXP70. 값은 `succubus_behavior_catalog.gd`에 보관하며 기존 성장·일반증강·수집·가챠 정책 적용.
- 제공되어 있던 일반 idle4/walk6/atk6/hit3/dead4, 엘리트 idle4/walk6/atk5/hit2/dead5/skill1 프레임 재사용. 새 캐릭터 그림이나 매혹 이펙트는 생성하지 않음.

## 매혹

- 실제 피해(HP+실드)를 준 타격마다 용사별 공유 스택1. 일반·엘리트 서큐버스 모두 같은 스택을 사용하며15회에 소비, 마지막 타격 개체가2초 매혹의 접근 대상이 됨. 기본공격·절개·왈츠 타격 모두 적중으로 계산. 무적에 막힌 타격은 스택/피해 누적 없음.
- 기본공격과 새 기술 시전 봉인, 채널링 종료, 시전자에게 이동. 매혹 동안40% 둔화(이미 걸린 더 강한 둔화는 보존), 다른 서큐버스를 포함하여 매혹 대상에15% 추가 피해. 이미 발사된 투사체와 설치된 지속 피해는 유지.
- 사용자 확인: 공유15스택, 매혹 **종료 후**7초 면역. 면역 중에는 스택을 쌓지 않음. 시전자 사망·삭제로 접근 대상이 사라져도 매혹을 종료하고 면역 시작. 프로필 교체·사망 시 상태 초기화. 다른 행동 제어 중에도 매혹/면역 시간 경과.
- 기절·공포가 접근 이동보다 우선, 석화는 이동을 고정하지만 매혹의 공격·기술 봉인은 유지. 유체화가 이미 활성화되었으면 시간 만료와 안전 위치 복구를 계속 처리. 용사 아키타입 분기 전에 공통 제어, 연속 추가 시전도 차단. 쿨다운 속성 목록은 매혹 진입 때 캐시.

## 잠입·특수증강

- 개체마다1회: 치명 피해를 받으면 HP최소1로 생존하고3초 잠입. 이동·공격·새 엘리트 기술·강제 이동 봉인, 피해 무시, 알파0.4. 잠입 동안 모든 용사·소환수의 타겟/현재 전황/회피 판정에서 제외하며 기존 타겟·유도 추적도 해제. 과거 관측 기억과 이미 발사된 공격은 유지. 충돌 레이어·마스크를0으로 하고 충돌체/소프트 분리를 비활성화한 뒤3초 종료 시 진입 전 설정으로 복구. 몬스터 등록과 성장·아군 버프는 유지. 실드가 먼저 흡수하고 남은 피해로 HP 조건 판단. 왈츠 중 잠입 진입 시 왈츠 취소.
- **그늘의 안식**: 진입 시 현재HP를 최대HP30%까지 회복(30%를 더하는 방식 아님).
- **그림자 반격**: 잠입 해제 후 공격력20% 상승. 개체 성장 배율로 재계산하며 레벨/증강 변경에도 유지, 중복 곱하지 않음.
- **위기의 장막**: HP30% 이하로 조건 변경. 여전히 개체당1회이며, 치명 피해에도 생존 가능. 증강 선택 시 이미30% 이하이면 다음 물리 틱에 발동.

## 엘리트 기술

- **절개** 선쿨0초/재사용15초: 용사 뒤로 순간이동 후 공격력150% 타격. 장식물·성벽이 막으면 근처16방향의 안전한 대체 위치를 검사. 맵 내부 및 용사와 최소48 간격을 보장, 안전 위치가 없으면 시전하지 않고0.25초 후 재시도.
- **정기흡수** 선쿨6초/재사용20초: 이전 흡수 이후 실제 타격 피해(HP+실드) 누적의55% 회복하고 누적값 소비. 피해가 없거나 행동 잠금이면0.25초 재시도. 회복은 최대HP를 넘지 않음.
- **유혹의 왈츠** 선쿨10초/재사용60초:2.5초 동안 알파0.5 은신/받는 피해50% 감소. 사용자 확인에 따라0.5초마다5회 랜덤 각도 순간이동, **총 공격력200%**를 누적 반올림 방식으로 분배. 매혹 추가 피해와 일반 방어·실드·무적 판정 적용. 실제 준 피해의40% 회복. 막힌 타격 예산은 이후로 이월하지 않음. 일반공격/다른 엘리트 기술은 동시 실행하지 않음.
