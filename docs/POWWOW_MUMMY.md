# 미라 주술사

희귀 / 언데드 / 원거리 / 코스트 4.5. 기본 0레벨 HP62, 이동속도44, 공격력5, 공격 간격2초. 사거리 지름475(반경237.5), 투사체속도275, 비행거리285.5. 기존 등급/수집/연구/마왕/증강 성장과 원거리 공통 이동 AI를 사용한다. 기존 powwowmummy 일반/엘리트 및 투사체 에셋 재사용.

## 버프 시전

- 첫 시전 대기20초, 이후20초 주기. 무작위 버프 하나를 자신을 제외한 살아 있는 아군 한 개체에 적용. 버프 사거리는 별도 제한 없음. 아군이 없으면 시전을 건너뛰고 다음 주기로 넘어간다.
- 용기: 공격력+15%를10초간 적용하고 최대HP10% 실드 부여. 공격력은 같은 버프와 합산하지 않고 기간 갱신. 실드는10초 뒤 제거하지 않고 피해로 소진될 때까지 유지하며, 재시전 시 기존 잔량과 새 용량 중 큰 값으로 갱신(합산 없음). 기존 미라/망령 기사/엘리트 실드와 별도로 먼저 흡수한다.
- 회복: 현재 잃은HP의5%를 반올림하여 즉시 회복. 최대HP 비율이 아니다.
- 날렵: 이동속도+50%를10초간 적용. 동일 버프 중첩 없이 갱신하고 기존 둔화/고유 이동 배율과 곱한다. 고정형의 이동속도0은 유지한다.
- 버프 선택은20초 시전 때만 살아 있는 몬스터 레지스트리에서 표본을 선택한다. 매 프레임 전체 그룹/몬스터 스캔 없음. 공통 버프 관리자는 효과를 가진 대상만 순회하며 재사용 만료ID 배열을 사용한다.
- 강화/일반 버프가 겹치면 더 강한 효과·더 긴 남은 기간을 유지한다. 공격력 성장/증강 재계산 시 버프를 한 번만 곱하고, 종료 시 최신 성장 공격력으로 복원한다. 폭탄쥐는 폭발 피해에 용기 배율을 적용한다.

## 시전 / 사망 비주얼

시전 중0.4초간 이동/기본공격을 멈추고 skill 애니메이션을 재생한다. 일반은 현재 skill_01~03만 있어 마지막 skill_03을 한 단계 더 유지해4단계를 구성한다. 엘리트는 실제 skill_01~04를 사용한다. 버프 대상 전용 이펙트는 아직 연결하지 않는다.

일반/엘리트 모두 사망 시 idle_01을 고정하고0.55초 페이드아웃한 뒤 제거한다. 기존 파일에 있는 죽음 프레임은 요청에 따라 사용하지 않는다. 사망 신호/보상/레지스트리 정리는 기존 경로를 유지한다.

## 특수증강

1. **불굴의 찬가**: 용기 효과+50%. 공격력+22.5%, 실드 최대HP15%. 지속시간10초 유지.
2. **재생의 기도**: 회복 효과+100%. 잃은HP10% 회복.
3. **신속한 의식**: 버프 주기20→15초. 기존 남은 대기에서도5초 차감하며 재설정으로 중복 차감하지 않는다.

## 엘리트 — 다중시전

주기마다3종 버프를 서로 다른 아군에게 하나씩 시전한다. 아군이3개체 미만이면 존재하는 개체 수만큼 서로 다른 종류를 무작위로 나누고 동일 개체 중복 시전은 하지 않는다. 시전자 자신은 대상에서 제외한다. 신속한 의식으로 엘리트도15초 주기가 가능하다.

기본 투사체로 실제HP/실드 피해를 준 경우 다음 버프 대기시간-1초, 최소0초. 무적에 막히거나 충돌 없이 소멸하면 감소하지 않는다. 투사체는 캐시/풀링하고 시전자 약한 참조를 초기화한다. 시전자가 사망한 뒤 남은 투사체는 명중 피해를 주지만 대기 감소는 하지 않는다.
