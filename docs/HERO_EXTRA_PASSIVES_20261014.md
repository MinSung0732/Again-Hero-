# 영웅 보조 증강 추가 — 2026-10-14

지속 보조 장착은 최대 6종이다. 기존 8종에 아래 8종을 추가해 전체 후보는 16종이다. 즉시 회복은 장착형이 아니며 부상 시 다시 선택할 수 있다.

| 증강 | 한 번 선택한 효과 | 한도/조건 |
| --- | --- | --- |
| 피해량 흡수 (피흡) | 실제 피해의 0.5% 회복 | 10레벨, 총 5%; 소수 피해 흡수는 누적 |
| 둔화 저항 | 저항 +4%p | 추가 최대 40%p, 기존 저항과 합산 후 85% 상한 |
| 사거리 증가 | 사거리 +4% | 10레벨, 원거리 영웅만 |
| 즉시 회복 | 최대 HP의 25% 회복 | 생존·부상 시, 보조 칸/레벨 없음 |
| 투사체 피해량 | 투사체 무기 피해 보너스 +6% | 10레벨, 원거리 영웅만 |
| 공격 범위 | 범위 공격 반경·폭 +5% | 10레벨, 표시와 판정 함께 확대 |
| 투사체 개수 | 발사체 +1개 | 2레벨, 최대 추가 2개; 투사체 무기 보유 필요 |
| 무기 지속시간 | 장판·소환·보호막 지속 +5% | 10레벨; 즉시 공격 애니메이션/장전 제외 |

날렵한 용사·검과 방패의 용사·광기의 용사는 근접으로 분류한다. 이들은 투사체 속도·사거리·투사체 피해 증강을 받지 않는다. 투사체 개수는 근접이라도 bolt/burst/piercer/meteor 패턴 무기를 보유하면 후보가 된다. 선택 후보와 직접 적용 경로 모두 제한을 검사한다.

피흡은 MonsterHitContext를 통과한 공격의 실제 HP 감소를 사용한다. 과잉 피해와 자기 자신에게 반사된 피해는 회복을 늘리지 않는다. 기존 무기 자체 흡혈과 별도로 적용한다. 활성 피흡이 없으면 HP 차이 조회를 생략하며, 소환/발사체 소유자는 기존 부모/참조로 찾는다. 그룹 전체 순회나 새 노드 생성이 없다.

범위는 원형·검격·빔 폭·궤도·폭발·후속 파동에 연결했다. 소환 설정은 캐시 복사본의 사거리와 지속시간을 조정한다. 변경된 효과는 이후 발동에 반영되며 이미 발동한 공격은 발동 당시 값을 유지한다. 기본 네이티브 발사체의 추가 발사는 기존 64개 일반 투사체 풀을 사용한다. 그 외 네이티브 공격도 기존 풀 한도를 유지하므로 포화 상태에서는 추가 발사가 일부 제한될 수 있다.

신규 카드 아이콘은 역할에 맞는 기존 아틀라스 칸을 공유한다. 증강 설명은 이번 선택 효과와 현재 누적 보너스를 표시한다.
