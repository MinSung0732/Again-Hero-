# 전갈

- 일반 / 짐승 / 물량 / 근접 / 코스트3. 일반 가챠·수집·팀 편성·일반증강·특수증강·엘리트 선택에 공통 Catalog로 연결. localtest는 기존 전체 Catalog 해금 규칙 적용.
- 기본값: HP48, 이속145, 공격4, 공격 간격0.65초, 근접 판정 반경58, 처치 EXP18. 기존 등급·수집·마왕 레벨·증강 보정 이후 실제 능력치로 전투. 스탯은 `scorpion_behavior_catalog.gd`에 둔다.
- 기존 Scorpion 일반/엘리트 프레임을 수정 없이 사용. 일반 idle5/walk6/atk5/hit4/dead3, 엘리트 idle4/walk7/atk6/hit3/dead3. 중독은 기존 용사 중독 도트 표시를 재사용. 섭취 전용 이펙트는 추가하지 않는다.

## 기본 중독

- 실제 기본공격으로 감소시킨 HP와 흡수된 실드 합계만큼 10초에 걸쳐 한 번 더 피해. 막힌 타격은 중독을 만들지 않는다. 누적 반올림 방식으로 마지막 틱까지 정확한 기록 피해량을 분배하며, 다시 방어/받는 피해 배율을 적용하지 않는다.
- 같은 개체의 동일 타격 채널은 중첩·갱신되지 않고 만료 후 다시 적용 가능. 다른 전갈은 독립 중독. 공격한 개체가 죽거나 삭제돼도 기록된 중독은 유지한다. 기존 공통 중독의 무적시간 무시 규칙 적용.

## 특수증강

1. **속효성 맹독**: 새로 부여하는 중독의 지속시간을3초로 변경. 총 피해는 동일하며 이미 걸린 중독을 갱신하지 않는다.
2. **쌍독침**: 공격력+20%, 지연된2타 추가. 2타는 기존 무적시간을 무시하고 정상 방어/실드 판정 후 별도 채널로 중독 부여. 사용자 승인에 따라 개체별1타·2타 중독을 각각 독립 유지하며 각 채널 내 중첩·갱신 금지. 2타 시점에 대상이 사거리 밖이면 빗나가며, 전갈 사망/행동 잠금 시 후속타 취소. 지연은0.12초와 현재 공격 간격45% 중 작은 값으로 섭취 후 고속 공격에서도 후속타 누락 방지.
3. **사멸의 독늪**: 전갈 사망 위치에 지름150(반경75)의 테두리로 범위 표시. 3초 동안 사망 시 개체 공격력의200%를 분배,0.5초 틱. 해당 틱에 범위 안의 용사에게만 피해를 주며 밖에서 놓친 피해를 나중에 몰아서 주지 않는다. 개체별 독늪은 독립 피해. 원본 개체 삭제 후에도 유지하고3초 뒤 표시/로직 종료. 일반 상태 피해 경로로 무적시간을 무시하며 현재 방어/실드 판정 적용.

## 엘리트 — 약육강식

- 선쿨3초 / 재사용7초. 사용자 승인 기준: 반경250 안의 가장 가까운 **일반 전갈1마리**를 섭취. 자기 자신, 다른 엘리트, 대형 전갈, 이미 죽은/삭제 예정 개체 제외. 대상 없음/행동 잠금은 섭취 실패, 준비 상태를 유지하며0.25초 뒤 재탐색.
- 대상은 즉시 HP0/사망 상태가 되고 전투 레지스트리에서 제거. 기존 죽음 애니메이션은 재생하지만 EXP 구슬, 킬카운트/마왕 전투 기록/용사 처치 패시브, 회복·상자·자석 처치 진행, 처치 기록을 발생시키지 않는다. 사망 지휘력 환급과 사멸의 독늪은 일반 사망과 동일하게 발동한다.
- 대상의 최대HP·공격력·이동속도·초당 공격횟수를 섭취 시점에 스냅샷 합산. 임시 용기 공격 배율/날렵 이동 배율 및 실드, 사거리, 코스트/EXP, 증강/엘리트 기술은 흡수하지 않는다. 추가HP만큼 현재HP도 증가하며 기존 잃은HP는 유지.
- `공격 간격 = 1 / (자체 초당 공격횟수 + 흡수한 초당 공격횟수 합계)`. 섭취량은 개체별 영구 가산값으로 보관하여 마왕 레벨/일반·특수증강 재계산 후에도 유지하고 중복 곱하지 않는다. 자체 엘리트 보정도 재계산 때 보존.

## 성능·검증

- 섭취는 공간 격자와 재사용 후보 배열 사용. 독늪은 활성 구역만 순회하며, 만료 시 배열 끝 원소로 교체·제거하여 대량 만료에도O(n²) 이동 방지. 범위 테두리는 공통40점 캐시 및 기존 Line2D 풀 사용. 몬스터 그룹·타깃·충돌체로 등록하지 않는다.
- `tests/scorpion_smoke.gd`: 실제 Battle 소환, 가챠/수집/일반증강 등록, 중독 기간/예산/중첩 금지/무적/실드/출처,2연격, 독늪 피해/사망 위치/반경/출처 삭제/외부 무피해/풀 재사용, 섭취 선쿨/반복쿨/보상 제외/레지스트리/성장·증강 보존 검사.
- Windows Godot 실행 및 메두사 중독/주술사 공통 버프/가챠 정책/전체 상세정보 UI 회귀 검사. Android 미검증.
