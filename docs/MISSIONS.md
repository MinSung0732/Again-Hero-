# 도전과제 일일·주간미션

기준 feature/stage10-astra `bf9e0e3a0bc4ede4affdf19a68d9d941c4cf599f`. main은 유지.

## UI / 보상

왼쪽 도전과제(`daily`) → 중앙 고정 모달. 상단 일일/주간 탭, 초기화 안내, 카테고리 아이콘·목표·보상·진행도·게이지, **현재 탭 모두 받기**. 이벤트 도구(`weekly`)는 그대로 이벤트이며 주간미션은 도전과제 안에 있음.

| 카테고리 | 일일 목표 | 골드 / 연구 | 주간 목표 | 골드 / 연구 |
| --- | ---: | ---: | ---: | ---: |
| 소환 | 100마리 | 150 / 10 | 500마리 | 500 / 50 |
| 뽑기 | 1회 | 100 / 10 | 10회 | 600 / 60 |
| 마력 사용 | 100 | 150 / 10 | 1,000 | 500 / 50 |
| 스테미너 소모 | 15 | 150 / 20 | 100 | 700 / 70 |
| 연구 획득 | 50 | 100 / 10 | 1,000 | 700 / 70 |
| 전체 완료 합계 | | **650 / 60** | | **3,000 / 300** |

기존 첫 클리어 골드1,000·반복 클리어3,000보다 일일 총 골드를 작게 잡아 전투 수입을 대체하지 않음. 일일 연구60은 탐색 최대 연구300보다 작고 주간 연구300은 장기 보조 보상. 큰 주간 목표에는 상대적으로 높은 보상. 수치는 mission_catalog에서 조정.

- 완료·미수령 → 진행 중 → 수령 완료 순. 같은 상태는 카탈로그 순. 개별 카드 클릭 수령, 완료 카드만 활성화.
- 수령 완료 회색·비활성화·하단 이동. 아이콘도 desaturation 셰이더 적용. 모든 상태에서 현재/목표·게이지 표시.
- 모두 받기는 현재 탭의 호출 시작 시 수령 가능한 미션만 원자적으로 지급. 보상 연구가 다른 과제를 완료하면 다음 수령 대상으로 표시.
- 양쪽 탭 중 수령 가능 과제가 있으면 공통 도구 빨간점. 팝업 열기/수령/5초 체크포인트에서 갱신.
- 920×1160 중앙 고정, 작은 뷰포트 균일 축소. Galmuri11·명시적 줄바꿈·136px 행·좌우22px 내부 여백. 제목/탭/버튼 고정, 목록 별도 스크롤. 추가 탭은 가로 스크롤로 수용.
- 아이콘·카드·스타일·셰이더 캐시; 수령 후 생성/free 없이 상태/순서 갱신. 닫기/Esc/상위 탭 숨김 종료, 던전 스와이프 차단.

## 초기화 / 집계

한국시간 매일00:00 / 목요일00:00. `day=floor((unix+32400)/86400)`, Unix day0가 목요일이므로 주간키 `floor(day/7)`. 기기 타임존/DST 무관 O(1). 지난 기간 미수령 보상 소멸. 이전 날짜의 버퍼는 새 날짜에 넘어가지 않고 하루만 바뀌면 주간 진행은 유지.

| 이벤트 | 집계 | 제외 / 정책 |
| --- | --- | --- |
| 소환 | 생성 성공 직전: 직접·초월·마왕 포위 스킬·소환 시 슬라임/박쥐 추가 생성 | 실패, 사망 분열, 합성 재생성, 무작위 스테이지 증원, 튜토리얼/연습/LocalTestMode 제외 |
| 마력 | 마왕 스킬 성공 후 demon_ultimate_charge 차감분 | 실패, 소환에 쓰는 **지휘력**, 몬스터 마나, 테스트 제외 |
| 뽑기 | 저장 total_draws 실제 증가분 | 미리보기·실패 저장·조각 선물 제외. 10+1은 실제11회 |
| 스테미너 | claim_battle_entry 실제 입장권 확정 시 active_charged | 무료/중복/로딩 실패 전액 환불 제외. 조기 퇴장 부분 환불은 최초 확정 소비를 취소하지 않음 |
| 연구 | 저장 meta.research_points 양수 증가분 | 차감·실패 저장·클라우드 import 제외. 클리어/탐색/뽑기 변환/미션 보상 포함 |

전투 액션은 목표까지만 작은 카운터에 모아5초마다 저장. 전투 종료/scene exit/앱 백그라운드/종료 알림에도 flush. 정상 종료 알림 없이 강제 프로세스 종료하면 마지막5초 미저장 액션 손실 가능. 매프레임 저장·그룹 스캔·목록 정렬 없음.

## 구조 / 저장 / 리소스

mission_catalog(표시·목표·보상) → mission_ledger(순수 기간·집계) → mission_store(계정별 버퍼·수령) → MissionProgress(타이머) → lobby_missions_view(UI).

- stage_progress.cfg / missions.state에 저장, 기존 계정 bundle/클라우드 snapshot에 포함. 새 허용 파일/DB migration 불필요.
- AccountSaveScope가 실제 재화/뽑기/입장 변경과 집계를 같은 저장에 포함. 일반 쓰기는 최신 ledger를 보존하여 오래된 ConfigFile 재사용으로 진행이 지워지지 않음. MissionStore만 write_missions=true로 마커/전투 합산 수정.
- 지급·수령 마커 한 트랜잭션. 계정 실패 시 메모리/serial rollback, 게스트 기존 journal 재생. 실패 버퍼 유지, 손상 저장 덮어쓰기 방지. 호출자 ConfigFile을 수정하지 않아 재시도 중복 집계 방지.
- 계정 owner별 버퍼, 계정 교체 시 다른 계정으로 유출 방지. 현재 시각은 기기 Unix를 KST로 해석하며 서버 권위 시각/다중 기기 동시 수령 ledger는 기존 계층에 없어 추가하지 않음.
- 새 탭은 TABS 및 기간 규칙으로 확장, UI 탭 하드코딩 없음. 새 카테고리는 EVENTS/TITLES/목표·보상/아이콘/성공 이벤트 함께 추가.
