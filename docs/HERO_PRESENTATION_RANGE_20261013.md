## 연결과 UI

- BGM은 전장이 아니라 선택 용사의 `HeroCharacterCatalog.stage_for_hero()` 출신에 연결한다. 기존 전용 `Battle` OGG 한 곡만 복제해 loop=true로 재생하고, 도입/HP별 phase2/final 전환은 용사 생존에서 생략한다. 마왕 모드의 도입·HP 전환과 기존 음량/음소거/종료 페이드는 유지한다. 새 오디오/런타임 Base64 디코딩 없음.
- 생성 시트의 실제 아이콘은 균등 셀을 넘었다. 원본 PNG는 보존하고 불투명 연결 영역으로 60무기/8보조를 개별 추출, 128×128 셀에 최소10px 여백·nearest로 중앙 정렬한다. 정규화된 두 PNG와 원본 경계/실제 region manifest를 저장한다. 런타임은 기존 AtlasTexture 캐시만 사용하며 이미지 분석/크롭은 하지 않는다. 재생성 도구 `python tools/normalize_hero_augment_icons.py`는 Pillow/numpy를 사용한다.
- 상단에 기존 게임 로고·마왕과 같은 녹색 HP/파란 EXP 및 픽셀 바 배경을 연결한다. HP/EXP 수치·레벨·시계·처치·3무기·보조 요약 유지. 긴 보조 목록은 한 줄 말줄임/툴팁으로 HUD가 전장을 가리지 않게 한다.
- 룰렛은 중앙 900×620 모달, 3개 재사용 행/아이콘, 양옆 움직이는 화살표와 회전 반짝임을 사용한다. 2.4초 감속 종료 인덱스를 실제 receipt.id에 맞추고 마지막 중앙 이름·아이콘·실제 적용 대상을 일치시킨다. 진화/강화/완성 회복 모두 같은 경로, 기존 serial/일회 지급·일시정지/상자 큐를 유지한다. 결과 완료 함수 중복 호출도 무시한다.
