# 몬스터 밸런스 규격 v1 — 2026-10-11

## 목표와 적용 단위

강한 카드 하나로 모든 용사를 이기는 게임이 아니라 **물량으로 빌드 유도 → 탱커/제어로 공격 기회 확보 → 원거리/폭발로 마무리**하는 조합 게임을 유지한다. 이번 수치는 코드 분석을 기반으로 한 첫 정규화 패치이며, 실전 승률 검증을 마친 최종 밸런스는 아니다.

기준은 **마왕 레벨 1 / 몬스터 강화 0 / 연구 0 / 증강 없음**에서 등급 전투 배율까지 적용된 수치다. 같은 지휘력을 투자한 조합을 비교한다. 개체 하나의 단순 DPS나 1:1 승리만으로 순위를 정하지 않는다. 도감의 `get_base_stats`는 배율 적용 전 원본을 표시하고, 전투 상세정보는 기존 경로대로 배율/성장을 적용한다.

## 등급 기준

| 등급 | 비용당 기본 예산 계수 | 기본 강화 1레벨당 체력/공격 증가 | 의미 |
|---|---:|---:|---|
| 일반 | 1.00 | 2% | 저비용 역할 기준점, 물량·미끼 전략 |
| 고급 | 1.05 | 3.5% | 조금 더 안정적인 역할 수행 |
| 희귀 | 1.12 | 5% | 특정 조합/상황에서 우위 |
| 전설 | 1.20 | 7% | 복합 능력, 강점과 약점이 뚜렷함 |
| 초월 | 별도 설계 | 기존 1~5초월 기술 강화 | 해금에 투자한 군단의 결정적 전투 카드 |

강화 비율은 기존 값 유지다. 비용당 예산 계수는 **배율 적용 후 목표**이므로 기존 희귀(HP×1.10/공격×1.12/간격×0.96)·전설(HP×1.22/공격×1.25/간격×0.92) 배율을 역산해 원본을 만든다. 새 계수와 기존 배율을 이중으로 더하지 않는다. 실제 정수 피해·체력 반올림으로 미세한 오차는 생긴다.

## 역할 기준

| 역할 | 지휘력 1당 목표 체력 | 지휘력 1당 목표 직접 DPS | 설계 강점 / 약점 |
|---|---:|---:|---|
| 물량 | 24 | 2.7 | 총 압박·미끼 / 광역에 취약 |
| 탱커 | 28 | 1.2 | 몸체·쉴드·전선 유지 / 단독 추격·처치 약함 |
| 원거리 | 14 | 2.1 | 지속 화력 / 접근당하면 취약 |
| 제어 | 18 | 1.3 | 아군의 공격 가능 시간 확보 / 직접 화력 낮음 |
| 지원(밸런스 분류) | 18 | 1.2 | 치유·버프의 군단 기여 / 단독 화력 낮음 |
| 폭발 | 10 | 반복 공격형 2.4 / **1회 폭발 피해 16** | 제어와 연계한 순간 피해 / 반복 공격 불가·접근 실패 위험 |

이 값은 시작 예산이다. `health_share`, `damage_share`로 고유 능력의 기회비용을 반영한다. 허용 범위 0.25~2.0, 기본 1.0. 예: 등장 50% 쉴드가 있는 미라는 몸체 HP 예산을 낮추고, 흡혈·부활·휴식 회복이 있는 망령 기사는 몸체와 화력 일부를 줄인다. 독·상태이상·버프의 효율은 단순 체력/DPS 공식으로 정확히 자동 평가할 수 없어 검토 메모를 반드시 남긴다. 각 몬스터의 검토 계수/이유는 `monster_balance_catalog.gd`에 있다.

- 해골 전사: 2타가 각각 공격력 100%이므로 `cycle_damage_multiplier=2`.
- 늑대: 2타 합계가 공격력 100%이므로 계수 1. 하울링은 별도 기여.
- 크라켄: 3촉수 합계가 공격력 100%이므로 계수 1. 피해 분할 시간은 공격 타이머와 겹치므로 별도 2초를 더하지 않는다.
- 공격 동작이 끝난 뒤 재사용시간이 시작되는 신규 몬스터: `cycle_extra_seconds`에 실제 추가 동작 시간을 넣는다.
- 폭발 평가는 반복 DPS에 합산하지 않고 1회 피해/비용으로 한다. 반복 공격과 폭발을 함께 가진 신규 몬스터는 각각 별도 예산을 계산하고 `damage_share`/`burst_share`로 합산 기여를 검토한다.
- 미라 주술사는 게임 내 역할/AI 태그는 원거리로 유지하고, 밸런스 계산만 지원 예산을 사용한다.
- 자동 보정은 HP/직접 공격력(또는 자폭 피해)에 적용한다. 사거리·투사체·상태이상·동작·소환 수는 고유 설계로 유지한다. 공격 간격은 유효 범위 0.25~10초에서 보존하며 해당 간격에 맞춰 공격력을 역산한다.

## 초월 기준

비용이 0인 대신 해금 전 군단 투자가 있는 단발 소환이다. 일반 몬스터 비용 공식에 넣지 않는다. 기존 성장 계수, 누적 집계의 의미, 해금 조건, 1~5초월 효과는 유지한다.

| 역할 | 기존 6종의 기본 몸체 체력 범위 | 판단 기준 |
|---|---:|---|
| 탱커 | 2000~2100 | 피해 흡수·아군 생존·핵심 공격 기회 |
| 원거리 | 1450 | 이동 용사 압박·제어 연계 |
| 제어 | 1400~2500 | 원거리/근접 노출 차이, 제어 실적·군단 시너지 |
| 폭발 | 1700 | 사냥/후퇴의 전체 주기·기술 피해·위험 부담 |

위 범위는 이번 기존 6종의 설계 참고값이며, 모든 신규 초월에게 강제 적용하는 전투력 공식이 아니다. 최초 1~5초 안에 주요 행동을 시작할 **게이지 기회**를 제공한다. 등장 동작, 거리, 정신집중, 우선순위 때문에 실제 적중 시간은 달라진다. 초기 게이지를 전부 채우거나 기술 쿨타임을 없애지 않는다. 만티코어는 현재 피해 400 해금 기준에서 각 타격 72 / HP1900, 아서는 실제 탱커40 기준 공격230 / HP2600이다. 해금에 쓴 군단이 용사에게 EXP도 제공한다는 점을 같이 평가한다.

## 신규 몬스터 추가 절차 — 대략적인 입력 허용

1. `MonsterCatalog.MONSTERS`에 ID/등급/역할/비용/씬/기술을 넣고 `ORDER`에 등록한다. `base_stats`의 HP/공격력이 임시 값이어도 일반 몬스터는 공통 예산으로 교정된다.
2. 특수 능력이 있으면 그 항목에 아래 `balance` 메타데이터를 추가한다. 기존 ID는 검토 완료 프로필, 신규 ID는 역할 기본값을 사용한다. ID를 Battle의 조건문에 추가할 필요는 없다.
3. 새 기술의 실효 성능을 검토해 계수와 `note`를 작성하고 감사 도구를 실행한다. 미검토 신규 ID는 수치는 계산되지만 감사에서 경고/실패하여 검토 누락을 드러낸다.
4. 초월은 기존 개별 behavior catalog의 BASE/성장/INITIAL_GAUGE를 같은 설계 절차로 검토한다. 다단 기술이나 고유 성장의 강도를 공식 하나로 자동 보장하지 않는다. 향후 추가 작업에서도 이 규격을 참조한다.
5. 일반 씬의 export/behavior BASE는 저작용 입력이다. 게임의 소환 권위는 Catalog 값이다. 새 우회 소환 경로가 생기면 수정자 적용 전 `MonsterCatalog.apply_runtime_base_stats`를 호출해야 한다. 초월의 `configure_transcendence`가 만든 성장 스냅샷은 덮어쓰지 않는다.

```gdscript
"balance": {
    "health_share": 0.8,  # 쉴드/부활 등 고유 생존 기여
    "damage_share": 0.75, # 독/제어/지원 등 고유 기여
    "cycle_damage_multiplier": 2.0, # 전체 연격의 공격력 합계
    "cycle_extra_seconds": 0.0, # CD 외 추가되는 동작 시간만
    "note": "2타 합계 200%, 갱신형 둔화 보유. 군단 지원으로 검토",
},
```

실행 명령:

```bash
godot --headless --path . --script res://tools/monster_balance_audit.gd
godot --headless --path . --script res://tests/monster_balance_smoke.gd
```

## 적용 순서 / 성능

Catalog 정규화 캐시 → 소환 직후 원본 적용 → 대형몹 → 원본 스냅샷 → 기존 등급/강화/연구/증강/마왕 레벨 → `_ready()` 및 전투 시작. 고정 0레벨 증원도 같은 Catalog 원본을 사용하며 EXP 집계는 별도 경로를 유지한다. UI는 독립 사본을 받으므로 외부 수정이 캐시를 오염시키지 않는다.

정규화는 ID별 최초 한 번, 소환은 작은 스탯 필드 수에 비례한다. 전체 개체 탐색·프레임 배열·새 몬스터 생성·매프레임 재계산을 추가하지 않는다. 데이터가 변경된 빌드를 실행할 때 새 캐시가 만들어지며 런타임 Catalog 변조는 지원하지 않는다.

## 실전 확인 및 후속 조정

최종 승률은 아직 측정하지 않았다. 같은 마왕 성장·같은 총 비용·같은 소환 위치·같은 용사 레벨/시드로 아래를 비교한다.

- 각 역할 단독 / 탱커+제어+화력 조합: 지휘력당 실피해, 피해 흡수, 유효 제어 시간, 용사에게 준 EXP, 실제 공격 도달률.
- 초월 0/5초월, 각 해금 직후와 늦은 소환: 첫 기술 시간, 전체 생존 시간, 군단 보조 효과, 소환 준비 비용.
- Stage1~10 여러 AI 시드: 특히 Stage4 권총 용사의 회피·장전 구간. 카운터 조합이 유의미하고 모든 상황에서 우세한 동일 카드가 없어야 한다.
- 우선 10개 이상의 고정 시드로 이상치를 찾고 필요 시 확대한다. 임의의 목표 승률을 검증 결과처럼 쓰지 않는다.
- 수치 후속 조정은 이번 기준점을 바탕으로 ±10~15% 단위로 시행한다. 명확한 기여 경로 오류는 수치 보상보다 먼저 수정한다.

## 롤백
