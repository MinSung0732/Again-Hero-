# 용사 무기 전달 방식·맵 공세 — 2026-10-15

100종 감사 결과와 전후 분류는 [TSV](HERO_SURVIVAL_VARIETY_20261015.tsv). 기존 무기 ID/10레벨/진화/아이콘/전용 프레임 경로를 유지하고 31종 전달 방식을 변경한다. Vampire Survivors에서 요청된 '서로 다른 공간을 담당하는 무기의 조합'을 목표로 하되 원본 게임의 수치나 에셋을 복제하지 않는다.

각 키트에 전달/공격 패턴 기준 최소 4종. 별빛/쇠뇌 등 새 설치체는 피격 없는 고정 마력체로, 이동·HP·어그로가 있는 이계 소환수와 구별한다. 회전 개체는 실제 개체 원형에만 접촉 피해를 주고 중심/사이 빈틈은 피해가 없다. 공포 이동에 고정 지대·설치체가 끌려가지 않으며 이동 성역/회전만 의도적으로 본체를 따른다. 경로 장판은 시전부터 0/0.4/0.8초의 실제 이동 위치에 순차 고정된다.

무작위 지대는 적 위치를 추적하지 않는다. 하나는 맵 전체, 나머지는 용사 주변 방향 구역에서 추출하고 Battle 경계로 제한하며 0.6초 예고 뒤 피해를 시작한다. 24개 설치 슬롯을 시작 때 할당, 한 무기당 지대 최대3/설치체 최대2/회전군1(개체2~8), 재시전은 같은 무기 슬롯 갱신. 기존 투사체64개 풀, 공간그리드, generation handle, 48개 순간 효과 풀 재사용. 소환/회전 매 프레임 Node 생성·전체 그룹 검색 없음. RefCounted 역참조는 WeakRef로 수명 순환 방지.

## 피해·성장 예산

비회전 기본 틱 피해 = round(시전 피해 × 2 × 기본 틱간격 / (기본 지속시간 × 지대 수)), 최저1. 설치체 기본0.75초 사격, 공격속도 보조로 실제 사격 간격 감소(하한0.2초). 회전 접촉 피해 = round(시전 피해 ×1.6×기본0.18초 / 실제 재사용간격), 같은 틱에 여러 개체가 닿아도 적당 한 번만 피해. 기본 지속은3~7초, 지속시간 보조·원래 field_duration 성장 반영(최대10초, 회전은 다음 발동까지 유지). 기본 예산으로 틱 피해를 정규화하므로 지속시간/틱간격 강화가 피해를 역으로 낮추지 않는다.

기존 Lv3/6/10 및 진화 damage/reach/cooldown, 느려짐/흡혈/처형/후속 파동/시전 방어 효과를 보존한다. field_count는 지대 수, orbit_count는 회전 개체 수, 설치체의 bonus_hits 3당 최대2기까지 증설에 사용한다. 권총 설치 발동도 공유 탄약1 소비. 회전/지대는 실제 공간에서 상자를 타격한다. 상세정보는 '시전 피해 기준'으로 표기하고 틱/접촉/사격 분할을 설명한다. 위 식은 명목 예산이며 적 체류시간·접촉률·맵 이동·설치체 사격 경로에 따른 실측 DPS가 아니다.
