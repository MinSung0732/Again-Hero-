# 메두사

희귀 / 인간형 / 제어 / 근거리 / 코스트 7. 기본 0레벨 HP 110, 이동속도 140, 공격력 6, 사거리 72, 공격 간격 0.65초. 기존 등급·수집·연구·마왕·증강 성장 계산을 그대로 사용한다. 기존 일반/엘리트 프레임과 중독 도트만 재사용한다.

## 기본 행동 / 석화

- 몬스터 충돌 및 공통 밀어내기에서 제외. 지형과 용사 충돌은 유지한다.
- 사거리 밖에서 추적하는 동안 개체마다 이동 배율이 초당 0.10씩 증가하며 최대 2배. 실제 HP/실드 피해를 입히면 1배로 초기화한다. 무적에 막힌 공격은 초기화/스택을 발생시키지 않는다.
- 용사별 메두사 공용 적중 카운터. 처음 10회 적중 시 2.5초 석화, 카운터 소비, 다음 필요 적중 수 +1. 다음은 11회, 12회 등. 석화 중에는 재적용/갱신하지 않으며 적중 누적은 유지한다. 종료 후 다음 유효 적중으로 다시 임계값을 검사한다.
- 석화는 이동·돌진·순간이동 위치 변경을 차단한다. 공격/스킬 로직과 몸체 애니메이션은 계속 진행한다. 상태저항을 반영하고 몸체만 약간 어둡게 표시한다. 석화 전용 이펙트는 아직 없다.
- 사망/프로필 초기화 시 석화·메두사 누적 카운터·피해량 기반 중독을 정리한다.

## 특수증강

1. **뱀의 가속**: 현재 실제 이동속도의 5%를 추가 피해로 적용. 추적 배율 초기화 이전 속도를 사용한다.
2. **석상의 균열**: 석화 중인 대상에게 총 공격 피해 1.5배.
3. **돌가루의 잔재**: 이 증강을 가진 메두사가 발동한 석화 종료 후 3초간 30% 둔화.

미지정 수치는 초기 밸런스 기본값이며 Catalog에서 조정한다.

## 엘리트 — 숨겨진 독

선쿨/재사용 0초 패시브. 반경 250(지름 500)의 얇은 원을 표시하며 해당 범위의 살아 있는 메두사(자신 포함)에 중독 공격을 부여한다. 공간 그리드 후보를 재사용 배열에 받아 실제 반경을 검사한다. 0.2초 간격 갱신, 0.35초 버프 유예로 매 프레임 전체 몬스터 스캔을 피한다. 오라를 벗어나면 유예 만료 후 중독 신규 부여가 끝난다.

## 피해량 기반 중독

- 실제 첫 공격이 준 HP/실드 피해량을 기록하여 5초 동안 같은 피해량을 한 번 더 나눠 준다. 0.5초 주기 누적 반올림으로 마지막 틱까지 원래 총량을 정확히 보존한다.
- 같은 공격 개체의 중독이 남아 있으면 중첩/갱신하지 않는다. 다른 개체는 별도 기록으로 동시 적용한다. 만료된 뒤에는 같은 개체도 다시 적용할 수 있다.
- 일반 무적시간을 무시하며 중독 틱은 새로운 무적시간을 만들지 않는다. 이미 기록한 실피해에 방어 계수를 다시 곱하지 않는다. 틱 시점의 실드는 피해를 흡수한다.
- 원래 공격 개체가 사망해도 남은 중독은 유지한다. 소스는 약한 참조로 보관한다. 용사 최종 사망 시 틱 순회 도중에도 안전하게 정리한다.
- 기존 중독 이펙트 4프레임을 연결한다. 기존 독거미 계열 중독 계산은 별도로 유지하며 표시만 공통 사용한다.
- `apply_damage_poison(duration, total_damage, source)`로 다른 지속시간도 사용할 수 있다. 이 시스템의 중독 틱은 메두사 적중/석화 스택을 추가하지 않는다.
