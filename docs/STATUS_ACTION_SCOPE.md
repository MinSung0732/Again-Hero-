# 상태이상 행동 집계

이자나미/슈텐-도지는 소환 전 아군이 용사에게 성공적으로 부여한 상태이상 행동 수를 스냅샷으로 사용한다. 상태이상 종류/효과 틱/장판 개수/투사체 개수 대신 원래 공격·기술 시전당1회다. 이후 실제 상태 이벤트는 계속 발생해도 소환된 능력치는 고정된다.

`status_action_scope.gd`의 Token을 공격·시전당 생성하고, 자식 투사체/효과 슬롯에 같은 참조를 보관한다. 대상에게 상태를 적용하는 동안 begin/finish를 쌍으로 호출하며 기존 스코프를 복원한다. 지연 효과는 저장한 Token을 사용하고, 풀 재사용 시 참조를 비운 후 새 발사의 Token을 받는다. 차단된 엘리트 시전 재시도는 대기 Token을 재사용한다.

Hero의 기존 `status_applied`는 모든 실제 상태 이벤트를 그대로 전달하여 AI 관측/패시브 의미를 보존한다. 별도 `status_action_applied`는 Token의 최초 성공 이벤트만 전달하며 Battle의 성장/해금 카운터가 구독한다. 상태가 적용되지 않으면 횟수를 소비하지 않는다. 직접 호출/단일 상태 경로에 스코프가 없으면 성공 이벤트마다1회다. 신규 다중 상태/지속 장판 기술은 반드시 같은 출처 Token을 연결해야 한다.

회귀: `tests/status_action_growth_smoke.gd`는 실제 Battle/Hero, 밴시 복수 상태 공격, 엘리트 거미 다중 장판, 설녀3발/풀 재사용, 석화 종료 둔화와 두 몬스터의 소환 전 스냅샷을 확인한다. 전투 핫패스에 전체 그룹 스캔/추가 노드/매프레임 Token 생성은 없다.
