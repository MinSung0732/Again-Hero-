# 용사 증강 설명 정리 · 소환물 광역 성장

## 선택 설명

무기100종의 레벨업·일반 상자·MAX 상자는 해당 단계에서 바뀌는 수치와 짧은 무기 태그를 표시한다. 용사 성향·피해 예산·전체 공격 방식 설명·미래 MAX 안내는 선택 설명에서 제거한다. 편성 무기 목록은 태그만 표시한다. 상세창은 현재 능력치 표와 태그, 다음 강화 수치로 정리하고 연관 콘텐츠/계산 안내 문단을 제거한다. 보조 증강도 즉시 증가량·누적량만 간단히 표시한다.

- 증가율은 동일 resolver의 직전 단계/선택 단계 결과로 계산한다. 피해는 최종 power×damage_scale, 사거리/간격은 실제 성장 배율 비교. MAX는 Lv10→MAX 비교이며 일반 레벨 증가분을 다시 더하지 않는다.
- 실제 공격 경로·전달 방식·소환 광역 여부를 짧은 태그로 표시한다. MAX의 각인/왕복/협공 등도 태그로 구분한다.
- 소환 카드의 성장 사거리는 소환수 공격 거리에 자동 적용되지 않으므로 일반 무기의 사거리 증가 문구를 복사하지 않는다. 소환수 공격 거리·공격 간격은 실제 summon_patch가 바뀔 때 표시한다.
- 수치는 두 자리까지 표시해 0.34→0.28초가 같은 값으로 반올림되지 않도록 한다. 예: `공격 간격 -0.06초`. HP/피해 비율 가산은 %p로 구분한다. 공격 범위 보조의 기존5% 오기는 실제6%로 수정했다.
- 일반 카드부터 MAX까지 최대160자/6개 논리 행, 보조70자 미만/2행 검사. 한글의 실제 화면 줄바꿈은 화면 폭에 따른다. 장문을 잘라 숨기는 대신 변경 수치만 구성한다.

예: 투견 Lv3 선택

```text
소환 피해 +28.6% · 재소환 -2.2%
소환 유지 16 → 18초 · 소환 HP +10%p
전방 휩쓸기: 반경65 · 45% · +3체 · 연격 +1타
#소환 #근접 #광역
```

## 소환물 광역 성장

기존 Lv1~2의 단일 공격 이후, Lv3에서 광역 공격을 얻고 Lv6·9·10·11에서 강화한다. Lv11은 기존 Lv10 무기의 상자 MAX 진화이며 캐릭터 레벨11 자동 해금은 아니다. HP·유지시간·기본 피해 성장과 기존 고유 연격/집중/연속사격 성장도 함께 적용된다.

| 소환물 | 공격 방식 |
|---|---|
| 투견 | 타격 지점 주변의 전방 적을 휩쓰는 연격. 후방은 제외 |
| 정찰병 | 자기 위치 중심의 회전 베기. 전후방 모두 타격 |
| 감시자 | 탄착 지점의 차원 파동. 빠른 사격에 맞춰 추가 피해는 낮게 설정 |
| 문지기 | 탄착 지점의 균열 폭발. 느린 사격에 맞춰 반경·추가 피해를 크게 설정 |

각 칸은 **반경 / 기본 타격 산출 피해 대비 추가 피해 / 추가 적 수 상한**이다. 기본 주 대상은 광역 타격에서 제외한다.

| 단계 | 투견 | 정찰병 | 감시자 | 문지기 |
|---|---|---|---|---|
| Lv3 | 65 / 45% / +3 | 90 / 50% / +3 | 70 / 30% / +2 | 85 / 50% / +3 |
| Lv6 | 90 / 60% / +4 | 120 / 65% / +4 | 95 / 40% / +3 | 115 / 65% / +4 |
| Lv9 | 115 / 75% / +5 | 150 / 80% / +6 | 125 / 50% / +4 | 145 / 80% / +5 |
| Lv10 | 145 / 90% / +6 | 180 / 95% / +7 | 155 / 65% / +6 | 180 / 100% / +7 |
| Lv11 MAX | 190 / 100% / +8 | 220 / 110% / +10 | 200 / 85% / +8 | 230 / 120% / +10 |

## 전투 경계와 예산

- 광역 피해는 실제 근접 타격/탄착에서만 발생한다. 대상별 방어·무적·피해 종류·피흡은 기존 MonsterHitContext를 거친다. 주 대상에게 같은 타격을 두 번 주지 않는다. 숨음/사망/비표적은 제외, 반경 밖·투견 후방 제외. 탄 반사 시 광역도 취소된다.
- MAX의 타격당 추가 피해 상한은 투견8배·정찰병11배·감시자6.8배·문지기12배다. 모든 추가 대상이 범위에 있을 때의 합이며 실전 DPS/단일 보스 피해 증가율이 아니다. 원래 연격/사격 간격·최대3체 공유·MAX 협공이 존재하므로 단일타격 비율만으로 무기 간 승률을 보장하지 않는다.
- 살아 있는 소환물은 선택 시 새 광역 수치를 받는다. 기존 HP비율/경과시간 유지, 사망·만료 개체는 회복/부활시키지 않는다. 공격 범위 보조는 광역 반경에 한 번 적용한다. 발사된 탄은 발사 시점 수치를 스냅샷하며 재사용 시 광역/표시 상태를 초기화한다.
- HeroSummonGrowthCatalog에 단계별 값, 공통 SummonAreaAttack에 공간 쿼리/상한/피격 분류/짧은 범위 파동을 둔다. 기존 소환수·탄 풀을 재사용하며 공격 노드·전투 핫패스 배열/Dictionary·전체 그룹 스캔을 추가하지 않는다. 기존 피해 숫자의 지연 초기화 풀은 유지한다.
- 일반 AI 소환 설정에는 새 성장값을 넣지 않는다. 같은 소환수 객체가 AI 원본 설정으로 다시 활성화되면 광역 필드는0으로 초기화된다. 기존 무기 ID·소유/상자 영수증·보조 수치·저장/보상 형식은 유지한다.
