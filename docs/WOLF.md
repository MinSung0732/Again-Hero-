# 늑대

- 고급(uncommon) · 짐승 · 물량 · 근접, 코스트5. 기본 HP100 / 이속160 / 공격12 / 사거리68 / 공격주기0.65초 / 처치EXP27. 수집 성장·마왕 레벨·일반/특수증강·엘리트 보정은 기존 공통 경로 적용.
- 기본 2연격은 현재 공격력의 총량을 두 번에 분배(홀수는 첫 타 올림, 나머지 두 번째 타). 두 번째 타는0.16초 후 같은 생존 대상이 사거리 내에 있어야 적중. 첫 타가 실제 HP/실드 피해를 주어야 후속 타를 예약하며, 후속 타는 첫 타가 만든 무적시간을 무시. 공격 도중 하울링/무리사냥/사망/강제 이동 잠금 진입 시 예약 취소.
- 반경250 내 다른 아군 늑대 사망 시1초 정지 하울링 후10초 공격력+15%. 기존 버프가2초 이하일 때만 다시 시전 가능, 중첩 없이10초로 갱신. 공격 시 배율1회 적용해 성장·미라 주술사 버프 갱신과 누적되지 않음. 일반 skill_01..03, 엘리트 hit_01..03을 skill 애니메이션으로 사용. 용기 링 이펙트는 실제 버프 타이머와 도트 크기에 맞춤.

## 특수증강

1. **분쇄의 송곳니**: 두 번째 타가 현재 공격력100%로 증가(첫 타는 기존 절반).
2. **피의 추적**: 각 늑대의 대상별 실제 HP/실드 적중3회마다 대상 최대HP1%의 총 출혈 피해를3초에 나눠 적용. 첫/둘째 타 각각 적중1회, 무효 타격 제외. 대상별 개체 카운터 독립. 기존 Hero의 단일 출혈 슬롯을 갱신, 중첩 없음. 다른 기존 출혈 호출의 지속시간·0.4%/초·갱신 금지 기본 동작은 유지.
3. **강철의 울음**: 하울링 시전1초 동안 받는 피해50% 감소. 버프 유지 시간이나 엘리트 소환 시전에는 적용하지 않음.

## 엘리트 — 무리사냥

- 선쿨5초 / 재사용20초.1초간 hit 프레임 시전 후, 바라보는 방향의 뒤쪽3열×4행에 일반 늑대12마리 소환. 시전 완료 순간 위치/방향을 스냅샷, 완료 전 사망 취소, 완료 후 시전자 사망과 무관하게 소환 완료. 아이들/이동으로 복귀.
- 소환 비용0, 별도 마왕EXP 지급 없음, 기존 처치EXP·사망 이벤트 적용. 일반·특수증강 적용, 엘리트 재귀 소환 없음. 이속+30%는 소환된 개체의 생존 기간 유지(기간 미지정 기준). runtime_variant_stats로 마왕 레벨/일반증강 갱신 후에도 보존, 주술사 이속 버프와 별도로 적용. speed_up 표시.
- 공유 SpriteFrames/텍스처와 FX 불투명 범위를 전투 시작 warmup에서 준비. 소환 job별 다음 인덱스만 저장, 전투 전체 프레임당 생성 최대2개, 제거 swap/pop, 모달 일시정지·새 전투 reset 준수. 실제 몬스터는 기존 생성/등록/사망 경로를 사용.
- 늑대 전용 등록부와 재사용125px 사망 위치 그리드로 같은 프레임의 여러 사망을 모음. 사망이 있는 갱신에서만 각 시전 가능 생존 늑대를1회 확인하고 근처 셀에서 정확한 거리 판정. 전 그룹/모든 개체 쌍 스캔 및 매프레임 후보 배열 없음.
