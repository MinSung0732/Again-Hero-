# 제우스 전투 소환 연출

전투에서 초월 소환이 **실제로 성공하고 1회 소환 상태가 소비된 뒤** `Battle.transcendent_summoned(id, actor)`로 실제 개체를 전달한다. 뽑기·확률·골드·보상 코드에는 연결하지 않는다. 개체 위치/전투 시간/피해/스킬 판정은 연출이 바꾸지 않는다. 화면의 번개는 시각 효과이며 실제 스킬을 발동하지 않는다.

## 재조립본
- `assets/art/effects/battle_summon/zeus/`: 전달된 README, manifest, 조립 PNG, 7개 원본 파츠 PNG, **파츠** 시트를 보존한다. 시트는 프레임 애니메이션이 아니다.
- 포함된 `zeus_reassembled.tscn`의 경로만 프로젝트 위치에 맞게 수정. 7개 Sprite2D는 centered=false, 원점(0,0), 배율1, 동일768×1280. 테스트에서 씬 로드와 각 경로·크기를 확인한다.
- 실제 컷신은 7개 PNG를 동일한 rest mesh/UV/좌표/공통 배율로 합성한다. 파츠 크기 자동 맞춤·파츠별 확대·큰 회전 없음. 원본 파츠 alpha를 보존한다. Python RGBA 합성 검사에서 전달된 조립 PNG와 차이0.
- 메시의 공통 변위장을 모든 파츠에 동일하게 적용해 경계가 벌어지지 않는 최대1.5 원본px의 머리/옷 가장자리 흔들림만 제공한다. 이는 임시 표현이며 완성 Live2D 리깅·관절 애니메이션이 아니다. 머리/손/지팡이의 큰 동작·눈깜빡임은 제공하지 않는다.

## 5초 흐름
- 0~0.85: 어두운 실루엣, 지팡이에 작은 전기. 0.85~1.7: 위에서 아래로 빛이 지나가 전신 공개.
- 약1.9: 기존 독립 번개 PNG가 지팡이 보석에서 방출. 비율을 유지하고 독립적인 24fps 전기 프레임/입자/후광을 사용한다.
- 3.15~3.5: 발 아래의 여백에 UI 이름 `제우스` 표시. 초월 문구 없음. 4.3~5: 컷신 페이드아웃.
- 전투 패널 우하단 안에 배치하고 패널 경계에서 clip한다. HUD 아래쪽과 패널 밖에 그리지 않는다. 전신 캔버스에 공통 배율 적용, 얼굴 클로즈업 없음.
- 별도 Camera2D를 한 번 생성해 재사용. 0~0.95 ease-out 접근, 약1.3배 확대/축소, 4~5초 원래 카메라로 부드럽게 복귀. 원래 카메라의 부모·top_level·위치·줌·offset·추적 설정을 수정하지 않는다. 추적 모드는 현재 추적 대상 위치로, 수동 모드는 원래 수동 위치로 돌아간다. 원래 제한 영역도 유지한다.
- 실제 개체의 화면 좌표를 이용한 화면 조명으로 주변만 어둡게 한다. 월드 조명 노드와 전투 판정은 변경하지 않는다.
- 카메라 드래그는 연출 동안만 차단. 대상 사망/삭제, 전투 종료, 패널 숨김, 메뉴/증강 일시정지 시 즉시 원래 카메라 복원. 게임 일시정지는 연출이 해제하지 않는다.
- 카탈로그에 몬스터별 view/duration/zoom 등록 가능. 컷신과 7개 텍스처/번개 프레임은 설치 시 준비하여 반복 instantiate/free·그룹 탐색 없음.

## 다음 제작에 필요한 보완 파츠
모두 **768×1280 투명 PNG, 공통 원점(0,0), 몸통X384·발Y1200**, 동일 배율. 조립 기준 이미지와 레이어 순서·회전축/pivot·가림 관계를 manifest에 기록한다. 움직이는 가장자리 아래는 최소24~48px 겹침을 복원하고, 실제 최대 회전/이동 범위에 맞춰 더 확장한다.

| 대상 | 필요한 보완 |
|---|---|
| 몸통/피부/기본 의상 | 머리카락·팔·천 뒤에 숨은 어깨, 가슴, 허리, 다리와 의상 복원. 몸통 한 덩어리를 완성하고 겹침 여유 확보 |
| 머리/머리카락 | 얼굴/목을 완성한 head, 앞머리·좌/우 측면·뒤머리 분리. 뿌리까지 이어지는 완전한 머리카락과 그 뒤 피부·옷 복원 |
| 팔/손/소매 | 좌우 상완·전완·손·소매를 각각 완성. 어깨/팔꿈치/손목의 가림부와 관절 겹침, 회전축 기록 |
| 옷자락/리본 | 몸통에 붙는 뿌리부터 끝까지 완전한 좌우 천·리본. 그 뒤 의상/다리 복원, 앞/뒤 레이어 구분 |
| 지팡이 | 현재 staff_upper만으로는 부족. 손 뒤를 포함한 완전한 지팡이·보석·장식, 손 앞/뒤 레이어와 손잡이 pivot, 전기 방출 anchor |
| 표정 | 눈 좌/우(흰자·홍채·윗/아랫눈꺼풀), 닫힌 눈, 눈썹, 입 분리. 그 아래 얼굴 피부 복원 |

## 검증/미리보기
처음 내려받았으면 먼저 `godot --headless --editor --import --quit --path .`로 import한 뒤 실행한다.

`godot --headless --path . --script tests/battle_summon_cinematic_smoke.gd`

고립된 전투/카메라 fixture에서 60Hz 5초 진행, 추적/수동 복원·개체 위치 불변·3개 패널 비율·캐시 재사용·메뉴/종료/삭제 중단·납품 정적 씬을 검사한다. 실제 PC OpenGL fixture 렌더에서 실루엣/전신/번개/이름을 확인했다. **실제 전투 플레이와 Android 실기기·장시간 성능·APK export는 미검증**. 기존 rig/번개 smoke도 통과. 가챠 코드와 보상 테스트는 이번 작업 대상이 아니다.
