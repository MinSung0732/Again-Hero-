# 제우스 전투 소환 컷인

실제 전투 초월 소환 성공·1회 사용 소비 후 `transcendent_summoned(id, actor)`에 전달된 실제 개체로 연출한다. 뽑기와 별도이며 골드·확률·보상은 수정하지 않는다. 그림 속 번개는 시각 효과이며 실제 스킬·피해·이동 판정을 발동하지 않는다.

## 현재 구성
- 전투 패널 우하단에 붙는 대각선 삼각형 배경. 직사각형 배경 카드 없음. 배경/일러스트/눈 표정/번개를 독립 레이어로 표시한다. 번개 플래시도 삼각형에만 적용한다. 일러스트는 컷인 내부 사각형으로 자르지 않고 삼각형 바깥으로 펼치며, 전체 전투 패널 경계에서만 클리핑한다.
- `battle_cast_v1.png`는 지팡이를 들어 올린 **전투 전용 새 포즈**. 원본 제우스의 얼굴·금발·월계관·흰/금/파랑 의상·청색 보석 지팡이를 참조해 ImageGen으로 생성했다. 기존 뽑기 포즈와 별도이며 생성 이미지이므로 원본의 픽셀 단위 복제본은 아니다. 원본 캔버스971×1620을 균일 배율로 표시, nearest 필터. manifest에 alpha bounds/방출 anchor/해시 기록.
- `battle_closed_eyes_v1.png`는 새 포즈의 얼굴 crop(360,470,190,145)을 참조한 눈감음 표정. 눈 두 영역에만 마스크로 덧씌우므로 원본 몸통·코·입·머리카락을 교체하지 않는다. 원본 입력과 생성 프롬프트는 BATTLE_CAST_SOURCES.md.
- 단일 포즈 메시의 작은 외곽 흔들림, 표정 레이어 혼합, 일러스트 줌을 시간으로 연속 제어한다. 시트/프레임을 순서대로 바꾸는 슬라이드쇼가 아니다. 큰 팔 관절 회전이나 몸통 재조립은 없다. **완성 Cubism Live2D 모델은 아니다.**
- 전달된 정적7 PNG/manifest/파츠 시트/정적 씬은 보존한다. 정적 씬 경로·원점/배율은 기존 검증 그대로이며 시트는 파츠 목록이다. 현재 컷인은 새 전투 포즈를 사용한다.

## 약5초 흐름
| 시간 | 일러스트 |
|---|---|
| 0~0.35 | 처음부터 본모습 전신, 작은 진입 움직임 |
| 0.35~0.65 | 눈을 감음 |
| 0.65~1.65 | 일러스트만 얼굴 쪽으로 부드럽게 약3.1배 확대 |
| 1.8~2.12 | 눈을 뜨고 집중. 이 구간은 번개를 약하게 표시 |
| 2.75~3.85 | 일러스트가 원래 전신 구도로 복귀 |
| 3.5~5 | 발 아래 이름 `제우스`, 4.3초부터 페이드 종료 |

별도 전투 카메라는0~0.95초 ease-out 접근, 가벼운 확대/축소,4~5초 원래 카메라로 복귀한다. **일러스트의 얼굴 줌과 전투 카메라는 독립**이다. 원래 카메라의 부모·top_level·위치·줌·offset·추적/수동 설정을 수정하지 않는다. 전투 개체 위치와 판정도 바꾸지 않는다. 주변 조명은 화면 마스크이며 월드 조명 노드 변경 없음. 대상 죽음/삭제·전투 종료·패널 숨김·메뉴/증강 일시정지 시 복원한다.

## 접근 슬로우 / 실제 제우스 중심 번개
- 카메라 접근 보간값과 함께 `Engine.time_scale`을 기존 속도×0.18까지 낮춘다. `Time.get_ticks_usec()` 기반 컷인·카메라·표정·번개는 실제 시간으로 진행하므로 약5초 길이를 유지한다. 물리 tick 수와 일시정지/판정/개체 좌표는 변경하지 않는다. 전투의 이동·공격·지휘력·전투 타이머는 기존 scaled delta 기준으로 함께 느려진다.
- 눈뜸과 함께1.9/2.08/2.26초에 실제 소환된 제우스 원점에서8방향 PNG 번개가 세 번 퍼진다. 동일 생성 번개4프레임을 재사용·균일 회전/스케일, 별도 시각 효과이며 피해/충돌을 추가하지 않는다. 카메라 투영과 줌을 적용해 실제 개체를 따라간다. 우하단 일러스트/지팡이 이펙트와는 별도 레이어다.
- 마지막 번개 페이드 후2.65~3.3초에 저장한 속도로 복귀. 모든 취소 경로(메뉴/증강/전투 종료/대상 사망·삭제/패널 숨김/SceneTree pause/모바일 백그라운드/씬 이탈)에서도 복원한다. 재생 전 속도가1.0이 아니어도 그 값을 복원하며, 일반 상태 cancel은 속도에 손대지 않는다.
- 데이터: Catalog의 `slow_motion`/`world_effect` 및 `ZEUS_RADIAL`에 속도·타이밍·방향 수·거리 등록. 월드 효과도 설치 시 준비 후 재사용한다.

설치 시 뷰/텍스처/메시/전기4프레임을 준비하고 재사용. 전체 그룹 검색·매 프레임 메시 생성·반복 instantiate/free 없음. 몬스터별 view/duration/zoom은 Catalog 등록.

## 로컬 테스트
초월 등록 후 로컬 테스트 전투에서 `잠금 해제`를 먼저 누르고 `초월 소환`을 누른다. 클릭 전에는 `잠김` 및 흐린 아이콘. 자연 조건 카운터가 먼저 채워져도 테스트 클릭 확인 전에는 소환할 수 없다. 새 전투에서 확인 상태 초기화. 일반 계정에서는 숨김/함수 차단, 정상 자연 해금 유지. 사용 완료·메뉴/증강·종료 차단, 전투당1회 유지. 조건 카운터만 채우고 실제 지휘력/마력/소환 수/스탯 스냅샷은 변경하지 않는다.

## 검증
처음 내려받은 프로젝트는 먼저 `godot --headless --editor --import --quit --path .`.
- `godot --headless --path . --script tests/battle_summon_cinematic_smoke.gd`: 처음부터 표시·삼각형·우하단 정렬·눈감음/눈뜸·일러스트 줌/전신 복귀·원래 카메라/모드 복원·캐시/중단/비율·원본 정적씬·0.18배속/기존 속도 복원·8방향/3회/실제 개체 투영·실시간5초와 실제 physics delta 누적 비교.
- `godot --headless --path . --script tests/local_test_transcendence_unlock_smoke.gd`: 일반 계정 차단·클릭 전 차단·이미 자연 준비된 경우에도 명시적 클릭·클릭 후 소환 허용·자원/스냅샷 보존·중복/사용/신규 전투/종료·일반 자연 해금.
- Godot4.6 PC OpenGL 격리 fixture에서 전신·삼각형·눈감음 확대·눈뜸·복귀 렌더 확인. 실제 전투 플레이·Android/장시간 성능·APK export는 미검증.

## 완전한 파츠 애니메이션 확장
공통 캔버스/원점/배율 유지, 각 pivot과 앞뒤 가림 순서 기록. 머리카락 아래 피부·옷, 팔의 어깨/팔꿈치/손목 겹침, 천의 뿌리·그 뒤 다리, 손 뒤까지 이어지는 완전한 지팡이, 개별 눈꺼풀/홍채/눈썹/입이 필요하다. 움직이는 경계 아래 최소24~48px를 복원하고 최대 동작 범위에 맞춰 확장한다. 현재 새 포즈 및 눈감음 패치는 이 보완 파츠를 대신하는 완전한 리깅 자료가 아니다.
